一、背景与目标

1.1 为什么做

SRM 产品已内置 AI 智能模块，客户端用户可自主创建「专家团」辅助采购决策、供应商评估等场景。随着客户规模增长，管理端面临三个核心痛点：

🔍 缺乏全局视野

管理端无法查看客户端创建的专家团，无法了解各客户的使用偏好和最佳实践，难以提炼行业通用方案。

📦 无法统一分发

优质专家团配置无法在客户间复用，每个客户需从零搭建，增加使用门槛，降低产品价值感知。

⚙️ 缺少质量管控

客户端创建的专家团缺少审核机制，可能存在不当内容或低质量配置，需要管理端具备发布/下架管控能力。

1.2 核心目标

目标功能
实现管理端对专家团的全面管控管理端可管理的专家团
支持优质专家团跨客户复用管理端导入并发布专家
降低客户端专家团创建门槛客户端使用预置专家团

1.3 目标用户

本模块面向 管理端运营人员、管理端管理员 和 客户端用户 三类角色，核心解决管理端对专家团的「可见、可控、可分发」问题。

三、用户故事

运营人员小王 希望将某个客户端的优质专家团导出为 JSON 文件， 以便备份或在其他环境复用该配置。

运营人员小王 希望上传 JSON 文件导入专家团到管理端， 以便快速将预制的行业通用专家团配置部署到系统中。

运营人员小王 发现某个已发布的专家团存在问题，希望快速下架， 以便防止客户端用户继续使用有问题的配置。

管理员老李 希望删除不再使用的专家团，但不确定是否需要彻底删除， 所以先移入回收站，需要时可以恢复，确认无用后再彻底清理。

管理员老李 希望批量恢复回收站中的专家团， 以便在误删场景下快速恢复多个专家团，减少重复工作。

四、功能架构总览

专家团管理模块由四大子模块组成，围绕专家团的「查看 → 导入 → 发布 → 回收」形成完整生命周期管理链路。

💡 核心链路：客户端创建专家团 → 客户端查看/导出 → 管理端导入 → 审核后发布上架 → 客户端使用 → 问题专家团下架/删除 → 回收站恢复或彻底清理。

五、子模块详细设计

📋 5.1 专家团列表

专家团列表是管理端运营人员的核心工作台，展示所有来源（客户端创建 + 管理端导入）的专家团，支持多维度搜索、筛选、批量操作和快捷导入。

列表字段设计

字段类型排序说明
头像图片—专家团图标，缩略图 40×40，点击可预览大图
名称文本✅专家团名称，最大 50 字符，点击进入详情
描述文本—专家团简介，列表展示前 80 字符，超出截断
来源枚举✅管理端 / 客户端（目前只有管理端）
类别标签✅专家团类别，如「采购寻源」「供应商评估」「合同审核」等
状态枚举✅发布 / 下架
创建人文本✅创建该专家团的用户名（客户端来源显示客户端用户名，管理端来源显示管理端操作人）
创建时间时间✅专家团首次创建时间
更新人文本✅最近一次修改的操作人
更新时间时间✅最近一次修改时间

搜索与筛选

筛选项类型说明
名称文本输入模糊搜索，支持关键词匹配
描述文本输入模糊搜索，支持关键词匹配
分类下拉多选从系统预设分类中选择，支持多选组合筛选
状态下拉单选全部 / 已发布 / 已下架
创建人文本输入模糊搜索创建人名称
💡 搜索条件支持组合筛选，结果实时刷新。筛选条件变化时自动重置分页到第 1 页。

功能清单

  • 列表展示：默认按创建时间倒序排列，每页 20 条，支持分页切换；
  • 搜索筛选：顶部搜索栏支持名称/描述/创建人模糊搜索 + 分类/状态组合筛选
  • 查看详情：点击专家团名称或「查看」按钮，弹出专家团详情弹窗；
  • 导出：勾选单个或多个专家团，点击「导出」按钮，将选中专家团配置导出为 JSON 文件
  • 导入：点击列表右上角「导入专家团」按钮，弹窗上传 JSON 文件，详见 5.4 导入/导出
  • 删除：勾选专家团后点击「删除」按钮，二次确认后移入回收站（软删除）
  • 发布 / 下架：仅管理端来源的专家团显示此操作；「下架」状态可发布，「发布」状态可下架；
  • 回收站入口：列表右上角显示回收站图标按钮，点击打开回收站面板
  • 批量操作：列表左侧复选框支持多选，配合底部批量操作栏执行批量删除、批量导出

🗑️ 5.3 回收站

回收站提供已删除专家团的缓冲恢复能力，防止误删操作造成数据丢失。回收站以侧滑抽屉或弹窗形式展示。

回收站列表字段

字段类型说明
头像图片专家团图标缩略图
名称文本专家团名称
来源枚举管理端 / 客户端
类别标签所属分类
删除人文本执行删除操作的用户
删除时间时间移入回收站的时间

功能清单

  • 恢复：单个恢复，将专家团从回收站移回列表，恢复为删除前的状态（已发布/已下架）
  • 彻底删除：单个彻底删除，不可恢复，需二次确认弹窗
  • 批量恢复：勾选多个专家团后一键批量恢复
  • 批量彻底删除：勾选多个专家团后一键批量彻底删除，需二次确认弹窗
  • 清空回收站：一键清空回收站中所有专家团，需二次确认弹窗，操作记录审计日志
⚠️ 彻底删除操作不可逆。建议对管理端来源的专家团在执行彻底删除前，先导出 JSON 备份。

📦 5.4 导入 / 导出

导入/导出功能实现专家团配置的跨环境迁移和数据交换，采用 JSON 作为标准交换格式。

导入功能

项目说明
触发方式列表页右上角「导入专家团」按钮
交互形式弹窗上传 JSON 文件，支持拖拽上传和点击选择
文件格式仅支持 .json 文件
文件大小限制单文件 ≤ 5MB
来源标记导入的专家团来源自动标记为「管理端」
初始状态导入成功后默认为「已下架」状态，需手动发布
名称冲突处理同名专家团提示专家团已存在；

导出功能

项目说明
触发方式列表页勾选后点击「导出」按钮，或详情页点击「导出」按钮
导出格式JSON 文件，文件名格式：expert_teams_YYYYMMDD_HHmmss.json
导出内容包含专家团完整配置：基本信息、擅长领域、团队成员、开场问题
批量导出支持勾选多个专家团一次性导出，所有专家团打包到同一个 JSON 文件
不包含字段导出文件不包含来源、状态、创建人、调用次数等管理端运行态字段

导入校验规则

  • 格式校验：文件扩展名必须为 .json，文件内容必须为合法 JSON 格式
  • 必填字段校验：name、description、category、expertise_areas、members 为必填，缺失则标记该行失败
  • 长度校验：name ≤ 50 字符，description ≤ 500 字符，超出则截断并提示

六、关键交互流程

流程一：导入专家团并发布上架

1

点击导入按钮

运营人员在专家团列表页点击右上角「导入专家团」按钮，弹出上传弹窗

2

上传 JSON 文件

拖拽或点击选择 JSON 文件，系统实时校验文件格式和大小，不合法则即时提示

3

执行导入校验

后端逐条校验必填字段、长度、格式，展示导入结果摘要（成功/失败数量及失败明细）

4

确认并关闭弹窗

导入成功后弹窗展示结果摘要，运营人员可下载失败报告，关闭弹窗返回列表

5

审核并发布

在列表中找到导入的专家团（来源=管理端，状态=已下架），查看详情确认无误后点击「发布」

6

发布成功

状态变更为「已发布」，客户端用户即可在专家团列表中看到并使用该专家团

流程二：删除专家团并恢复

1

勾选目标专家团

在列表中勾选一个或多个需要删除的专家团

2

点击删除按钮

点击列表上方或底部的「删除」按钮，弹出二次确认弹窗：「确认将 N 个专家团移入回收站？」

3

确认删除

点击「确认」，专家团从列表消失，移入回收站；列表自动刷新

4

打开回收站

点击列表右上角回收站图标，打开回收站抽屉/弹窗

5

恢复专家团

找到目标专家团，点击「恢复」按钮，专家团回到列表，恢复删除前状态

流程三：下架问题专家团

1

定位目标专家团

通过搜索或筛选找到需要下架的专家团（仅管理端来源且状态为「已发布」）

2

点击下架按钮

在操作列点击「下架」按钮，弹出确认弹窗：「确认下架专家团 XXX？下架后客户端用户将无法使用」

3

确认下架

点击「确认下架」，状态变更为「已下架」，操作记录写入审计日志

4

客户端生效

客户端用户刷新后不再展示该专家团；已在使用中的会话不受影响，但无法新建该专家团的会话

七、边界与异常情况

序号场景处理策略备注
1 导入 JSON 文件格式不合法 弹窗提示「文件格式错误，请上传合法的 JSON 文件」，不执行导入 前端预校验 + 后端二次校验
2 导入文件超过 5MB 弹窗提示「文件大小超过 5MB 限制，请压缩后重试」 前端文件大小校验
3 尝试对客户端来源专家团执行发布/下架 操作按钮不展示；若通过接口调用，后端返回 403 并提示「客户端来源的专家团不可在管理端发布/下架」 前端隐藏 + 后端拦截
4 批量删除时部分专家团已在回收站中 跳过已在回收站中的记录，结果提示「N 个已移入回收站，M 个已在回收站中已跳过」 幂等处理
5 恢复已彻底删除的专家团 不可恢复。回收站中未找到的记录说明已彻底删除或过期清理 彻底删除前建议导出备份
6 导出的 JSON 文件在导入时被篡改 后端校验 JSON Schema 结构，不合法字段忽略或报错；不执行任何脚本或代码 安全校验，防止注入
7 并发操作同一专家团（如一人发布、另一人删除） 乐观锁机制，后提交者收到冲突提示「该专家团已被其他用户修改，请刷新后重试」 基于版本号或 update_time
8 清空回收站时回收站为空 提示「回收站为空，无需清空」 按钮可点击但无实际操作
9 客户端来源的专家团被删除后，客户端用户正在使用 已建立的会话继续使用不受影响，但客户端列表中不再展示该专家团，无法新建会话 渐进式失效策略
