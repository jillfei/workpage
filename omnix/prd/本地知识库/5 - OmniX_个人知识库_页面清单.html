V1 必做清单（按用户旅程排序）

  • ① 知识库列表页 — 用户第一眼看到"我有哪些知识库"。
  • ② 新建知识库弹窗 — 名称 + 系统文件夹选择器 + 实时校验（高压线：不创建半成品）。
  • ③ 知识库概览页 — 健康条 + 主路径 + 同步控制，首次扫描状态可见。
  • ④ 知识库设置抽屉 — 改名/图标/同步策略/重新绑定（显式重绑，绝不静默改扫）。
  • ⑤ 页面/文件清单页 — 6 态徽标 + 来源定位 + 筛选；失败/暂不支持不伪装知识化。
  • ⑥ 页面阅读页 — 正文+溯源；"回到原文件"恒在（本地优先兜底）。
  • ⑦ 快速搜索（顶栏） — 全局入口，跳页/片段。
  • ⑧ 混合检索结果页 — 融合候选 + 匹配理由 + 降级说明。
  • ⑨ 问答视图页 — 引用/冲突/缺口 + 三类空结果（不编造、拒绝≠未找到）。
  • ⑩ 导入/同步进度面板 — 真实计数，状态机可见。
  • ⑪ 资料源健康面板 — 健康不粉饰，非健康项下钻 + 重试/回填入口。
  • ⑫ 空状态/主路径引导 — 新库不空白、不报错。
高压线页面级验收点：不创建半成品(②)、不静默改扫(④)、禁止伪装知识化(⑤)、不编造/拒绝≠未找到(⑨)、原文件入口恒在(⑥)、健康不粉饰(⑪)。这 6 条须写入 UI 验收用例。

④ 非页面（后台服务 / 引擎）

以下能力支撑上述页面，但不是独立页面，应作为客户端内嵌服务/本地进程设计。列出来避免把"功能"误当成"页面"而遗漏工程量。

后台能力对应模块说明 / 给页面的接口
写入链引擎3.2扫描→变更识别→路由→解析→标准化→切分→向量化(可选)→图谱；向"导入进度面板/健康面板"推送实时状态
写入状态机3.38 态持久化 + 流转校验 + 降级态；页面仅消费 state + copy + reason
混合检索引擎3.4意图识别 + 多路召回(关键词★/语义/图谱/时间) + RRF 融合 + 去重 + 重排；对外暴露 Query/Answer 契约
解析器适配层3.2Markdown 直连 / 代码按策略 / PDF·Word·Excel·PPT 路由 MinerU；无解析器→返回"暂不支持"
本地数据库 / 受控存储全局页面/片段/索引的本地存储（本地优先）；原文件零改动、只读引用
权限 / scope 中间件3.5检索/写入前置校验 kb_id+source_root；无权限返回"拒绝"语义
增量同步 / 目录监听3.6V1 手动+定时增量；V1.1 目录监听；产出变更事件驱动状态机
可选嵌入 / 重排服务3.4 / 3.6本地或受控部署；不可用时检索降级（关键词+图谱），不得阻断基础能力
⚠️ 工程提醒：PRD 明确"原文件始终零改动"是全局高压线。本地存储层与解析器适配层必须实现"只读引用 + 不生成解析副本写回绑定目录"，任何页面触发的"重新解析"都应读取原文件而非副本。

⑤ 客户端软件特殊实现点

因为是桌面客户端（本地优先），有几个页面能力依赖 OS / 本地能力，需在前端之外单独规划：

  • 系统原生文件夹选择器：新建库 / 重新绑定时调用 OS 文件对话框，仅返回绝对路径；校验存在/可读/可规范化（前端预检 + 后端兜底）。
  • "回到原文件"= 系统文件管理器：点击用 OS 打开 bound_path 内对应文件（非应用内页）；这是客户端专属能力。
  • 本地数据库：页面/片段/索引存本地（SQLite 或本地向量库），不强制云。
  • 可选本地推理：嵌入/重排可本地或受控部署；不可用时整条搜索降级，体验不中断（本地优先兜底）。
  • 后台进程：写入链 / 增量同步 / 回填在后台运行，前台进度面板订阅；盘卸载时知识库置"异常"而非静默改扫。
  • 托盘 / 常驻（可选）：PRD 未要求，但客户端常需后台同步常驻；如做，须保证"不静默改扫"原则。
