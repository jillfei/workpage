个人知识库

本地文件夹绑定 · 扫描解析 · 文档管理 · 会话引用 —— 产品需求文档 v1.0

文档版本修改日期修改人修改说明
v1.0 2026-10-14 孙礼飞 初稿，覆盖个人知识库列表页（知识库创建、扫描、状态筛选、删除）与知识库详情页（目录管理、文档解析状态管理、批量操作、容量统计、知识库编辑与更新）的功能需求与交互规则

一、概述

1.1 背景说明

在使用 AI 智能体协作的过程中，用户的资料大多以本地文件夹形式散落在个人电脑中（工作周报、项目文档、研究资料、合同归档等）。这些文件无法被智能体直接理解和引用，导致每次任务都需要手动整理、反复上传，既低效又容易遗漏关键背景。需要一套「个人知识库」能力，让用户把本地文件夹一次性绑定进产品，由系统自动完成扫描、解析与向量化，沉淀为可持续复用、可挂载到会话中的私有知识资产。

1.2 需求描述

本期需要交付个人知识库的两个核心页面：

（1）知识库列表页：作为知识库的统一管理入口，用户可浏览全部知识库卡片，按名称/描述搜索、按处理状态筛选；支持「新建知识库」——填写名称、上传图标、绑定本地文件夹并填写描述后，系统对文件夹进行扫描并反馈扫描结果，创建后进入后台解析与向量化流程；支持删除知识库（仅删除索引数据，不删除本地原文件）。

（2）知识库详情页：作为单个知识库的管理工作台，左侧以目录树还原本地文件夹结构并支持目录管理（打开、重命名、新建子文件夹、删除），右侧以文件列表呈现每个文档的解析状态，支持文件名搜索、状态与类型筛选、排序、分页；支持单个或批量「添加到会话」「移动」「删除」操作；展示各类文件状态统计与知识库容量统计；支持编辑知识库基本信息与「立即更新」（增量同步本地文件夹变化）。

1.3 核心概念定义

概念定义
知识库由用户绑定的一个本地文件夹生成的私有知识集合，包含该文件夹下全部可解析文件及其索引数据，可挂载到会话供智能体引用。
绑定路径创建知识库时选定的本地文件夹绝对路径。绑定后不可修改；删除知识库不会删除原文件夹中的文件。
扫描新建知识库时对所选文件夹进行的文件发现过程，统计文件总数并识别其中暂不支持格式的文件数量。
解析系统读取文件内容并提取文本与元数据的过程，按解析模型执行；解析完成后进入索引环节。
向量化 / 索引将解析后的文本转换为向量并建立检索索引的过程，向量化模型默认使用企业统一配置。
失效知识库绑定的本地文件夹已不存在（被移动或删除）的状态；失效知识库卡片置灰，不可进入详情，仅可删除。
添加到会话将选中文件作为上下文引用材料发送到当前会话，供智能体在回答中直接使用。

1.4 目标用户与典型场景

用户角色典型场景核心诉求
职场办公人员 将「周报」文件夹绑定为知识库，后台自动解析完成后，在会话中引用历史周报生成新一周的工作总结 一次绑定、长期复用，不必每次手动上传
知识工作者 / 研究人员 将行业报告、论文、笔记所在文件夹建为知识库，按文件状态查看解析进度，把关键文献添加到会话做横向对比分析 解析进度透明、文件可精确筛选与引用
团队管理者 将项目文档库绑定后定期点击「立即更新」同步最新文件，通过容量统计了解知识库规模，对失败文件一键重新处理 数据可维护、异常可修复、规模可感知
个人用户 整理个人资料文件夹为多个知识库，通过搜索与状态筛选快速定位目标知识库，删除不再使用的知识库释放容量 管理简单、操作安全、不误删本地文件

二、功能架构与流程图

个人知识库由知识库列表页与知识库详情页两层构成：列表页负责「有哪些知识库、如何创建与删除」，详情页负责「单个知识库内有哪些文档、处于什么状态、如何管理与引用」。列表页卡片点击进入详情页，「去使用」将文件送入会话协作流程。

三、详细设计

本产品由两个页面组成：3.1 知识库列表页（知识库资产的管理入口）与3.2 知识库详情页（单个知识库的文档管理工作台）。

🔹 3.1 知识库列表页

页面概述

知识库列表页是全部个人知识库的统一入口。页面自上而下为：页头（标题 + 新建入口）、筛选区（搜索框 + 状态筛选）、知识库卡片网格。卡片承载知识库的核心信息与快捷操作，未创建任何知识库时展示空状态引导。

3.1.1 页头模块

数据来源：页面静态标题与当前用户的知识库操作入口。

字段类型必填说明
页面标题 文本 是 固定展示「个人知识库」，左侧配书本图标，位于页面顶部左侧
新建知识库按钮 操作 是 页头右侧常驻「+ 新建知识库」按钮；点击弹出「新建知识库」弹窗并重置表单；每次打开时图标预览随机使用系统预设的颜色（10 色池）与默认图标（12 枚 emoji 池）

3.1.2 筛选模块（搜索 + 状态筛选）

数据来源：知识库列表数据，按条件在前端实时过滤。

字段类型必填说明
搜索框 文本输入 否 占位提示「搜索知识库...」；输入即时触发列表过滤（无需回车），匹配规则：知识库名称或描述模糊包含关键词（不区分大小写）；与状态筛选为「且」关系叠加；清空后恢复全部
状态筛选 单选按钮组 是 选项：全部状态（默认选中）/ 待处理 / 处理中 / 已完成 / 已失效；点击切换选中态（高亮描边样式）并立即刷新列表；
筛选规则：「处理中」同时命中状态为「处理中」与「待处理」的知识库，其余按状态精确匹配

3.1.3 知识库卡片模块

数据来源：知识库列表数据（名称、图标、状态、路径、文件数、创建/更新时间等）。

字段类型必填说明
图标 图片/emoji 是 48×48 圆角方块展示；若上传过自定义图片则显示图片，否则显示 emoji 图标并铺满图标底色；底色为创建时分配的颜色，未指定时默认 #4F46E5
名称 文本 是 单行展示，超宽省略号截断；展示时进行安全转义
状态徽标 枚举 是 展示于名称右侧；枚举与样式：待处理（紫色）/ 处理中（蓝色，带呼吸闪烁圆点动画）/ 已完成（绿色，带 ✓ 前缀）/ 已失效（红色，带 ✕ 前缀）
归属信息 文本 是 固定展示「OmniX @ 本地文件夹」，说明知识库的来源类型
描述 文本 否 最多展示 2 行，超出省略截断；未填写描述时展示系统生成的默认描述「基于 {路径末两级} 创建的知识库」
绑定路径标签 文本标签 是 以浅灰标签样式展示完整本地文件夹路径；
正常知识库：hover 提示「点击打开路径」，点击 Toast 提示「正在打开路径: {路径}」；
已失效知识库：标签旁追加红色警示图标与「文件夹不存在」文案，点击提示「文件夹不存在，无法打开」
文件数 数字 是 展示「{N} 个文件」，N 为扫描统计的文件总数
创建时间 时间 是 格式「YYYY-MM-DD HH:mm」；待处理状态的知识库展示创建时间，其余状态亦固定展示创建时间
更新时间 时间 是 格式同上；创建后与创建时间一致，随后续更新变化
删除按钮 操作 是 卡片右上角悬浮显示（hover 卡片时出现）；hover 时变为红色警示样式；点击弹出删除确认弹窗，不触发卡片整体点击
去使用按钮 操作 否 卡片底部右侧，hover 卡片时出现；仅正常状态展示（已失效不展示）；点击跳转至会话使用该知识库
卡片整体点击 操作 是 点击卡片进入该知识库详情页；已失效知识库点击无响应（不可进入详情）；hover 时卡片上浮并显示边框高亮与阴影；已失效卡片整体透明度降低为 60%

3.1.4 空状态模块

数据来源：筛选后的列表数据（为空时展示）。

字段类型必填说明
空状态插画区 静态 是 圆形浅紫底 + 知识库线性图标居中展示
标题 文本 是 固定文案「还没有知识库」
引导文案 文本 是 固定文案「点击右上角“新建知识库”，绑定一个本地文件夹开始使用吧。」
创建按钮 操作 是 「创建第一个知识库」按钮，点击打开新建知识库弹窗
💡 空状态同时覆盖「从未创建知识库」与「搜索/筛选后无匹配结果」两种情况，共用同一套展示。

3.1.5 新建知识库弹窗（含扫描流程）

数据来源：用户表单输入 + 系统对所选文件夹的扫描结果。

字段类型必填说明
格式提示条 静态 是 弹窗顶部黄色提示条「支持的文件格式」：Markdown · 文本文件 · PDF · Word · Excel · PPT · 图片
名称 文本输入 是 占位「请输入知识库名称，最多50个字符」；前端限制最大输入长度 50；提交为空时 Toast 提示「请输入知识库名称」并阻止提交
图标 图片上传 否 默认展示系统随机分配的颜色 + emoji 图标，点击可上传自定义图标；
格式限制：JPG、PNG、GIF；大小限制：不超过 1MB，超出时 Toast 报错「图片大小不能超过 1MB」；建议尺寸 128×128px；上传成功后立即预览
选择路径 文件夹选择 是 只读输入框 + 「选择文件夹」按钮；点击按钮唤起系统文件夹选择器，选中后回填路径并 Toast 提示「已选择文件夹路径」；路径绑定后不可修改；未选择时提交 Toast 提示「请选择文件夹路径」并阻止提交
路径提示 静态 是 输入框下方盾牌图标 + 文案「仅支持本地文件夹，绑定后不可修改」
描述 多行文本 否 占位「简单描述这个知识库的用途...」；最大输入长度 200；为空时系统自动生成默认描述
取消按钮 操作 是 关闭弹窗，不保留已填内容（下次打开重新初始化）
开始扫描按钮 操作 是 提交入口；校验通过后关闭弹窗、开启全屏扫描遮罩；扫描期间进度条从 0% 递增至 100%，副标题按阶段切换文案（正在分析文件结构 → 正在解析文件内容 → 正在提取关键词与元数据 → 即将完成），并实时显示「已发现 N 个文件」；扫描完成后弹出扫描结果弹窗
扫描结果弹窗 弹窗 是 绿色成功图标 + 标题「扫描完成 / 知识库创建成功！」；
统计行 1：「共扫描到 {N} 个文件」；
统计行 2（仅存在不支持文件时显示）：「其中 {M} 个文件格式暂不支持」；
说明文案：知识库当前状态为「处理中」，系统正在后台解析和向量化文件，完成后将自动变为“已完成”；
底部「点击查看」按钮：关闭弹窗并跳转至知识库详情页
创建成功反馈 状态反馈 是 扫描完成后，新知识库卡片立即插入列表顶部（状态=处理中，创建/更新时间为当前时间），并 Toast 提示「知识库"{名称}"创建成功」
💡 扫描过程与扫描结果中的文件数量均由扫描服务返回；「开始扫描」为唯一提交按钮，未通过校验时不开启扫描。

3.1.6 删除确认模块

数据来源：待删除知识库信息 + 用户确认动作。

字段类型必填说明
确认标题 静态 是 红色垃圾桶图标 + 标题「确认删除知识库？」
说明文案 静态 是 「此操作将删除知识库 {知识库名称} 及其所有索引数据。」；下方红色加粗警示「原文件夹中的文件不会被删除。」
取消按钮 操作 是 关闭弹窗，不执行删除
确认删除按钮 操作 是 红色主按钮；点击后从列表中移除该知识库并刷新卡片，Toast 提示「已删除知识库"{名称}"」，关闭弹窗

3.1.7 全局交互与提示模块

数据来源：各操作触发的系统反馈。

字段类型必填说明
Toast 提示 轻提示 是 页面右上角弹出，3 秒后自动消失并滑出；按类型区分样式与图标：成功（绿色对勾）/ 错误（红色叉）/ 警告（黄色叹号）/ 信息（蓝色叹号）；多条堆叠展示
弹窗关闭规则 交互 是 新建弹窗、扫描结果弹窗、删除弹窗均支持：点击遮罩关闭、按 Esc 键关闭；扫描遮罩亦支持 Esc 关闭

🔹 3.2 知识库详情页

页面概述

知识库详情页是单个知识库的管理工作台，自上而下为：顶部返回导航、知识库信息头（图标、名称、编辑、状态、路径、更新时间、立即更新）、内容页签（当前仅「文档」）、主工作区（左目录树 + 右文档列表）。文档列表由统计栏、筛选栏、文件表格、分页栏构成，支持单文件与批量操作。

3.2.1 顶部导航模块

数据来源：页面固定导航配置。

字段类型必填说明
返回导航 操作 是 左侧「← 知识库」返回链接，点击返回知识库列表页

3.2.2 知识库信息头模块

数据来源：当前知识库的基本信息（名称、图标、状态、路径、更新时间、描述）。

字段类型必填说明
知识库图标 图片 是 72×72 圆角大图标，展示知识库图标
名称 文本 是 大号加粗展示知识库名称，随编辑保存实时更新
编辑按钮 操作 是 名称右侧铅笔图标按钮（hover 高亮）；点击打开「编辑知识库」弹窗
状态徽标 枚举 是 名称右侧展示当前处理状态（带状态圆点）
绑定路径 文本 是 文件夹图标 + 完整本地路径展示，只读不可改
更新时间 时间 是 展示「更新于：YYYY-MM-DD HH:mm」；「立即更新」成功后刷新为当前时间
立即更新按钮 操作 是 更新时间右侧紫色胶囊按钮；点击后进入加载态（图标旋转 + 文案「更新中…」），加载期间禁止重复点击；完成后刷新更新时间并 Toast 提示「知识库已更新」，按钮恢复初始态
描述 文本 否 信息头底部展示知识库描述，随编辑保存实时更新

3.2.3 内容页签模块

数据来源：页面固定配置。

字段类型必填说明
「文档」页签 页签 是 默认选中，展示目录树 + 文档列表主工作区

3.2.4 目录树模块

数据来源：知识库绑定文件夹内的目录结构（含各级子文件夹）。

字段类型必填说明
模块标题 静态 是 「目录」标题 + 右侧功能图标（菜单示意）
目录搜索框 文本输入 否 占位「目录名称」，支持按名称查找目录节点
树节点 树形列表 是 按文件夹层级缩进展示（最多支持多级缩进样式）；节点构成：展开/收起箭头 + 文件夹图标 + 文件夹名称 + 文件数量（如「12」）；根节点默认为「知识库文件夹」；
点击节点：选中（高亮背景）并切换其子级展开/收起状态，箭头方向随之切换
节点菜单（更多） 下拉菜单 是 hover 节点时出现「⋮」更多按钮，点击展开菜单；菜单项：
① 打开文件夹：打开该目录对应的本地文件夹；
② 重命名：名称变为行内输入框（自动聚焦并全选）；输入为空时回退为原名或「未命名文件夹」；Enter 或失焦提交，Esc 取消；
③ 新建子文件夹：在该节点下创建新子节点并自动展开父级，新节点直接进入行内命名状态；
④ 删除：删除该目录（红色警示样式）；
同一时刻仅一个菜单展开；点击页面其它区域自动收起全部菜单

3.2.5 工具栏与统计模块

数据来源：知识库内全部文件的状态与容量统计数据。

字段类型必填说明
状态统计卡片 统计组 是 横排 6 张统计卡：待解析（紫）/ 解析中（蓝）/ 索引中（天蓝）/ 已完成（绿）/ 暂不支持（灰）/ 处理失败（红）；每张卡片展示该状态文件数量与状态名；hover 轻微上浮；数量随文件数据实时计算
容量入口 操作 是 展示「知识库使用容量：{容量值} 📊」，hover 高亮并提示「查看容量详情」；点击打开容量统计弹窗
重新处理按钮 操作 否 红色描边按钮，仅当存在「处理失败」文件时显示；点击弹出确认框「确定要重新处理 {N} 个处理失败的文件吗？」；确认后全部失败文件状态重置为「待解析」并清除失败原因，Toast 提示「已将 {N} 个文件标记为待解析」；若无失败文件时点击则提示「没有需要重新处理的文件」

3.2.6 文档筛选模块

数据来源：知识库内文件数据，前端实时过滤。

字段类型必填说明
文件名搜索 文本输入 否 占位「文件名」；输入即时按文件名模糊过滤（不区分大小写），与状态、类型筛选叠加（且关系）
文档状态筛选 下拉单选 否 默认「文档状态」（全部）；选项：待解析 / 解析中 / 索引中 / 已完成 / 处理失败 / 暂不支持
文件类型筛选 下拉单选 否 默认「文件类型」（全部）；选项与类型映射：Markdown / 文本文件 / PDF / Word / Excel / PPT / 图片

3.2.7 批量选择模块

数据来源：文件表格行选中状态。

字段类型必填说明
行复选框 复选 是 每行首列复选框，勾选后计入已选集合；跨筛选、排序保持已选状态；表头全选复选框支持半选态：全部勾选显示勾选，部分勾选显示横线半选，未选显示空
批量操作栏 操作组 是 选中数量 > 0 时在筛选栏右侧展示：「已选择 {N} 个文件」+ 操作按钮组：
① 添加到会话：将选中文件加入会话引用，Toast 提示「已将 {N} 个文件添加到会话」并跳转会话页，随后清空选择；
② 批量移动：打开移动弹窗；
③ 批量删除：弹出确认框「确定要删除选中的 {N} 个文件吗？删除后本地文件被同步删除，不可恢复。」；确认后移除文件、清空选择并 Toast 提示；
④ 取消选择：文字按钮，清空全部已选
⚠️ 批量删除与单个删除的本地文件将被同步删除且不可恢复，确认弹窗文案必须保留该警示。

3.2.8 文档列表模块（表格）

数据来源：知识库内文件数据（文件名、大小、状态、时间、修改人、类型等）。

字段类型必填说明
选择列 复选框 是 表头为全选复选框（含半选态），见批量选择模块
文件名称 文本 是 文件图标 + 文件名；文件名下可附一行小字展示所属目录（移动后展示）；hover 文件名显示气泡提示「点击打开本地文件」；hover 时文件名变为主题色
文档大小 文本 是 如「39.45KB」；容量统计按该值累计，按 KB/MB 自动换算展示
文档状态 枚举 是 状态圆点 + 文字，颜色区分：待解析（紫）/ 解析中（蓝）/ 索引中（天蓝）/ 已完成（绿）/ 暂不支持（灰）/ 处理失败（红）；
「处理失败」状态额外展示红色圆形警示图标：hover 展示气泡「处理失败：{失败原因}，点击重新处理」，点击将该文件重置为「待解析」并清除原因
更新时间 时间 是 格式「YYYY-MM-DD HH:mm」
修改人 文本 是 该文件最后修改人
排序 操作 是 文件名称、文档大小、文档状态、更新时间、修改人五列表头可点击排序：首点升序、再点切换降序；当前排序列高亮箭头（▼ 升序 / ▲ 降序）；状态列按预设处理顺序（待解析→解析中→索引中→已完成→暂不支持→处理失败）排序；大小按数值、时间与文本按中文字序比较
更多操作菜单 下拉菜单 是 操作列「更多」展开菜单，菜单项：
① 重新处理（仅处理失败文件显示，红色）：重置为待解析；
② 复制路径：复制「{所属目录/}文件名」到剪贴板，Toast 提示「已复制路径：{路径}」；
③ 文件管理器中打开：在系统文件管理器中定位该文件，Toast 提示「已在文件管理器中打开：{路径}」；
④ 添加到会话：单个文件加入会话并跳转，Toast 提示「已将「{文件名}」添加到会话」；
⑤ 分隔线；
⑥ 移动：打开移动弹窗；
⑦ 删除（红色）：确认后删除该文件；
同一时刻仅一个菜单展开，点击其它区域自动收起
分页栏 分页 是 左侧展示「共 {N} 项，每页显示 15 项」（每页固定 15 条）；右侧展示上/下翻页按钮、页码与「跳至 [ ] 页」快捷输入

3.2.9 移动弹窗模块

数据来源：知识库目录树中的文件夹列表。

字段类型必填说明
标题 静态 是 「移动到」
目标文件夹列表 单选列表 是 按目录树层级缩进展示全部可选文件夹；点击选中（高亮样式）；未选择时点击「确定」Toast 提示「请选择目标文件夹」并留在弹窗
取消按钮 操作 是 关闭弹窗，不执行移动
确定按钮 操作 是 执行移动：文件名下方展示所属目录；单个移动 Toast 提示「已移动「{文件名}」到「{文件夹}」」；批量移动 Toast 提示「已移动 {N} 个文件到「{文件夹}」」；完成后刷新列表并清空选择

3.2.10 容量统计弹窗模块

数据来源：知识库内全部文件的类型、数量与大小统计。

字段类型必填说明
容量总览区 统计横幅 是 渐变横幅展示：标签「知识库总容量」+ 总容量值（KB < 1024 显示 KB，否则显示 MB，保留两位小数）+「共 {N} 个文件」
容量占比条 占比条 否 有文件时展示横向堆叠占比条：按 7 种文件类型（Markdown/文本文件/PDF/Word/Excel/PPT/图片）的容量占比分段着色，每段有类型对应颜色；标题行右侧展示「{X} 种文件类型」；hover 分段显示类型与百分比
类型统计卡片 统计卡组 是 双列卡片网格，覆盖全部 7 种类型（无文件的类型显示 0 个）：每卡展示类型图标与名称、文件数量、容量值及占比百分比、容量占比进度条；卡片底部按占比填充类型色条

3.2.11 编辑知识库弹窗模块

数据来源：当前知识库基本信息 + 用户修改输入。

字段类型必填说明
格式提示条 静态 是 黄色警示条「支持的文件格式：Markdown · 文本文件 · PDF · Word · Excel · PPT · 图片」
名称 文本输入 是 回显当前名称，最大长度 50；保存为空时回退默认值「个人知识库」
图标 图片上传 否 回显当前图标；提示文案与限制同新建：JPG、PNG、GIF，不超过 1MB，建议 128×128px
知识库路径 只读文本 是 展示绑定路径，输入框禁用态（灰底）；下方提示「仅支持本地文件夹，绑定后不可修改」
描述 多行文本 否 回显当前描述；占位「简单描述这个知识库的用途...」
取消按钮 操作 是 关闭弹窗，不保存修改
确定按钮 操作 是 保存修改：名称与描述立即同步至信息头展示；关闭弹窗

3.2.12 通用确认弹窗模块

数据来源：触发确认的操作（删除、批量删除、重新处理等）。

字段类型必填说明
标题与正文 静态 是 按触发操作展示对应标题（如「删除文件」「批量删除」「重新处理」）与确认文案
取消按钮 操作 是 关闭弹窗，不执行操作
确定按钮 操作 是 红色主按钮，执行对应操作并关闭弹窗
💡 删除类操作（单个删除、批量删除）与重新处理操作均复用该确认弹窗；删除操作确认文案必须包含「删除后本地文件被同步删除，不可恢复」。

3.2.13 全局反馈模块

数据来源：详情页各操作的系统反馈。

字段类型必填说明
Toast 提示 轻提示 是 页面底部居中深色气泡，2.4 秒自动消失；重复触发时重置计时器并刷新文案
弹窗关闭规则 交互 是 编辑、移动、容量统计、确认弹窗均支持点击遮罩关闭；下拉菜单点击页面其它区域自动收起
