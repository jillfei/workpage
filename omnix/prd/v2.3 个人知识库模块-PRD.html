OmniX 个人知识库模块

本地文件夹绑定 · 自动扫描解析 · 向量化索引 · 会话知识挂载 —— 产品需求文档 v1.0

文档版本修改日期修改人修改说明
v1.0 2026-10-14 产品团队 初稿，覆盖个人知识库模块的知识库列表页（搜索筛选、卡片列表、新建知识库、扫描进度与结果、删除确认）与知识库详情页（基本信息与编辑、目录树、文档状态统计、容量统计、文件筛选排序、单文件与批量操作、移动、重新处理）的完整需求定义

一、概述

1.1 背景说明

用户在日常工作中积累了大量分散于本地文件夹的文档资料（设计规范、技术文档、研究报告、合同归档等）。在与 AI 智能体协作时，这些本地资料无法被直接引用，用户只能反复手动粘贴内容或逐个上传附件，导致：知识无法沉淀复用、智能体缺少专业背景上下文、首轮产出质量低。

个人知识库模块旨在让用户将本地文件夹一键绑定为知识库，由系统自动完成扫描、解析与向量化索引，使本地资料成为可随时挂载到会话中的持久化知识资产，同时提供文档级的状态跟踪、目录管理、容量统计与失败重试等完整的运维能力。

1.2 需求描述

本期需求包含两个页面：

页面需求范围
知识库列表页 以卡片形式展示用户的全部知识库；支持关键词搜索与状态筛选；支持新建知识库（绑定本地文件夹，触发扫描并展示扫描进度与结果）；支持删除知识库（仅删除索引数据，不删除本地文件）；支持从卡片一键跳转会话页使用知识库；失效知识库（源文件夹不存在）置灰并明确提示
知识库详情页 展示知识库基本信息（名称、图标、状态、路径、更新时间、描述）并支持编辑与立即更新；左侧目录树支持展开折叠、选中、重命名、新建子文件夹；右侧文档区提供六种处理状态的统计卡片、容量统计弹窗、文件名搜索、状态与类型筛选、列排序；文件支持单个与批量的移动到会话、移动目录、删除、复制路径、文件管理器打开；处理失败文件支持查看失败原因并单个或全量重新处理；分页信息展示

1.3 核心概念定义

概念定义
知识库用户绑定的一个本地文件夹及其在系统中生成的索引数据集合。知识库与源文件夹一一绑定，绑定后路径不可修改；删除知识库仅删除索引数据，不影响源文件夹内的文件。
知识库状态知识库整体的处理状态，共四种：待处理（已创建、排队等待扫描解析）、处理中（正在解析与向量化）、已完成（全部处理完毕、可正常使用）、已失效（源文件夹被移动或删除，知识库不可用）。
文档状态知识库内单个文件的处理状态，共六种：待解析（排队中）、解析中（正在提取正文内容）、索引中（正在向量化建立索引）、已完成（可被检索引用）、处理失败（解析异常，附失败原因，可重新处理）、暂不支持（文件格式超出支持范围）。
支持的文件格式Markdown、文本文件、PDF、Word、Excel、PPT、图片七类。扫描时不属于上述范围的文件被计入"暂不支持"。
目录树知识库详情页左侧对源文件夹目录结构的树状映射，节点为文件夹，显示各文件夹下的文档数量，支持层级展开折叠与管理操作。
添加到会话将选中的一个或多个文档作为知识上下文挂载到智能体会话中的操作，完成后跳转至会话页面。
知识库容量知识库内全部文档占用的存储总量，可按七种文件类型统计数量、大小与占比。

1.4 目标用户与典型场景

用户角色典型场景核心诉求
知识工作者 / 个人创作者 把积累多年的笔记、资料文件夹绑定为知识库，在与智能体对话时直接引用，无需重复上传 一次绑定长期可用、引用方便
产品 / 研发人员 将需求文档、技术文档目录绑定为知识库，让智能体基于团队沉淀的专业资料产出方案 资料结构化、状态可跟踪
资料量大的重度用户 单知识库数百个文件，需要关注解析进度、失败文件与容量占用，及时处理异常文档 失败可见可重试、容量可统计
多项目用户 按项目建立多个知识库，通过搜索与状态筛选快速定位，跨目录整理文档 多库管理清晰、检索高效
作为新用户，我希望选择一个本地文件夹就能创建知识库并实时看到扫描进度，以便直观确认系统识别了哪些文件、有多少格式不支持。
作为重度用户，我希望在详情页看到每种文档状态的数量统计，并对处理失败的文件一键重新处理，以便快速定位异常文档、不必逐个排查。
作为注重数据安全的用户，我希望删除知识库时明确告知"原文件夹中的文件不会被删除"、删除文档时明确告知"本地文件被同步删除"，以便清楚每次删除操作的真实影响范围，避免误删。

二、功能架构与流程图

个人知识库模块由知识库列表页与知识库详情页两级页面构成：列表页负责知识库的"建、查、删、用"，详情页负责单个知识库内文档的"看、筛、管、修"。底层由文件夹扫描、文档解析、向量索引三项服务支撑，最终通过"添加到会话"与智能体协作链路衔接。

2.1 系统架构图

💡 架构原则：列表页管"库"，详情页管"文档"。知识库状态（待处理/处理中/已完成/已失效）刻画库级生命周期，文档状态（待解析/解析中/索引中/已完成/处理失败/暂不支持）刻画文件级生命周期，两级状态相互独立、各自可筛选。

三、详细设计

本章按页面 → 模块两级展开。每个模块先以一句话说明数据来源（含数据的模块），再以字段表定义显示规则、来源、边界与交互效果。

🔹 3.1 知识库列表页

知识库列表页是个人知识库模块的入口页，自上而下由页头、筛选行、卡片网格构成；新建、扫描、删除等流程以弹窗 / 浮层形式叠加在页面之上。

3.1.1 页头模块

页面顶部通栏，左侧为模块标识与页面标题，右侧为新建入口。底部有分隔线与内容区隔开。

字段类型必填说明
模块图标图标—32×32 圆角灰底容器内展示知识库（书本）线性图标，仅作视觉标识，不可交互
页面标题文本—固定文案"个人知识库"，18px 加粗
新建知识库按钮按钮—白底描边按钮，含"+"图标与文案"新建知识库"；悬停背景变灰；点击打开「新建知识库」弹窗（见 3.1.5）
3.1.2 搜索与状态筛选模块
数据来源：筛选条件作用于当前用户的全部知识库记录，筛选结果实时驱动卡片列表刷新。
字段类型必填说明
搜索关键词文本输入否占位符"搜索知识库..."，左侧放大镜图标；输入即时触发过滤（无需回车），按知识库名称与描述做不区分大小写的模糊匹配；清空后恢复全量展示
状态筛选枚举按钮组否五个互斥选项：全部状态（默认选中）/ 待处理 / 处理中 / 已完成 / 已失效；选中项高亮（主色文字 + 浅色底 + 描边）；选择"处理中"时同时命中"待处理"与"处理中"两种状态的知识库（两者同属未完成处理阶段）；与搜索条件叠加生效（AND 关系）
空结果处理展示规则—筛选后无匹配记录时，卡片区展示空态（见 3.1.4）
3.1.3 知识库卡片列表模块
数据来源：当前用户已创建的知识库列表，按更新时间倒序排列；新建成功的知识库插入列表首位。

两列网格布局。卡片整体可点击进入详情页（已失效除外）；悬停时卡片上浮并出现右上角删除按钮与右下角"去使用"按钮。

字段类型必填说明
知识库图标图片/图标是48×48 圆角方块；用户上传图片时展示图片（等比裁切铺满），未上传时展示系统默认表情图标，背景色从预设色板中随机分配；创建后固定不变
名称文本是15.5px 加粗，单行显示，超长省略号截断
状态徽标枚举徽标是名称右侧胶囊徽标，四种状态四种样式：待处理（紫色文字/浅紫底）、处理中（蓝色文字/浅蓝底，前置呼吸闪烁圆点动画）、已完成（绿色文字/浅绿底，前置"✓"）、已失效（红色文字/浅红底，前置"✕"）
归属信息文本是名称下方元信息行，含用户图标，固定展示"OmniX @ 本地文件夹"（创建者 @ 知识库类型）
描述文本否最多两行，超出省略号截断；用户未填写时系统生成默认文案"基于 …（路径末两级）… 创建的知识库"
路径标签可点击标签是灰底描边标签，含文件夹图标与完整绑定路径；点击不冒泡到卡片：正常状态调用系统能力打开该本地文件夹路径；已失效状态点击弹出错误 Toast"文件夹不存在，无法打开"，悬浮提示"文件夹不存在"
失效警示展示规则—仅已失效知识库显示：路径标签旁追加红色警示图标与文案"文件夹不存在"；同时整卡透明度降为 60%，卡片点击进入详情页的行为被禁用
文件数数值是底部统计区，文档图标 + "N 个文件"；为扫描时统计的入库文件总数，已失效知识库显示 0
创建时间日期时间是底部统计区，格式 YYYY-MM-DD HH:mm
更新时间日期时间是底部统计区，格式 YYYY-MM-DD HH:mm；新建时为创建时间，后续随内容更新变化，并作为列表默认排序依据（新→旧）
删除按钮图标按钮—卡片右上角，默认隐藏，卡片悬停时淡入；悬停按钮变为红色警示样式；点击不冒泡，打开删除确认弹窗（见 3.1.8）；已失效知识库同样保留此按钮（失效库唯一可用操作）
去使用按钮按钮—卡片底部右侧深色按钮，默认隐藏，卡片悬停时淡入；点击不冒泡，跳转至会话页面（通过父窗口导航消息机制，独立打开时直接跳转）；已失效知识库不显示此按钮
3.1.4 空状态模块

当筛选结果为空时占满整个卡片区域居中展示。

字段类型必填说明
空态插图图标—88×88 圆形浅色底容器 + 知识库线性图标
标题 / 描述文本—标题"还没有知识库"；描述"点击右上角'新建知识库'，绑定一个本地文件夹开始使用吧。"
创建按钮按钮—文案"创建第一个知识库"，含"+"图标；点击直接打开新建知识库弹窗
3.1.5 新建知识库弹窗（表单）

800px 居中模态弹窗，入场缩放动画；点击右上角关闭、取消按钮、遮罩空白处或按 ESC 均可关闭，关闭后表单不保留草稿。

字段类型必填说明
格式提示条静态提示—弹窗顶部黄色信息条，标题"支持的文件格式"，内容"Markdown · 文本文件 · PDF · Word · Excel · PPT · 图片"
名称文本输入是占位符"请输入知识库名称，最多50个字符"；最大长度 50 字符（输入框硬限制）；为空时点击提交弹出错误 Toast"请输入知识库名称"并阻止提交
图标图片上传否打开弹窗时系统自动从预设色板随机分配背景色、从预设图标池随机分配默认表情图标；点击 44×44 预览块唤起本地文件选择器，仅接受 JPG / JPEG / PNG / GIF；文件大小上限 1MB，超限弹出错误 Toast"图片大小不能超过 1MB"且不替换原图标；上传成功后预览块内展示图片；辅助文案说明格式、大小与建议尺寸（128×128px）
选择路径路径选择是只读输入框 + "选择文件夹"按钮；点击按钮唤起系统文件夹选择器，选定后回填完整路径并弹出成功 Toast；为空时提交弹出错误 Toast"请选择文件夹路径"；下方提示"仅支持本地文件夹，绑定后不可修改"
描述多行文本否占位符"简单描述这个知识库的用途..."；最大长度 200 字符；留空时系统按路径自动生成默认描述
底部操作按钮组—「取消」（关闭弹窗）与「开始扫描」（校验通过后关闭弹窗并启动扫描流程，见 3.1.6）
3.1.6 扫描进度浮层
数据来源：对所绑定本地文件夹的实时扫描任务，文件计数随扫描进度递增。

全屏白色半透明磨砂遮罩 + 居中进度面板，扫描期间覆盖页面，按 ESC 可关闭浮层。

字段类型必填说明
加载动画动效—64×64 旋转加载图标，持续循环
标题文本—固定文案"正在扫描文件夹..."
阶段副标题文本—随进度分段切换：0–30%"正在分析文件结构，请稍候"→ 30–60%"正在解析文件内容..." → 60–85%"正在提取关键词与元数据..." → 85%以上"即将完成..."
进度条进度指示—渐变填充（主色→紫色），平滑过渡；达到 100% 后浮层自动关闭并弹出扫描结果弹窗
文件计数文本—"已发现 N 个文件"，N 随进度实时递增，扫描结束即为入库文件总数
3.1.7 扫描结果弹窗
数据来源：本次扫描任务的统计结果（文件总数、不支持格式文件数）。
字段类型必填说明
结果图标与标题展示—绿色圆形成功图标 + 标题"知识库创建成功！"
扫描文件总数数值是统计行"📄 共扫描到 N 个文件"，N 为主色加粗数字
不支持文件数数值否统计行"⚠️ 其中 N 个文件格式暂不支持"，N 为橙色加粗；仅当不支持数 > 0 时显示该行，否则整行隐藏
状态说明文本—固定说明：知识库当前状态为"处理中"，系统正在后台解析和向量化文件，完成后自动变为"已完成"
点击查看按钮按钮—底部主按钮；点击关闭弹窗并跳转知识库详情页；同时新知识库以"处理中"状态插入列表首位，并弹出成功 Toast"知识库"XX"创建成功"
3.1.8 删除确认弹窗
字段类型必填说明
警示图标与标题展示—400px 窄弹窗；红色圆形垃圾桶图标 + 标题"确认删除知识库？"
知识库名称文本是正文中以内联灰底标签展示待删除知识库名称，防止误删
影响说明文本—说明"此操作将删除知识库及其所有索引数据"，并以红色加粗强调"原文件夹中的文件不会被删除"
操作按钮按钮组—「取消」关闭弹窗不做任何操作；「确认删除」红色危险按钮，点击后从列表移除该知识库、关闭弹窗并弹出成功 Toast"已删除知识库"XX""
3.1.9 全局 Toast 提示
字段类型必填说明
Toast 消息轻提示—屏幕右上角堆叠展示，左侧彩色竖条区分类型：成功（绿）/ 错误（红）/ 警告（橙）/ 信息（蓝），带类型图标；右滑入动画，3 秒后自动淡出移除；最大宽度 360px

🔹 3.2 知识库详情页

详情页自上而下为返回导航、知识库信息头部、主工作区（左侧目录树 + 右侧文档管理区）；编辑、移动、容量、确认等操作以弹窗承载。

3.2.1 返回导航模块
字段类型必填说明
返回入口链接—页面顶部通栏（底部描边分隔），左向箭头图标 + 文案"知识库"；点击返回知识库列表页；悬停颜色加深
3.2.2 知识库信息头部模块
数据来源：当前进入的知识库档案信息（名称、图标、状态、绑定路径、更新时间、描述）。
字段类型必填说明
知识库图标图片是72×72 圆角方块，紫色渐变底 + 图标（或用户上传的自定义图片）
名称文本是20px 加粗展示；在编辑弹窗保存后即时刷新
编辑按钮图标按钮—名称右侧铅笔图标小方按钮，悬停变主色；点击打开「编辑知识库」弹窗（见 3.2.10）
状态徽标枚举徽标是名称行右侧胶囊徽标（圆点 + 状态文案），当前展示"已完成"绿色样式；与列表页知识库状态枚举一致
绑定路径文本是元信息行第一项，文件夹图标 + 完整本地路径；只读展示，不可修改
更新时间日期时间是元信息行第二项，时钟图标 + "更新于：YYYY-MM-DD HH:mm"
立即更新按钮按钮—更新时间右侧胶囊小按钮（刷新图标 + "立即更新"）；点击后进入加载态：图标旋转、文案变"更新中…"、置灰且不可重复点击；完成后刷新"更新于"为当前时间、恢复按钮并弹出 Toast"知识库已更新"；用于手动触发与源文件夹的增量同步
描述文本否头部底部灰色多行文本；在编辑弹窗保存后即时刷新
3.2.3 目录树模块（左侧栏）
数据来源：知识库绑定的本地文件夹的目录结构，各节点计数为该文件夹（含子级）下的文档数量。

260px 固定宽度侧栏，顶部标题"目录"，下方为多级树形结构；树节点支持展开折叠、选中、行内重命名与新建子文件夹。

字段类型必填说明
树节点名称文本是文件夹图标 + 名称；层级通过左侧缩进递增表达（每级 +16px）；点击节点选中（浅紫底高亮，全树唯一选中态）
文档计数数值是节点名称右侧灰色数字，表示该文件夹下文档数量；新建子文件夹初始为 0
展开/折叠箭头交互控件—有子级的节点显示箭头；点击节点行同时切换子级显隐，箭头方向随状态旋转（展开朝下 / 收起朝右）；叶子节点以等宽占位符对齐，无箭头
更多操作菜单下拉菜单—节点悬停时行尾淡入"⋯"图标，点击展开菜单（其余菜单自动收起，点击页面任意处全部收起）；菜单项：重命名、新建子文件夹；点击菜单项不触发节点选中
行内重命名输入框—触发"重命名"后节点名称原位变为输入框（主色描边 + 外发光），自动聚焦并全选原文本；Enter 或失焦提交，ESC 取消还原；提交值为空时回退为"未命名文件夹"；重命名为纯前端即时生效
新建子文件夹交互行为—在当前节点下插入新子节点（计数 0）并自动选中：若当前节点原为叶子节点，自动补出展开箭头并展开子级容器；新节点立即进入行内重命名态，输入框为空、占位符"未命名文件夹"
3.2.4 文档状态统计模块（工具栏左侧）
数据来源：当前知识库全部文档，按文档状态实时聚合计数，随文件列表变化（重新处理、删除等）即时刷新。
字段类型必填说明
状态统计卡片 ×6数值卡片是横向排列六张统计卡，每张含大号状态色数字 + 状态名标签，左侧彩色竖条区分：待解析（紫）/ 解析中（蓝）/ 索引中（天蓝）/ 已完成（绿）/ 暂不支持（灰）/ 处理失败（红）；悬停轻微上浮 + 投影；计数为 0 时仍显示卡片（数字为 0）
重新处理按钮按钮—工具栏右侧红色描边按钮（刷新图标 + "重新处理"）；仅当"处理失败"计数 > 0 时显示；点击弹出确认框（见 3.2.9），确认后将全部失败文档重置为"待解析"并清除失败原因，Toast 提示"已将 N 个文件标记为待解析"；无失败文件时点击 Toast"没有需要重新处理的文件"
3.2.5 容量入口与容量统计弹窗
数据来源：当前知识库全部文档的大小与类型信息，按七种文件类型实时聚合。
字段类型必填说明
容量入口文本按钮是工具栏右侧文本"知识库使用容量：XXX KB 📊"；悬停变灰底主色；点击打开容量统计弹窗（800px 宽）
总容量主视觉数值卡片是弹窗顶部紫色渐变大卡：标签"知识库总容量"、总大小（<1024KB 显示 KB，否则换算为 MB，保留两位小数）、副文案"共 N 个文件"、右侧文件夹图标
容量占比条分段进度条否仅当存在文件时显示：标题行"容量占比 | N 种文件类型"；下方分段色条按各类型大小占比分色填充（每段最短 4px），悬停段落显示"类型名 百分比"提示；占比 = 该类型总大小 / 全部文件总大小 ×100%，保留一位小数
类型明细卡片 ×7数值卡片组是两列网格，按固定顺序展示 Markdown / 文本文件 / PDF / Word / Excel / PPT / 图片七类（各配专属色图标字母 M/T/P/W/X/S/I）；每卡展示：类型名、文件个数（大号数字 + "个"）、"大小 · 占比%"、底部占比细进度条；无该类型文件时计数 0、占比 0.0% 仍显示卡片
3.2.6 文档筛选与批量操作模块
数据来源：筛选条件作用于当前知识库的文档列表，三个条件为 AND 叠加关系。
字段类型必填说明

批量操作条操作条—已选文件数 > 0 时在筛选行右侧淡入浅紫底操作条："已选择 N 个文件"（N 主色加粗）+ 四个操作：「添加到会话」「批量移动」「批量删除」「取消选择」；取消选择或操作完成后清零并隐藏

3.2.7 文档列表表格模块
数据来源：当前知识库经扫描入库的文档记录（名称、大小、状态、更新时间、修改人、类型、所属目录、失败原因），展示筛选后的结果集。
字段类型必填说明
勾选框（首列）复选框—行级勾选进入批量选择集；表头全选框作用于当前筛选结果：全选/全不选；部分选中时呈半选态（indeterminate）；翻页或筛选变化后选择集保留、全选态按当前结果重算

更新时间日期时间（可排序）是格式 YYYY-MM-DD HH:mm，按时间先后排序
修改人文本（可排序）是文档最后修改人姓名
操作列下拉菜单—"更多"文字入口，点击展开菜单（其余菜单自动收起，点击页面任意处收起）。菜单项自上而下：重新处理（红色加粗，仅"处理失败"文档显示，效果同警示图标点击）、复制路径（复制"目录/文件名"到剪贴板，Toast"已复制路径：…"）、文件管理器中打开（调用系统文件管理器定位该文件，Toast 提示）、添加到会话（单文档挂载到会话，Toast"已将「XX」添加到会话"后跳转会话页）、分隔线、移动（打开移动弹窗，单文档模式）、删除（红色危险项，打开确认弹窗"确定要删除「XX」吗？删除后本地文件被同步删除，不可恢复。"）
排序交互交互规则—文件名称 / 文档大小 / 文档状态 / 更新时间 / 修改人五列表头可点击排序；再次点击同列切换升/降序，切换列时重置为升序；当前排序列表头显示主色箭头（升序 ▼ / 降序 ▲），非当前列箭头置灰
分页信息栏文本 + 控件—表格底部：左侧"共 N 项，每页显示 15 项"（N 随筛选结果实时变化）；右侧为上一页 / 页码 / 下一页按钮与"跳至 X 页"输入框

序号规则说明

7会话挂载跳转"添加到会话"（单个或批量）成功后均跳转至会话页面，挂载的文档作为该次会话的知识上下文
