本地知识库模块

本地文件夹纳管 · 自动解析向量化 · 文档浏览管理 · 模型配置 —— 产品需求文档 v1.0

文档版本修改日期修改人修改说明
v1.0 2026-07-24 OmniX 产品组 初稿，包含背景目标、用户画像、用户故事、功能架构、子模块详细设计、关键交互流程、边界与异常情况

一、背景与目标

业务背景

在 OmniX 智能体平台中，用户的大量知识沉淀在本地电脑的各类文件中——产品设计资料、技术文档、行业研究报告、合同范本、工作周报等。这些文件格式多样、散落各处，智能体难以直接检索与引用，导致"用户明明有资料，Agent 却用不上"的尴尬。

当前缺少一个统一的入口，将本地文件夹低成本地转化为可被智能体检索引用的知识底座。用户要么手动逐份上传，要么放弃使用本地资料。因此，需要提供"本地知识库"能力：用户只需绑定一个本地文件夹，系统即可自动完成扫描、解析、向量化，形成结构清晰、状态可见、可被检索的知识源。

产品目标

低成本创建

绑定一个本地文件夹、填写名称即可创建知识库，无需逐文件上传。

状态透明

清晰展示知识库与文档的解析进度与状态，让用户随时知道哪些内容已就绪。

可整理可运维

提供目录树浏览、文档级移动 / 删除 / 重解析，便于知识库持续维护。

模型可配

兼顾企业统一策略与个人自定义，支持配置文档解析模型与向量化模型。

占用可见

提供容量统计，帮助用户了解知识库的空间占用分布。

安全可靠

删除知识库仅移除索引，不动本地原始文件；危险操作均二次确认。

成功指标（北极星与驱动）

指标类型指标名称口径与基线目标
北极星知识库活跃使用率近 30 天内有检索或更新行为的知识库占比，目标 ≥ 60%
驱动指标文件解析成功率已完成解析文件数 ÷ 已扫描文件数，目标 ≥ 95%
驱动指标知识库创建成功率成功创建并进入处理中的知识库数 ÷ 发起创建数，目标 ≥ 98%
健康指标解析失败重解析成功率重解析后转为"已完成"的文件数 ÷ 触发重解析数，目标 ≥ 90%
健康指标平均解析耗时单个文件从"待解析"到"已完成"的时长中位数，目标持续下降
非目标（Non-goals）
为避免范围蔓延，以下功能明确不在本期范围内：
1. 文件内容的在线编辑与多人协同编辑（本模块聚焦"纳管与检索就绪"，文件编辑在本地完成）；
2. 云端知识库托管与跨设备同步；
3. 多人协同权限管理与知识库共享；
4. 知识图谱能力（当前仅为占位入口，暂不实现）；
5. 替代文件系统管理——删除知识库不会删除本地原始文件。

二、用户画像

角色典型场景核心诉求
个人知识库使用者
（核心用户）		 将本地工作资料文件夹绑定为知识库，希望智能体能基于这些资料回答问题 创建成本低；能直观看到知识库是否就绪；能快速找到某个文档
知识库管理员 负责创建、维护、清理知识库，关注解析成功率与容量占用 能批量整理文档；能修复解析失败；能查看容量分布
企业平台管理员 统一配置企业默认的文档解析模型与向量化模型 保障解析质量与一致性；可允许个人覆盖默认模型

三、用户故事

作为个人使用者， 我希望选择一个本地文件夹并填写名称即可创建知识库， 以便让智能体快速拥有我的专属知识，而不必手动上传每个文件。
作为知识库使用者， 我希望在列表页一眼看到每个知识库的状态（待处理 / 处理中 / 已完成）和文件数量， 以便判断它是否已经可以被使用。
作为知识库使用者， 我希望在详情页按文件名、状态、类型筛选和排序文档， 以便从大量文件中快速定位到目标文档。
作为知识库管理员， 当某份文档解析失败时，我希望看到失败原因并一键重新解析， 以便快速修复问题，让文档尽快可用。
作为知识库管理员， 我希望批量选中多个文件进行移动或删除， 以便高效整理知识库结构，而不必一个个操作。
作为知识库管理员， 我希望通过左侧目录树浏览文件夹结构、重命名或新建子文件夹， 以便保持知识库目录清晰、符合我的整理习惯。
作为企业管理员， 我希望为知识库指定文档解析模型（企业默认或个人自定义）， 以便在统一质量与灵活个性化之间取得平衡。

四、功能架构

本地知识库模块整体由"列表与新建""详情与文档管理""模型配置""容量统计"四大块构成，并贯穿一条"创建 → 解析 → 就绪 → 使用 → 维护"的生命周期主线。

五、子模块详情

本地知识库模块包含四个子功能域：列表与新建（知识库的创建与统一管理入口）、详情与文档管理（单库内的文档浏览与运维）、模型配置（解析与向量化模型）、容量统计（空间占用分析）。以下分别说明。

🔹 5.1 列表与新建

功能描述

列表与新建是模块的统一入口。用户在此浏览所有已创建的知识库（以卡片网格呈现），按名称或描述搜索、按状态筛选、按更新或创建时间排序；通过卡片进入详情，或在悬停时执行删除。新建知识库以弹窗表单完成，填写名称、图标、本地文件夹路径与描述后提交，系统自动启动文件夹扫描与解析流程。

字段设计

字段类型必填说明
图标图标选择—知识库的视觉标识，可上传图片或选用内置图形；未上传时显示默认图标
名称文本✅知识库名称，最大 50 个字符，列表与详情中展示
本地路径文件夹路径✅绑定的本地文件夹路径；绑定后不可修改
描述文本域—知识库用途说明，最大 200 字符，列表中截断展示
类型枚举自动当前固定为"本地文件夹"
状态枚举自动待处理 / 处理中 / 已完成。新建后为"处理中"，解析完成自动变"已完成"
文件总数数字自动扫描到的文件数量，由系统统计
创建时间系统记录自动创建时间，自动记录，不可编辑
更新时间系统记录自动最近一次更新时间（含解析完成、立即更新等），自动记录，不可编辑

功能清单

序号功能名称优先级功能描述
1知识库列表查看P0卡片网格展示所有知识库，含图标、名称、状态、描述、路径、文件数、时间；支持按名称 + 描述搜索、按状态筛选（全部 / 待处理 / 处理中 / 已完成）、按更新时间或创建时间排序；卡片点击进入详情；悬停显示删除入口；列表为空时引导创建

序号规则说明
1名称长度限制名称最大 50 字符，超出无法输入
2描述长度限制描述最大 200 字符，超出无法输入；列表中截断为两行

🔹 5.2 详情与文档管理

功能描述

详情页是单个知识库的管理中枢。头部展示知识库概览信息（图标、名称、状态、路径、更新时间、描述），并提供编辑入口与"立即更新"能力。主体分为左侧目录树与右侧文档区：目录树按文件夹结构浏览并支持文件夹级操作；文档区以统计卡片、筛选、排序表格与批量操作管理全部文档，并提供容量统计与模型配置入口。

文档级字段设计

字段类型必填说明
文件名称文本系统文档在本地文件夹中的名称，点击可在本地打开
所属文件夹路径系统文档在目录树中的相对位置，可经"移动"变更
文档大小数字系统文件体积（KB / MB），支持排序
文档状态枚举系统待解析 / 解析中 / 已完成 / 暂不支持 / 解析失败
失败原因文本系统仅"解析失败"时记录，悬停可查看具体原因
更新时间系统记录系统文档最近一次解析或变更时间
修改人系统记录系统最近一次操作该文档的用户

功能清单

序号功能名称优先级功能描述
1概览信息与编辑P0头部展示图标、名称、状态、路径、更新时间、描述；提供编辑按钮（修改名称 / 图标 / 描述，路径只读）与"立即更新"按钮（重新触发扫描）
2标签页切换P0提供"文档"与"知识图谱"标签；"知识图谱"为占位入口，本期不实现
3目录树浏览P0左侧按文件夹结构展示，支持展开 / 折叠、显示每文件夹文件数、按名称搜索；文件夹"更多"菜单含：打开文件夹、重命名、新建子文件夹、删除
4状态统计卡片P0展示待解析 / 解析中 / 已完成 / 暂不支持 / 解析失败 五类文档数量；当存在解析失败文档时，显示"重新解析全部"按钮
5文档筛选与排序P0按文件名搜索；按文档状态（5 种）筛选；按文件类型（Markdown / 文本 / PDF / Word / Excel / PPT / 图片）筛选；按文件名称、大小、状态、更新时间、修改人排序
6文档表格与分页P0表格列含复选框、文件名（点击打开本地文件，悬停提示）、大小、状态（失败带原因提示）、更新时间、修改人、操作；每页 15 项，支持分页跳转
7单条文档操作P0"更多"菜单含：重新解析（仅失败文档可用）、复制路径、在文件管理器中打开、移动、删除；删除需二次确认
8批量操作P0勾选文件后出现批量栏，支持批量移动、批量删除（二次确认）；未选中时批量栏不显示、按钮禁用
9移动到P0弹窗按层级展示目标文件夹，确认后将文档（单条或批量）的所属文件夹更新为目标文件夹
10容量统计P1点击容量入口查看弹窗：总容量、容量占比条形图、各类型文件数量 / 大小 / 占比卡片（详见 5.4）
11模型配置P1配置文档解析模型与向量化模型（详见 5.3）

特殊规则说明

序号规则说明
1文档五态文档状态固定为五种；"解析失败"需记录并可查看失败原因
2重解析规则对"解析失败"文档触发重解析后，状态置回"待解析"并重新走解析流程；支持单条与批量
3批量删除不可恢复批量删除需二次确认，删除后不可恢复
4移动更新归属移动仅变更文档的所属文件夹，不改变文件本身
5打开 / 复制路径依赖本地文件系统能力；在受限于浏览器环境时需有明确提示
6全选作用范围筛选 / 分页后"全选"仅作用于当前结果集，避免误操作跨页数据
7每页条数文档列表默认每页 15 项

🔹 5.3 解析与向量化模型配置

功能描述

模型配置用于设定知识库在文档解析（提取文字与结构）与向量化（生成检索向量）阶段所采用的模型。解析模型支持"企业默认"与"个人自定义"两种模式，自定义优先级高于企业默认；向量化模型当前仅提供企业默认选项。

功能清单

序号功能名称优先级功能描述
1文档解析模型配置P1可选"企业默认模型"（管理员统一配置）或"自定义模型"；选择自定义后可添加多个解析模型、移除已有模型；自定义模型优先级高于企业默认
2向量化模型配置P1选择企业默认向量模型（当前仅提供企业默认选项）

特殊规则说明

序号规则说明
1自定义优先个人自定义解析模型优先级高于企业默认模型
2向量化仅默认向量化模型当前仅支持企业默认，不开放个人自定义

🔹 5.4 容量统计

功能描述

容量统计帮助用户了解知识库的空间占用情况。弹窗展示总容量、按文件类型的容量占比，以及每种类型的数量、大小与占比明细，便于识别占用大户。

功能清单

序号功能名称优先级功能描述
1总容量概览P1展示知识库总容量与文件总数
2容量占比分析P1以条形图展示各文件类型占总容量的比例
3类型明细卡片P1按 Markdown / 文本 / PDF / Word / Excel / PPT / 图片 七类，分别展示数量、大小、占比
💡 容量统计依赖文件体积数据；空知识库（无文件）时展示为零，不应报错。

六、关键交互流程

流程一：新建知识库并扫描解析

1

发起创建

用户在列表页点击"新建知识库"，弹出表单。

2

填写并提交

填写名称、上传图标、选择本地文件夹路径、填写描述；校验通过后提交。

3

扫描解析

展示扫描进度动画，分阶段提示扫描 / 解析 / 提取 / 完成，并实时统计发现文件数。

4

结果反馈

弹出结果，展示扫描文件总数与不支持文件数（警告）；知识库状态置为"处理中"。

5

后台完成

系统在后台继续解析与向量化，完成后状态自动变为"已完成"，用户进入详情页使用。

流程二：文档解析失败与重解析

1

发现失败

详情页统计卡片或表格中出现"解析失败"状态，并带红色警告图标与失败原因提示。

2

触发重解析

单条点"重新解析"或点击"重新解析全部"（存在失败时出现），状态置回"待解析"。

3

完成修复

重新走解析流程，成功后转为"已完成"；若仍失败则保留失败原因供排查。

流程三：批量移动 / 删除

1

勾选文件

在文档表格中勾选目标文件，出现批量操作栏。

2

执行操作

点"批量移动"则弹出层级文件夹选择并确认；点"批量删除"则二次确认。

3

刷新结果

操作后表格刷新，批量栏清空，给出成功提示。

流程四：目录树文件夹管理

1

打开菜单

在目录树某文件夹点"更多"，展开操作菜单。

2

执行操作

选择重命名（内联编辑）或新建子文件夹（就地生成并进入重命名）。

3

更新结构

目录树实时更新节点名称与层级，文档归属随文件夹调整。

七、边界与异常情况

序号场景处理策略备注
1新建时未填名称阻止提交，提示名称为必填项前端校验
2新建时未选择路径阻止提交，提示请选择本地文件夹前端校验

12移动未选择目标文件夹提示"请选择目标文件夹"，不执行前端拦截
13切换到知识图谱标签本期为占位区域，提示未实现或暂不开放非目标范围
14不支持的文件格式标记为"暂不支持"，扫描结果以警告样式提示数量不阻断整体
15空知识库查看容量总容量展示为 0，类型明细为空，不报错边界兼容
16分页 / 筛选后全选全选仅作用于当前结果集，避免跨页误删防误操作
17本地打开 / 复制路径受限在受限环境下给出明确提示，而非静默失败体验兜底
18知识库仍在解析中即删除允许删除并中止解析，仅移除已建索引，本地文件保留状态兼容
💡 以上边界场景覆盖了必填校验、文件规格、解析失败恢复、危险操作二次确认、占位能力与空数据兼容等核心风险点，建议在开发阶段逐一编写测试用例验证。
