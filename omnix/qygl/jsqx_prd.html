一、概述

1.1 背景与问题

企业智能体平台的功能分布在管理端与客户端两个端。其中管理端覆盖三大业务域、十个功能菜单：企业智能体（专家管理、专家团管理）、资源管理（模型管理、MCP 服务、技能管理、专家词库）、企业管理（部门管理、成员管理、角色管理、菜单管理），每个菜单下又包含新建、编辑、删除、启禁用、发布等大量操作点。企业中不同岗位的成员需要不同的功能范围与操作深度：有人只使用客户端对话，有人需要在管理端维护模型与技能资源，但不应触碰组织与权限配置。角色（Role）正是连接"人"与"权限"的核心载体——先定义角色并为其授权，再将角色分配给成员，即可完成企业内的权限治理。

在缺乏统一角色管理模块之前，企业面临以下问题：

  • 权限粒度粗：只能按端控制访问，无法精确到具体菜单和按钮（如"删除专家""发布专家"），要么不给、要么全给，容易权限过大；
  • 角色无法自定义：系统仅有"所有者""普通用户"两个预置角色，无法按企业岗位（如运营、内容管理员、审计员）灵活建角色；
  • 授权不透明：一个角色到底拥有哪些权限缺少直观的查看方式，权限变更、审计核对困难；
  • 误操作风险高：删除等高危操作缺少二次确认，预置角色若被误改误删，可能导致整个权限体系失效。

因此，在系统管理下建设角色管理模块：提供角色列表浏览与搜索、新增/编辑角色、按"权限组 → 菜单 → 按钮"三级权限树的管理端细粒度授权、系统默认角色的只读权限预览，以及单条/批量删除的确认保护，形成"定义角色 → 精细授权 → 透明查看 → 安全下线"的完整管理闭环。

1.2 目标用户与典型场景

系统所有者

企业最高权限者，拥有管理端与客户端的全部权限。负责规划企业角色体系、创建各类管理员角色并分配给对应负责人。关注权限体系的完整性与安全性。

企业管理员

日常维护角色的操作者：按岗位新建角色、勾选菜单与按钮权限、调整既有角色授权、下线废弃角色。关注授权效率（整组批量勾选）与操作确认保护（防误删）。

审计 / 合规人员

定期核对各角色的权限范围，确认权限与岗位职责匹配。通过只读的权限预览查看角色完整授权清单，关注权限信息的透明性与不可篡改性。

1.3 核心概念

概念定义
角色权限的集合与准入范围的载体，由名称、角色标识、可访问系统、备注及权限集合构成。角色创建后可分配给成员，成员据此获得对应端与功能的访问能力。
系统默认角色系统初始化预置的"所有者"与"普通用户"两个角色。所有者拥有管理端与客户端的所有权限；普通用户拥有客户端使用权限，是新用户注册的默认角色。系统默认角色仅可查看，不可编辑、不可删除，名称旁展示"系统默认"标签。
角色标识角色的唯一编码（如 ROLE_ADMIN），供系统内部进行权限判定使用，创建角色时由用户录入。
可访问系统角色可登录使用的端，包含"管理端"与"客户端"两项，支持多选，至少选择一项。决定角色的端级准入范围。
权限组按业务域对菜单的归类，是权限树的一级节点。共三组：企业智能体、资源管理、企业管理。支持整组批量勾选/取消。
菜单权限管理端某功能页面的访问权限（如"专家管理""模型管理"），是权限树的二级节点。勾选菜单表示该角色可进入对应功能页面。
按钮权限菜单页面内具体操作（如"新建专家""删除专家""专家发布"）的操作权限，是权限树的三级节点。勾选某按钮权限时，系统自动补选其所属菜单权限，避免"有按钮无页面"的无效配置。
管理端授权角色表单中当勾选"管理端"后展示的权限树配置区，承载权限组 → 菜单 → 按钮三级勾选，并提供全选与各级计数。
全部权限所有者角色持有的特殊权限标记，语义为权限树全部节点选中。预览时所有节点呈选中态，计数显示为总数/总数。

1.4 用户故事

作为 系统所有者，我希望创建自定义角色并按菜单、按钮两级配置权限，以便每个岗位只获得完成工作所需的最小权限。
作为 企业管理员，我希望在权限树中按权限组一键勾选整组权限，并通过全选、计数快速掌握勾选进度，以便配置角色时不必逐项点选近百个权限点。
作为 企业管理员，我希望勾选按钮权限时系统自动补选其所属菜单，以便不出现"有操作权限却进不了页面"的无效配置。
作为 审计人员，我希望以只读方式查看任一角色的完整权限清单，以便安全地核对权限与岗位职责的匹配性，不会误改配置。
作为 企业管理员，我希望删除角色前系统给出包含角色名称或数量的二次确认，以便避免误删导致成员权限失效。
作为 企业管理员，我希望按名称搜索角色，以便在角色较多时快速定位目标角色。

1.5 非目标

本期不做以下内容：
  • 不提供角色与成员的分配绑定功能（将角色授予具体成员在"成员管理"模块完成，本模块仅管理角色本身）；
  • 不提供客户端的细粒度授权配置（客户端仅通过"可访问系统"控制端级准入，无权限树）；
  • 不支持权限树节点的自定义增删改（权限组、菜单、按钮均为系统预置权限资源，菜单维护由"菜单管理"模块承担）；
  • 不提供数据级、字段级权限（权限粒度到菜单与按钮为止，不区分数据行范围）；
  • 不提供角色复制、导入导出与权限变更历史（版本追溯）；
  • 不支持对系统默认角色（所有者、普通用户）的编辑与删除。

二、功能架构与流程图

2.1 系统架构图

模块由一个主页面与三个弹窗构成：角色列表页是统一入口，承载搜索、表格展示、勾选、以及"查看 / 编辑 / 删除 / 新增 / 批量删除"全部操作入口；新增/编辑角色弹窗承载基本信息表单、可访问系统选择与管理端权限树授权；查看角色弹窗面向系统默认角色提供只读权限预览；删除确认弹窗为单条删除与批量删除提供统一的二次确认。权限树的资源（权限组 → 菜单 → 按钮权限，共 95 个权限节点）由系统预置，与菜单管理模块联动；角色保存后供成员管理模块分配使用。

2.2 业务流程图

五条核心业务流程：角色的新增/编辑（含必填校验分支）、权限树勾选联动、系统默认角色的查看、角色删除（单条/批量）、搜索与全选。

流程五：搜索与全选。在搜索框输入关键词 → 列表按角色名称实时过滤（不区分大小写）→ 无匹配结果时表格主体替换为"暂无角色数据"空状态；点击表头全选复选框 → 对当前筛选结果内的所有行全选 / 全不选。勾选状态不随搜索过滤清除，批量删除以全部已勾选角色为准（含被筛选隐藏但仍处于勾选状态的行）。

三、详细设计

本模块共一个主页面与三个弹窗：3.1 角色列表页（浏览与全部操作入口）、3.2 新增/编辑角色弹窗（表单与权限授权）、3.3 查看角色弹窗（只读权限预览）、3.4 删除确认弹窗（单条/批量二次确认）。每个页面按"功能描述 → 显示字段说明 →（如有表单）表单字段说明"展开。

3.1 角色列表页

功能描述

角色列表页是模块首页，位于"系统管理 > 角色管理"菜单下，集中呈现企业内全部角色。页面顶部为面包屑与两个全局操作按钮（删除、新增角色）；下方为搜索框，按角色名称实时过滤列表；主体为角色表格，展示名称（系统默认角色带"系统默认"标签）、角色标识、可访问系统、备注、创建人/创建时间、更新人/更新时间，以及随行类型变化的操作列——系统默认角色仅"查看"，自定义角色提供"编辑"与"删除"。表格支持行勾选与表头三态全选，勾选后通过顶部"删除"按钮批量删除。列表无数据或搜索无结果时展示空状态。表格下方固定展示系统默认角色的权限说明文案。

3.2 新增/编辑角色弹窗

功能描述

新增与编辑共用同一弹窗，通过标题与数据状态区分：由顶部"新增角色"按钮打开时为空白表单；由行内"编辑"打开时标题变为"编辑角色"并回显该角色的全部既有配置。表单包含名称、角色标识、可访问系统、备注四个基础项，以及"管理端授权"权限树区域——仅当可访问系统勾选了"管理端"时展示。权限树按"权限组 → 菜单 → 按钮权限"三级组织，支持全选、整组勾选、菜单勾选（连带其下按钮）与单按钮勾选（自动补选所属菜单），各级复选框具备选中/半选/未选三态，并实时展示"已选数/总数"计数（全选行与每个权限组行）。点击"确认"逐项校验必填项后保存；点击"取消"、右上角 X 或遮罩关闭弹窗且不保存。

权限树 · 全选行 固定在权限树顶部："全选 (已选数/总数)" + 三态复选框；点击在全选 / 全不选间切换 总数 = 权限树全部菜单与按钮权限节点（95 个）；全部选中→选中态，部分选中→半选态，未选→空态
权限树 · 权限组行 三态复选框 + 组名 + "(已选数/总数)"计数 + 展开箭头；点击行主体展开 / 收起该组（箭头旋转 90°），点击复选框整组选中 / 取消（不触发展开收起） 三个权限组（企业智能体、资源管理、企业管理）默认全部展开；组计数与三态随子节点勾选实时刷新；展开状态在弹窗内跨操作保持
权限树 · 菜单行 复选框 + 菜单名（左侧固定宽度）+ 该菜单的按钮权限胶囊列表；点击行任意非按钮区域，选中 / 取消该菜单及其下全部按钮权限 菜单勾选具有独立语义（可访问该功能页面）；全部按钮取消后菜单仍可保持选中
权限树 · 按钮权限项 胶囊样式小复选框 + 按钮名，选中时蓝底蓝边高亮；点击单独选中 / 取消该按钮权限 联动规则：选中某按钮时若其所属菜单未选中，自动补选菜单；取消按钮不联动取消菜单
取消按钮 底部左侧灰色按钮；点击关闭弹窗，不保存任何修改 关闭后再次打开时表单重置（新增为空白、编辑重新回显），不保留上次未保存的输入
确认按钮 底部右侧蓝色主按钮；点击执行必填校验，通过后保存角色并关闭弹窗、刷新列表 校验不通过时逐项提示且不关闭弹窗；新增写入创建人/创建时间，编辑仅刷新更新人/更新时间
遮罩 半透明黑色全屏遮罩，弹窗居中展示，带淡入与上浮动画 点击遮罩空白处等同"取消"，直接关闭且不保存

表单字段说明

字段类型必填说明
名称 单行文本 是 角色显示名称；占位提示"请输入名称"。为空时提交提示"请输入角色名称"并阻止保存。前后空格自动去除
角色标识 单行文本 是 角色唯一编码，供系统权限判定使用；占位提示"请输入角色标识，如 ROLE_ADMIN"。为空时提交提示"请输入角色标识"并阻止保存
可访问系统 多选卡片 是 可选"管理端""客户端"，支持多选；未选择任何一项时提交提示"请选择可访问系统"并阻止保存。勾选"管理端"联动展示"管理端授权"权限树区域
备注 单行文本 否 角色用途说明；占位提示"请输入备注"。为空时列表中展示"-"
管理端授权 权限树（组 → 菜单 → 按钮三级） 否 仅"管理端"选中时展示；提供全选、整组、菜单、按钮四级勾选方式，各级计数与三态复选框实时联动。允许不勾选任何权限直接保存（角色可进入管理端但无任何功能权限）
确认（表单按钮） 按钮 — 按"名称 → 角色标识 → 可访问系统"顺序逐项校验，任一不通过则提示并中断。通过后保存：新增生成自定义角色并写入创建人/创建时间/更新人/更新时间（当前用户、当天日期）；编辑更新表单内容与权限集合并刷新更新人/更新时间。保存后关闭弹窗并刷新列表
取消（表单按钮） 按钮 — 直接关闭弹窗，放弃本次全部输入与勾选，不做任何校验

3.3 查看角色弹窗

功能描述

查看角色弹窗面向系统默认角色（所有者、普通用户）提供只读的权限预览，入口为列表中该类角色行的"查看"链接。弹窗以与编辑表单一致的布局展示名称、角色标识、可访问系统、备注四项基础信息（全部只读），以及"管理端授权"只读权限树——仅当该角色的可访问系统包含"管理端"时展示。权限树默认全部展开且不可收起，所有复选框与按钮权限项均不可点击，仅呈现该角色的权限选中状态与计数。拥有全部权限的角色（所有者）所有节点呈选中态、计数为总数/总数；仅客户端的角色（普通用户）不展示授权区。弹窗底部仅提供"关闭"按钮，右上角 X 与遮罩点击同样关闭。

显示字段说明（列表格式）

字段 / 按钮规则来源 / 例外 / 边界
弹窗标题 固定显示"查看角色" 系统固定文案；仅系统默认角色可进入本弹窗
名称 / 角色标识 / 备注 单行只读文本框，回显角色既有值，不可聚焦编辑 来源：角色基本信息；备注为空时文本框为空
可访问系统 只读选择卡片，按角色配置呈现"管理端""客户端"的选中高亮样式 卡片不可点击、不响应切换操作，仅做状态展示
管理端授权区域 仅当角色可访问系统包含"管理端"时展示只读权限树；否则整块隐藏 边界：普通用户（仅客户端）不展示该区域；所有者（管理端 + 客户端）展示
只读权限树 三个权限组全部展开且不可收起（箭头固定朝下）；菜单与按钮权限按角色已保存的权限集合呈现选中态；全部复选框与胶囊项不可点击 例外：拥有全部权限的角色（所有者）所有节点呈选中态，无需逐节点匹配

关闭按钮 底部右侧蓝色主按钮"关闭"；点击关闭弹窗 右上角 X、点击遮罩空白处同样关闭；关闭不影响任何数据

说明：本弹窗为纯只读展示，无可提交的表单，故不含"表单字段说明"模块。

3.4 删除确认弹窗

功能描述

删除确认弹窗是角色删除的统一二次确认层，服务两个入口：自定义角色行内的"删除"链接（单条删除）与列表顶部的"删除"按钮（批量删除）。弹窗为小尺寸居中卡片，包含琥珀色警示图标、随入口变化的标题与文案：单条删除标题为"确认删除"，文案含目标角色名称；批量删除标题为"批量删除"，文案含勾选的角色数量。两种场景均明示"此操作不可撤销"。点击红色"确认删除"按钮执行删除并刷新列表（批量删除同时清空勾选状态）；点击"取消"、右上角遮罩空白处放弃操作并关闭弹窗。

显示字段说明（列表格式）

字段 / 按钮规则来源 / 例外 / 边界
警示图标 弹窗顶部居中展示琥珀色圆形感叹号图标 系统固定视觉元素，提示高危操作
标题 单条删除显示"确认删除"；批量删除显示"批量删除" 由触发入口决定
提示文案 单条："确定要删除角色「角色名」吗？此操作不可撤销。"；批量："确定要删除选中的 N 个角色吗？此操作不可撤销。" 角色名来源：被删除角色；N 来源：当前已勾选角色数量
取消按钮 灰色按钮；点击关闭弹窗，不执行删除 点击遮罩空白处同样关闭并放弃操作
确认删除按钮 红色主按钮；点击后立即执行删除、关闭弹窗并刷新列表 单条：移除该角色；批量：移除全部已勾选角色并清空勾选状态。删除不可撤销、无回收站。边界：系统默认角色行不提供单条删除入口；批量删除按勾选范围执行，勾选包含系统默认角色时不做单独拦截，操作需谨慎

说明：本弹窗为确认交互，无表单输入项，故不含"表单字段说明"模块。
