菜单管理

树形结构 · 三级菜单类型 · 搜索筛选 · 图标选择 · 权限配置 —— 产品需求文档 v1.0

文档版本修改日期编写人修改说明
v1.0 2026-09-09 产品经理 按标准 PRD 结构编写：概述（需求描述）、功能架构与流程图、三个页面（菜单列表页、新增/编辑弹窗、删除确认弹窗）的详细设计

一、概述

1.1 需求描述

在企业级后台管理系统中，菜单是用户导航至各功能模块的核心入口，也是权限体系的基础载体。系统需要通过一套统一的菜单管理机制来定义"哪些功能模块对用户可见、以何种层级组织、按什么顺序排列、由哪些操作按钮构成"。随着系统功能模块不断增长——涵盖多级目录、功能页面和页面内的操作按钮——迫切需要提供一个可视化的菜单管理工具，让管理员能够直观地维护整个系统的导航结构与权限标识。

在没有统一菜单管理之前，面临以下问题：

  • 结构不透明：系统导航结构散落在代码配置中，非技术人员无法直观了解当前系统有哪些菜单、层级关系如何，也无法快速调整；
  • 权限难管控：页面内的操作按钮（如新增、编辑、删除）缺少统一的权限标识管理，无法与角色体系精确对接，导致权限分配只能依赖开发配置；
  • 调整成本高：新增或调整一个菜单项需要修改代码并重新部署，无法由管理员在后台即时完成，响应业务变化的速度慢；
  • 缺乏层级可视化：目录、菜单、按钮三种类型的节点混在一起，缺少树形可视化的管理界面，难以快速定位和维护。

因此，本模块要建设一个可视化的菜单管理功能：以树形表格集中呈现全部菜单数据（目录 → 菜单 → 按钮三级结构），支持搜索与显示状态筛选，并提供新增、编辑、删除的完整管理闭环。管理员可在一个页面内完成菜单结构的查看、调整与维护。

二、功能架构与流程图

2.1 系统架构图

菜单管理功能由一个主页面与两个弹窗构成：菜单管理列表页（主入口，承载树形数据展示、搜索、筛选、展开折叠、新增入口）；新增/编辑菜单弹窗（承载菜单的创建与编辑表单，含类型选择、上级菜单选择、图标选择等）；删除确认弹窗（承载删除操作的二次确认）。列表页以树形表格呈现目录、菜单、按钮三级数据，每行提供新增子节点、编辑、删除操作入口。

2.2 业务流程图

四条核心业务流程：菜单的浏览与搜索筛选、新增菜单、编辑菜单、删除菜单。

三、详细设计

本功能共三个页面/弹窗：3.1 菜单管理列表页（主入口，承载树形数据展示、搜索、筛选、展开折叠与操作入口）、3.2 新增/编辑菜单弹窗（承载菜单的创建与编辑表单）、3.3 删除确认弹窗（承载删除操作的二次确认）。每个页面按"功能描述 → 显示字段说明 → 表单字段说明"展开。

3.1 菜单管理列表页

功能描述

菜单管理列表页是菜单管理功能的主入口页面，以树形表格集中展示系统全部菜单数据。菜单数据按目录 → 菜单 → 按钮三级层次组织，通过缩进与展开/折叠控件呈现层级关系。页面顶部提供面包屑导航、"全部展开/全部折叠"快捷操作与"新增菜单"入口；内容区上方提供按菜单名称搜索与按显示状态筛选的能力；树形表格每行根据节点类型与子节点状态，动态展示"新增""编辑""删除"操作链接。支持搜索关键词高亮、筛选时自动展开匹配节点的父级链路，确保用户能快速定位目标菜单。

显示字段说明

字段/按钮规则来源/例外/边界

显示状态筛选 搜索框右侧下拉框，选项为：全部 / 显示 / 隐藏；选择后与搜索条件共同过滤树形表格数据 "全部"不做状态过滤；"显示"仅展示 showStatus 为 show 的节点；"隐藏"仅展示 showStatus 为 hide 的节点；与搜索条件为"或"关系——子节点匹配时其父级也保留展示
菜单名称列 树形表格第一列，宽度 260px；展示节点名称，加粗深色文字；左侧带展开/折叠箭头图标（有子节点时显示，无子节点时隐藏），按层级缩进 展开箭头点击切换该节点的展开/折叠状态；搜索命中时关键词以黄色背景高亮；每级缩进 24px
类型列 树形表格第二列，宽度 76px；以彩色标签展示节点类型：目录（蓝底蓝字"目录"）、菜单（绿底绿字"菜单"）、按钮（黄底棕字"按钮"） 类型由菜单数据的 type 字段决定，三种类型对应三种配色方案
图标列 树形表格第三列，宽度 60px；展示该菜单节点配置的图标（iconify 图标）；未配置图标时显示灰色"-"占位符 仅目录和菜单类型可配置图标，按钮类型无图标
路由地址列 树形表格第四列，等宽字体展示；有路由值时显示路由路径（如 /system/dept），无值时显示"-"占位符 仅菜单类型有路由地址；目录和按钮类型此列显示"-"
权限标识列 树形表格第五列，等宽字体展示；有权限标识时显示标识字符串（如 system:dept:add），无值时显示"-"占位符 仅按钮类型有权限标识；目录和菜单类型此列显示"-"
排序列 树形表格第六列，宽度 70px；展示排序号数字 排序号越小排列越靠前；同层级内按排序号升序排列
显示列 树形表格第七列，宽度 76px；以彩色标签展示显示状态：显示（绿底绿字"显示"）、隐藏（红底红字"隐藏"） 显示状态决定该菜单是否在前端导航中呈现给用户
操作列 树形表格第八列，宽度 170px；包含操作链接，根据节点类型与子节点状态动态展示 详见下方操作规则说明
「新增」操作链接 蓝色文字链接，点击打开新增菜单弹窗，并预填上级菜单与推荐类型 显示条件：仅当当前节点类型不是"按钮"时显示（目录和菜单类型才可在其下新增子节点）
预填规则：上级为目录时推荐类型"目录"，上级为菜单时推荐类型"按钮"
「编辑」操作链接 蓝色文字链接，点击打开编辑菜单弹窗并回显当前节点全部数据 显示条件：所有节点均显示，无例外
「删除」操作链接 红色文字链接，点击打开删除确认弹窗 显示条件：所有节点均显示
可操作条件：仅当节点无子节点时可点击删除；有子节点时链接置灰（浅灰色），鼠标悬停显示提示"有子节点不可删除"，点击无响应
空状态 当搜索/筛选结果为空时，表格区域显示文件夹图标与"暂无菜单数据"提示文字 搜索与筛选条件共同作用后无匹配数据时展示

3.2 新增/编辑菜单弹窗

功能描述

新增/编辑菜单弹窗用于创建新的菜单节点或修改已有菜单节点的属性。弹窗采用模态形式，宽度 1000px，最大高度 85vh 可滚动。弹窗标题根据操作模式显示"新增菜单"或"编辑菜单"。表单包含菜单类型选择、上级菜单选择、名称、路由地址、权限标识、菜单图标、排序号、显示状态、外链打开等字段。其中，菜单类型通过单选按钮切换（目录/菜单/按钮），切换类型后表单字段按类型联动显隐；上级菜单选择器以列表形式展示可选的父级节点，根据当前类型动态限制可选范围。编辑模式下菜单类型锁定不可修改。弹窗支持点击遮罩层关闭、右上角关闭按钮关闭与底部取消按钮关闭。

表单字段说明

字段类型必填说明
菜单类型 单选按钮 是 三个选项：目录 / 菜单 / 按钮，横向排列。切换类型后表单字段联动显隐（见下方联动规则表）。
新增模式：类型可自由切换；
编辑模式：类型锁定为当前值，三个单选按钮均置为禁用状态，不可修改
上级菜单 列表选择 否 可滚动的列表选择器，最大高度 200px。首项为"根目录"，其后按树形层级缩进展示所有目录和菜单节点（按钮类型不在列表中展示）。
可选范围受菜单类型约束：
• 类型为"目录"时：仅可选择"根目录"或其他"目录"类型节点
• 类型为"菜单"时：仅可选择"目录"类型节点（不可选"根目录"）
• 类型为"按钮"时：仅可选择"菜单"类型节点
编辑模式：列表中当前编辑的节点置灰不可选（防止将自身设为自己的上级）
新增模式：从行操作"新增"进入时，自动选中对应的上级节点；从顶部"新增菜单"进入时，默认选中"根目录"
名称 单行文本 是 菜单的显示名称。占位提示"请输入名称"。为空时点击确认弹出 alert 提示"请输入菜单名称"并阻止提交
路由地址 单行文本 是（菜单类型时） 菜单对应的路由路径，如 /system/dept。占位提示"如 /system/dept"。
显隐规则：仅当菜单类型为"菜单"时显示，类型为"目录"或"按钮"时隐藏
权限标识 单行文本 否 按钮级权限标识字符串，如 system:dept:add。占位提示"如 system:dept:add"。
显隐规则：仅当菜单类型为"按钮"时显示，类型为"目录"或"菜单"时隐藏
菜单图标 文本 + 图标选择器 否 输入框右侧带图标选择器面板。点击输入框弹出图标选择面板（8列网格，最多展示 24 个预设图标），点击图标后自动填入图标名称并关闭面板；也支持手动输入图标名称。点击面板外部区域自动关闭面板。
显隐规则：仅当菜单类型为"按钮"时隐藏，类型为"目录"或"菜单"时显示
排序号 数字输入 是 控制同级节点的排列顺序，数字越小越靠前。默认值为 0。
显隐规则：仅当菜单类型为"按钮"时隐藏，类型为"目录"或"菜单"时显示
显示状态 下拉选择 是 两个选项：显示 / 隐藏。默认值为"显示"。决定该菜单在前端导航中是否对用户可见。
显隐规则：仅当菜单类型为"按钮"时隐藏（按钮无独立显示状态），类型为"目录"或"菜单"时显示
外链打开 开关（Switch） 否 切换该菜单是否以外部链接方式打开（在新窗口/标签页中打开外部地址）。默认关闭。
显隐规则：仅当菜单类型为"菜单"时显示，类型为"目录"或"按钮"时隐藏
「取消」按钮 按钮 否 灰色次要按钮，点击关闭弹窗并重置编辑状态，不保存任何数据
「确认」按钮 按钮 否 蓝色主要按钮，点击触发表单校验与保存。校验规则：名称不能为空（为空时 alert 提示并阻止提交）。保存成功后关闭弹窗并刷新树形表格。
新增模式：创建新节点并插入到指定上级节点的子节点列表中，若上级节点折叠则自动展开；
编辑模式：更新当前节点的全部字段值

3.3 删除确认弹窗

功能描述

删除确认弹窗用于对菜单删除操作进行二次确认，防止误删。弹窗宽度 400px，居中展示。弹窗内容区包含警告图标、标题"确认删除"、动态提示文字（含被删除菜单的名称），底部提供"取消"与"确认删除"两个按钮。弹窗支持点击遮罩层关闭。仅叶子节点（无子节点的节点）可触发此弹窗——有子节点的节点删除按钮置灰不可点击，需先删除全部子节点后才可删除父节点。

显示字段说明

字段/按钮规则来源/例外/边界
警告图标 内容区顶部居中展示大号橙色警告图标（alert-circle-outline），尺寸 48px 系统固定图标，用于传达危险操作的视觉提示
标题 图标下方展示"确认删除"标题文字，深色加粗 系统固定文案
提示文字 标题下方展示灰色提示文字，动态拼接被删除菜单名称："确定要删除「{菜单名称}」吗？此操作不可撤销。" 菜单名称取自当前选中删除节点的数据；若名称包含特殊字符需正常展示
「取消」按钮 灰色次要按钮，点击关闭弹窗，不执行任何删除操作 无例外
「确认删除」按钮 红色主要按钮，点击执行删除操作：从树形数据中移除目标节点，关闭弹窗并刷新树形表格 删除约束：仅当目标节点无子节点时可触发（有子节点时删除入口已置灰，不会进入此弹窗）
删除效果：从树形数据中彻底移除该节点，刷新后表格不再展示
遮罩层关闭 点击弹窗外的半透明遮罩区域可关闭弹窗，不执行删除 新增/编辑弹窗同样支持遮罩层关闭
