一、概述

1.1 需求描述

在企业级 SaaS 平台或内部管理系统中，用户（成员）是最基础的运营单元。管理员需要一个集中化的"用户管理"模块，完成对平台全部成员的全生命周期管理——从创建、编辑、状态管控到删除，以及批量导入、密码重置、角色分配、所有者转移等高频操作。

当前企业在用户管理中面临以下痛点：

  • 成员信息分散：组织架构调整频繁，成员所属部门、角色、联系方式等变更缺少统一维护入口，数据散落在多个系统中；
  • 权限管控薄弱：所有者、管理员、成员等角色缺少可视化管理界面，无法快速调整成员权限或转移企业所有权；
  • 批量操作低效：新团队上线时需要逐一手动录入成员信息，缺少批量导入能力，效率极低；
  • 账号安全缺失：成员忘记密码时缺少便捷的重置入口，离职成员缺少快速禁用与清理通道；
  • 状态不透明：无法直观看到哪些成员处于启用/禁用状态，缺少一键切换能力。

因此，本模块建设一个统一的用户管理页面：以列表为核心视图，集中呈现全部成员的基本信息、角色、状态，并提供搜索、多维度筛选、分页浏览；在此之上覆盖新增、编辑、删除、状态切换、密码重置、批量导入、所有者转移等完整管理闭环。

二、功能架构与流程图

2.1 系统架构图

模块由一个主页面与五个弹窗构成：用户管理列表页是核心入口，承载搜索、筛选、成员浏览与全部管理操作。弹窗包括新增/编辑成员弹窗（共用同一表单，按模式切换字段显隐）、删除确认弹窗、重置密码确认弹窗、转移所有者确认弹窗、导入成员弹窗（含文件上传与导入结果展示）。

2.2 业务流程图

六条核心业务流程：成员浏览与筛选、新增成员、编辑成员、删除成员、重置密码、转移所有者、批量导入。

三、详细设计

本模块共一个主页面与五个弹窗：3.1 用户管理列表页（核心入口）、3.2 新增/编辑成员弹窗、3.3 删除确认弹窗、3.4 重置密码确认弹窗、3.5 转移所有者确认弹窗、3.6 导入成员弹窗。

3.1 用户管理列表页

功能描述

用户管理列表页是模块的核心页面，集中呈现企业全部成员信息。页面自上而下包含：面包屑导航（系统管理 > 用户管理）、顶部操作栏（导出、导入、新增成员按钮）、筛选栏（关键词搜索 + 角色/部门/状态三个筛选下拉）、成员数据表格、底部分页组件。表格以行展示每位成员的头像、姓名、账号、部门、手机号、邮箱、角色、启用状态及操作按钮。操作列包含编辑、删除、重置密码三项。所有者行具有特殊标识与保护逻辑。

3.2 新增/编辑成员弹窗

功能描述

新增与编辑共用同一个弹窗表单，通过入口不同区分模式。新增模式下弹窗标题为"新增用户"，显示全部字段（含密码和管理端角色），底部按钮为"确认创建"；编辑模式下弹窗标题为"编辑用户"，隐藏密码字段，所有者行隐藏管理端角色字段，底部按钮为"保存修改"。弹窗顶部有关闭按钮，底部有取消按钮。

表单字段说明

字段类型必填说明
账号 单行文本 是 成员的系统登录账号。占位提示"请输入账号"。编辑模式下回填当前值
密码 密码输入 是（新增） 成员登录密码。占位提示"请输入密码"。仅新增模式显示，编辑模式下整个字段隐藏
姓名（昵称） 单行文本 是 成员显示名称。占位提示"请输入姓名（昵称）"。编辑模式下回填当前值（若为"—"则清空）
所属部门 下拉选择 是 选项：（空）请选择部门 / 总部 / 生产部 / 采购部 / 财务部。编辑模式下回填当前值
手机号 单行文本 是 成员联系电话。占位提示"请输入手机号"。编辑模式下回填当前值（若为"—"则清空）
邮箱 单行文本 否 成员邮箱地址，选填。占位提示"请输入邮箱"。编辑模式下回填当前值

3.3 删除确认弹窗

功能描述

二次确认弹窗，防止管理员误删成员。弹窗居中展示红色警告图标、提示文案（含待删除成员名称）、不可恢复警告，以及"取消"和"确认删除"两个按钮。

显示字段说明

字段/按钮规则来源/例外/边界
警告图标 红色圆形背景 + 感叹号图标，居中展示 系统固定视觉元素
标题文案 "确认删除"，大号加粗 系统固定文案
提示正文 "确定要删除用户 [用户名] 吗？"，用户名从当前行数据动态取值（若姓名为"—"则取账号） 动态数据，由触发操作的行决定
警告提示 "⚠️ 删除后不可恢复，请谨慎操作"，红色小字 系统固定文案
取消按钮 灰色描边按钮，点击关闭弹窗，不执行删除 —
确认删除按钮 红色实心按钮，点击执行删除操作，从列表中移除该成员，刷新表格，弹出"删除成功"Toast —

3.4 重置密码确认弹窗

功能描述

二次确认弹窗，用于将指定成员的登录密码重置为系统默认密码。弹窗居中展示蓝色图标、提示文案（含用户名和默认密码明文）、"取消"和"确认重置"按钮。

显示字段说明

字段/按钮规则来源/例外/边界
图标 蓝色圆形背景 + 锁重置图标，居中展示 系统固定视觉元素
标题文案 "确认重置密码"，大号加粗 系统固定文案
提示正文 "确定要将用户 [用户名] 的密码重置为 Aa123456 吗？"，用户名动态取值，默认密码以代码样式高亮展示 默认密码固定为 Aa123456；用户名由触发行数据决定
取消按钮 灰色描边按钮，点击关闭弹窗，不执行重置 —
确认重置按钮 蓝色实心按钮，点击执行密码重置，关闭弹窗，弹出"密码已重置为 Aa123456"Toast —

3.5 转移所有者确认弹窗

功能描述

二次确认弹窗，用于将企业所有者权限转移给另一位成员。弹窗居中展示金色图标、提示文案（含目标用户名）、权限变更说明，以及"取消"和"确认转移"按钮。确认后原所有者降为管理员角色，目标成员升为所有者。

显示字段说明

字段/按钮规则来源/例外/边界
图标 金色圆形背景 + 皇冠盾牌图标，居中展示 系统固定视觉元素，金色呼应所有者身份
标题文案 "确认转移所有者"，大号加粗 系统固定文案
提示正文 "确定将所有者转移给 [用户名] 吗？"，用户名动态取值（若姓名为"—"则取账号） 由触发操作的行决定目标用户
变更说明 "转移后，原账号取消所有者权限"，金色小字居中 系统固定文案，告知用户权限变更后果
取消按钮 灰色描边按钮，点击关闭弹窗，不执行转移 —
确认转移按钮 蓝色实心按钮，点击执行转移：原所有者 isOwner 设为 false、role 改为"管理员"；目标成员 isOwner 设为 true、role 改为"所有者"、enabled 设为 true。刷新表格，弹出"已将所有者转移给 [用户名]"Toast 一个企业只能有一个所有者；转移后目标自动启用

3.6 导入成员弹窗

功能描述

批量导入成员弹窗，支持通过 Excel 文件批量添加成员。弹窗分为两个阶段：上传阶段（展示拖拽上传区 + 模板下载提示 + 文件选择后的文件名展示）和导入结果阶段（逐行展示导入结果 + 汇总统计 + 失败数据导出）。两个阶段通过"开始导入"按钮切换。

显示字段说明

字段/按钮规则来源/例外/边界
弹窗标题 "导入成员"，弹窗头部居中 系统固定文案
拖拽上传区 虚线边框区域，内含上传图标 + "点击或拖拽文件到此区域上传" + "支持 .xlsx 格式文件"提示。支持点击触发文件选择器，也支持拖拽文件进入。拖拽进入时边框变蓝 + 背景变蓝 仅接受 .xlsx 格式；拖入非 .xlsx 文件时弹出 Toast 提示"仅支持 .xlsx 格式文件"并拒绝
文件名展示 选择文件后在上传区下方展示蓝色文件标签（含文件名 + 关闭按钮），可点击关闭清除已选文件 未选择文件时隐藏
导入提示 上传区下方固定提示：① "请先下载导入模板，按模板格式填写后上传"（含超链接）；② "单次导入不超过 500 条数据" 系统固定文案；模板链接指向"用户导入模板.xlsx"
导入结果列表 固定高度滚动区域（h-56），逐行展示导入结果。每行格式：成功——绿色 ✓ 图标 + "第 N 行 用户名 导入成功"；失败——红色 ✕ 图标 + "第 N 行 用户名 导入失败 — 失败原因"。每行以动画依次滑入（间隔 0.5 秒） 上传阶段隐藏；点击"开始导入"后显示。结果数据由后端逐行校验返回
导入汇总 结果列表下方展示："共 N 条，成功 X（绿色），失败 Y（红色）" 全部结果展示完毕后显示
导出失败数据按钮 汇总行右侧，红色描边按钮 + 下载图标，点击导出失败数据 Excel 文件 仅在有失败记录时展示；下载文件名为"用户导入失败数据.xlsx"
取消按钮 灰色描边按钮，上传阶段显示，点击关闭弹窗并重置所有导入状态 导入结果阶段隐藏
开始导入按钮 蓝色实心按钮，上传阶段显示。点击前需已选择文件，否则弹出 Toast"请先选择文件"。点击后隐藏上传区和此按钮，进入导入结果阶段 导入结果阶段隐藏
完成按钮 蓝色实心按钮，导入结果阶段显示，点击关闭弹窗并重置所有导入状态 上传阶段隐藏；全部结果展示完毕后显示
