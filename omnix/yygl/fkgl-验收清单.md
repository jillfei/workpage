# 意见反馈管理模块验收清单



| 模块 | 功能 | 描述 | 验收结果 | 备注 |
| --- | --- | --- | --- | --- |
| 页面与布局 | 页面初始化 | 进入“运营管理 > 意见反馈”后，默认加载全部反馈第 1 页；顶部导航和底部分页栏固定，内容区可独立滚动。 | ✅️ |  |
| 搜索与筛选 | 关键字搜索 | 支持按反馈编号、提交用户、反馈内容实时包含匹配，不区分大小写并去除首尾空格；条件变化后回到第 1 页。 | ✅️ |  |
| 搜索与筛选 | 状态筛选 | 支持“全部状态 / 待处理 / 已处理”，可与关键字组合筛选；清空条件后恢复全量数据第 1 页。 | ✅️ |  |
| 反馈列表 | 列表信息展示 | 正确展示反馈编号、反馈内容、提交用户、来源端、当前状态、提交时间、处理时间和操作；长内容截断并可查看完整内容。 | ✅️ |  |
| 反馈列表 | 状态与操作入口 | 待处理、已处理状态样式区分明确；所有记录可查看，仅待处理记录显示“处理”入口，已处理记录不可重复处理。 | ✅️ |  |
| 反馈列表 | 查看详情入口 | 点击数据行或“查看”均可打开对应反馈详情；点击操作链接不会重复触发行点击。 | ✅️ |  |
| 分页 | 分页浏览 | 支持每页 10 / 20 / 50 / 100 条、页码跳转及上一页/下一页；总条数、当前区间与列表数据一致，边界按钮正确禁用。 | ✅️ |  |
| 反馈详情 | 反馈信息展示 | 完整展示状态、编号、提交用户、来源端、提交时间、反馈正文、图片和日志；正文按纯文本展示且不截断。 | ✅️ |  |
| 反馈详情 | 处理结果展示 | 待处理反馈显示“该反馈尚未处理”；已处理反馈展示处理人、处理时间、处理备注和处理附件，空备注显示“无备注”。 | ✅️ |  |
| 反馈详情 | 弹窗操作 | 支持关闭图标、关闭按钮和遮罩关闭且不修改数据；仅待处理反馈显示底部“处理”按钮并可转入处理弹窗。 | ✅️ |  |
| 反馈处理 | 处理准入与初始化 | 仅待处理反馈可打开处理弹窗；反馈原文只读，处理人自动取当前登录用户且不可修改；每次打开清空未提交内容。 | ✅️ |  |
| 反馈处理 | 备注与图片上传 | 处理备注可选填并去除首尾空格；仅支持上传图片，可多选、预览和删除，未上传图片也可提交。 | ✅️ |  |
| 反馈处理 | 取消处理 | 通过取消、关闭图标或遮罩退出时，丢弃本次备注和待上传图片，不生成处理记录，状态保持待处理。 | ✅️ |  |
| 反馈处理 | 确认处理 | 提交后状态单向变更为已处理，记录处理人、处理时间、备注及附件；关闭弹窗并按当前筛选条件刷新列表至第 1 页。 | ✅️ |  |
| 附件 | 图片预览 | 反馈图片、处理附件及待上传图片均可打开全屏大图预览；关闭预览后返回原弹窗，原有内容和输入不丢失。 | ✅️ |  |
| 附件 | 日志下载 | 有日志时显示文件名并支持下载，下载文件名与展示名称一致；无日志时不显示对应区域。 | ✅️ |  |
| 状态反馈 | 空状态 | 无数据或筛选无匹配结果时显示“暂无反馈数据”，隐藏表格数据区和分页栏；调整条件后恢复列表。 | ✅️ |  |
| 状态反馈 | 处理成功反馈 | 处理完成后提示“处理成功，状态已变更为\"已处理\"”，列表状态、处理时间和分页统计同步更新。 | ✅️ |  |
| 响应式 | 窄屏适配 | 窄屏下搜索与状态筛选可自动换行，分页信息与控件可分行展示，不出现内容裁切或横向滚动。 | ✅️ |  |
