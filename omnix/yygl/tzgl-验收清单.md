# 通知管理模块验收清单



| 模块 | 功能 | 描述 | 验收结果 | 备注 |
| --- | --- | --- | --- | --- |
| 页面与布局 | 页面初始化 | 进入“系统管理 > 通知管理”后加载全部通知；顶部栏和底部分页栏固定，通知列表所在内容区可独立滚动。 | ✅️ |  |
| 顶部栏 | 全局入口 | 正确展示面包屑、通知说明和“创建通知”入口；创建入口在任意筛选或空状态下均可使用。 | ✅️ |  |
| 通知说明 | 系统通知清单 | 点击说明按钮可展开或收起清单，并展示“技能审核通过”“技能审核不通过”；点击面板外区域自动收起。 | ✅️ |  |
| 搜索与筛选 | 关键词检索 | 支持按通知标题或内容实时模糊匹配，不区分大小写并忽略首尾空格；条件变化后回到第 1 页。 | ✅️ |  |
| 搜索与筛选 | 来源与状态筛选 | 支持来源“全部 / 系统自动 / 管理员手动”和状态“全部 / 已发送 / 待发送”，可与关键词组合筛选并即时生效。 | ✅️ |  |
| 通知列表 | 列表信息展示 | 正确展示标题、内容摘要、来源、接收人员、状态、发送时间、创建时间和查看操作；长文本截断并可查看完整内容。 | ✅️ |  |
| 通知列表 | 排序与只读规则 | 通知按产生时间倒序排列，新通知位于第 1 页首行；列表仅支持查看，不提供编辑、撤回或删除操作。 | ✅️ |  |
| 通知列表 | 查看详情入口 | 点击数据行或“查看”均可打开对应通知详情，点击查看链接不会重复触发行点击。 | ✅️ |  |
| 分页 | 分页浏览 | 支持每页 10 / 20 / 50 / 100 条、页码直达及上一页/下一页；总条数和当前区间与列表一致，边界按钮正确禁用。 | ✅️ |  |
| 分页 | 页码折叠与联动 | 总页数超过 7 页时按规则折叠页码；筛选或页长变化后页码正确重置或收敛，不出现越界空白页。 | ✅️ |  |
| 创建通知 | 表单初始化 | 从顶部栏或空状态打开创建弹窗时，标题和内容清空、计数归零、接收人员默认为“全员”，创建时间预览刷新。 | ✅️ |  |
| 创建通知 | 字段限制与校验 | 标题必填且最多 50 字，内容必填且最多 500 字；校验失败时给出对应错误提示，弹窗保持打开且已填内容不丢失。 | ✅️ |  |
| 创建通知 | 保存并发送 | 校验通过后立即发送全员通知，来源记为“管理员手动”、状态为“已发送”，自动记录当前用户及创建、发送时间。 | ✅️ |  |
| 创建通知 | 发送后刷新 | 发送成功后关闭弹窗、列表回到第 1 页并刷新，新通知显示在首行，同时提示“通知已发送”。 | ✅️ |  |
| 创建通知 | 取消创建 | 点击关闭、取消或遮罩退出时，放弃全部输入且不产生通知记录；下次打开恢复初始状态。 | ✅️ |  |
| 通知详情 | 完整信息展示 | 展示标题、来源、状态、接收范围、创建人、创建时间、发送时间和完整正文；正文保留原始换行。 | ✅️ |  |
| 通知详情 | 关闭与状态保持 | 支持头部关闭、底部关闭和遮罩关闭；关闭后保留列表关键词、筛选值、当前页码及每页条数。 | ✅️ |  |
| 空状态 | 无数据引导 | 无通知或筛选无结果时展示“暂无通知”和创建入口，同时隐藏表格及分页栏；条件恢复后重新显示列表。 | ✅️ |  |
| 结果反馈 | 全局轻提示 | 成功和错误提示样式区分明确，位于所有弹窗之上，约 2.5 秒后自动消失；新提示覆盖旧提示且不堆叠。 | ✅️ |  |
| 响应式 | 窄屏适配 | 窄屏下筛选项、详情元信息等可合理换行，弹窗内容可内部滚动，主要操作和内容不被裁切。 | ✅️ |  |
