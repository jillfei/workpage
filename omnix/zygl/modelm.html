📋 功能说明

🪙 Token 统计模块
统计企业内所有模型调用的 Token 消耗情况，支持多维度筛选、排行与趋势分析，帮助管理员掌握资源使用态势。本模块由 Token 数据总览、Token 用量趋势、Token 用量详情 三个子模块组成。
一、Token 数据总览
位于页面顶部，展示所选时间范围内的整体消耗概况、部门过滤及用户/智能体排行榜。默认展示「近7天」的数据。
功能点触发方式说明
数据卡片进入 Token 统计页面自动展示顶部卡片展示所选时间范围内的总消耗量、总调用次数、输入 Token 数、输出 Token 数。卡片数据随筛选条件实时更新
时间范围筛选点击总览区域的时间标签：今天 / 近7天 / 近30天 / 近一年快捷标签一键切换时间范围。切换后总览卡片、排行榜同步刷新。默认展示「近7天」
部门筛选点击总览区域的「所有部门」下拉框按组织架构中的部门过滤统计数据，选择后卡片、排行榜均按该部门数据展示
用户排行总览区域右侧自动展示按 Token 消耗量降序展示 Top 5 用户（剩余滚动展示），显示排名、用户名、总Token，输入Token，输出Token
智能体排行总览区域右侧按 Token 消耗量降序展示 Top 5 智能体（剩余滚动展示），显示排名、智能体名、总Token，输入Token，输出Token，可快速了解各智能体的资源占用情况
二、Token 用量趋势
位于总览区域中部，以折线图展示 Token 消耗随时间的变化趋势，并支持与上一周期对比。
功能点触发方式说明
每日/每月切换点击趋势区域的「每日/每月」切换标签「每日」模式按天展示所选时间范围内每天的 Token 消耗；「每月」模式按月聚合展示消耗趋势
环比对比切换每日/每月时自动叠加「每日」模式叠加昨日数据作对比（图例：今日 / 昨日）；「每月」模式叠加上月数据对比（图例：本月 / 上月）
数值悬浮鼠标悬浮在图表节点上弹出浮层展示该时间点的具体 Token 消耗数值
三、Token 用量详情
位于页面下方，以表格形式列出每条调用记录，支持多维度筛选、排序与分页。默认展示「全部」的数据。
功能点触发方式说明
详情列表页面下方「Token 用量详情」区域自动展示以表格形式列出每条调用记录，字段包括：日期、供应商、模型类型、模型名称、智能体、用户、总 Token 数、输入 Token 数、输出 Token 数
详情时间筛选在详情区域顶部选择时间标签：今天 / 近7天 / 近30天 / 近一年 / 全部独立筛选详情表的日期范围，不影响总览区域的时间选择。选择「全部」则展示所有数据
详情自定义日期在详情区域的时间标签旁选择起止日期可手动指定任意日期区间，与时间标签联动更新
详情下拉筛选点击详情区域各下拉框支持按供应商、模型类型、智能体、模型名称、用户、部门多维度组合筛选，各筛选条件之间取交集，筛选结果实时更新。注：当总览区域已选择部门时，详情区域的部门下拉框自动显示该部门
列排序点击详情表头「日期 / 总Token数 / 输入Token数 / 输出Token数」点击切换升序↑ / 降序↓排列，未激活时显示↕。首次点击某列默认为降序，再次点击切换为升序。切换排序后自动回到第一页
分页点击详情表底部的页码 / 每页条数默认每页展示 10 条记录，可在 10 / 20 / 50 条/页之间切换，支持翻页浏览所有符合条件的数据
筛选联动修改任意筛选条件自动触发总览区域的时间范围和部门筛选会同步影响详情表；详情区域的筛选条件独立作用于详情表。所有筛选条件变化时，表格自动回到第一页
四、导出报表
位于 Token 数据总览区域，点击「导出报表」按钮可将当前筛选条件下的统计数据导出为 Excel 文件，便于线下分析与存档。
功能点触发方式说明
导出按钮点击 Token 数据总览区域「全部部门」下拉框右侧的「导出报表」按钮将当前页面展示的统计数据导出为 .xlsx 格式的 Excel 文件，自动下载到本地
数据总览自动包含在导出文件中导出所选时间范围内的总消耗 Token、总调用次数、输入 Token、输出 Token四项汇总指标
用户 Token 排行自动包含在导出文件中导出用户 Token 排行数据，包含排名、用户名、总 Token、输入 Token、输出 Token
智能体 Token 排行自动包含在导出文件中导出智能体 Token 排行数据，包含排名、智能体名、总 Token、输入 Token、输出 Token
Token 用量详情自动包含在导出文件中导出当前筛选条件下的详细数据，包含日期、供应商、模型类型、模型名称、智能体、用户、总 Token 数、输入 Token 数、输出 Token 数等字段
导出文件命名自动生成文件名格式：Token统计报表_开始日期_结束日期_部门.xlsx，部门为当前筛选的部门名称，未筛选部门时省略部门后缀
筛选条件联动导出时自动读取导出内容基于当前页面的筛选条件（时间范围、部门等），确保导出数据与页面展示一致
