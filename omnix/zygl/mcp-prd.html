MCP 连接器管理后台 功能说明

1. 页面结构

区域说明
列表页主 Tab（企业连接器 / 连接器市场）+ 回收站 + 设置分类（下拉）+ 添加连接器（下拉）+ 筛选区 + 卡片网格（全量展示，不分页）
详情页整页切换（非弹窗），含工具列表与在线调试
回收站页整页切换（非弹窗），标题「连接器」，含 Tab、搜索与批量操作（全量展示，不分页）
弹窗新增/编辑企业连接器、新增/编辑市场连接器、删除确认、彻底删除确认、类别管理、类别新增/编辑、类别删除确认；另有非模态的悬浮提示窗（用于已使用提醒，可拖动、仅手动关闭）

顶栏下拉入口

  • 设置分类：点击展开下拉菜单（右对齐），含「企业连接器」「连接器市场」两项；两项均打开类别管理弹窗，弹窗标题随入口显示「企业连接器类别管理 / 连接器市场类别管理」。
  • 添加连接器：点击展开下拉菜单（右对齐），含「企业连接器」「连接器市场」两项；「企业连接器」打开企业自建 MCP 表单（第 5 节），「连接器市场」打开市场授权表单（第 6 节），不再随当前 Tab 自动切换表单。
  • 点击页面其他区域收起下拉；两个下拉互斥展开。

2. 主 Tab 与筛选

  • 主 Tab：企业连接器 / 连接器市场（按数据来源字段区分，分别为企业自建与市场接入）。
  • 搜索：按名称模糊匹配（转小写后包含即命中），输入即触发。
  • 分类下拉：「全部分类」+ 类别管理中状态为「启用」的类别（不包含停用类别）。
  • 状态下拉：全部状态 / 已发布 / 未发布。
  • 归属下拉：全部 / 我的（创建人为当前登录用户）。仅企业连接器页显示；切到市场页时自动重置为「全部」。
  • 列表全量展示筛选结果，不分页；左下角显示「共 N 条」，无结果显示空态「暂无匹配的 MCP 服务」。

3. 卡片列表

卡片元素

  • 图标规则：优先显示上传头像；无头像时显示名称首字符（背景取该连接器主题色，无主题色时从颜色池取色）。
  • 名称、归属（自定义→@ 企业，官方→@ 官方）、描述（2 行截断，鼠标悬停显示全文）。
  • 底部：创建人、日期、工具数、调用数、启用开关。
  • 授权状态标签（仅连接器市场卡片）：名称后显示。✓ 已授权 API Key 已配置且可用（绿底绿字描边）；⊗ 未授权 API Key 为空（灰底灰字描边）。保存授权后变为已授权，移除 API Key 后变为未授权，即时刷新卡片。
  • 悬停显示「编辑」「删除」按钮（点击不触发卡片跳转）。

交互

操作行为Toast
点击卡片进入详情页—
编辑（企业）打开「编辑企业连接器」弹窗（编辑态），回显全部字段—
编辑（市场）打开「编辑市场连接器」弹窗（编辑态），回显全部字段—
删除先弹确认弹窗（标题「确定删除此 MCP 服务？」，副文案「删除后可在回收站恢复」，按钮 取消/确认）；点「确认」时校验：若连接器被专家引用（引用名单非空），弹出悬浮提示窗（白底卡片 + 黑色 ⚠ 图标，文案「专家『{引用方名单、号分隔}』已经引用了这个资源，请调整后再操作！」，可按住拖动到任意位置、不自动消失，仅点击右上角 ✕ 关闭），阻断删除；未被引用则移入回收站（列表移除，回收站置顶）。「取消」/✕/遮罩/Esc 关闭不操作未被引用时确认后：已将「{名称}」移入回收站
启用/停用开关切换启用状态。停用时校验：若被专家引用（引用名单非空），悬浮提示窗提醒「专家『{引用方名单、号分隔}』已经引用了这个资源，请调整后再操作！」（同样可拖动、仅手动关闭），阻断停用，开关保持原状态；启用不校验已启用「{名称}」 / 已停用「{名称}」

4. 详情页 & 工具调试

  • 头部：返回按钮、图标、名称、创建人、日期、描述。
  • 统计：总调用次数、工具数。
  • 工具列表为手风琴：点击行展开/收起参数表单；参数渲染 名称 (类型) *，输入框占位提示为参数描述；无参数显示「该工具无需参数」。

运行校验与状态

  1. 必填参数为空 → 自动聚焦第一个缺失项，Toast：请填写必填参数：{参数名}
  2. 通过 → 运行 按钮禁用，文案变「运行中…」，结果区灰底显示「正在调用工具…」。
  3. 完成（原型 800ms 模拟）→ 按钮恢复，结果区绿底输出 JSON（含工具名、状态、入参、输出）。入参仅包含已填写的参数，未填的非必填参数不提交。

5. 企业连接器新增/编辑

由顶栏「添加连接器」下拉的「企业连接器」项进入（新增态），或由企业连接器卡片的「编辑」按钮进入（编辑态）。弹窗标题随模式与入口显示：新增企业连接器 / 编辑企业连接器。

字段校验
头像选填；JPG/PNG，≤ 2MB；超限 Toast 头像大小不能超过 2MB 并清空选择。头像旁市场链接（魔搭/百炼/MCPso）为原型占位，点击 Toast 跳转到{市场名}市场（原型演示）
类别 *多选标签，至少 1 个；未选 Toast 请至少选择一个类别
连接器名称 *必填，最长 40 字
传输协议 *必填，下拉：SSE / Streamable HTTP
是否需要客户端内置 *下拉：是 / 否，默认「否」
描述 *必填，最长 240 字
服务地址 *必填，需为合法 URL 格式，占位提示示例 http://localhost:8080/mcp
HTTP Headers选填，JSON 格式文本

按钮

  • 测试：服务地址为空 → Toast 请先填写服务地址；否则 Toast 正在测试连接 {url} …，900ms 后 连接成功 ✓（原型演示），并解析出该服务的工具列表。
  • 保存：类别校验在原生必填校验之前执行；新增 Toast 连接器已保存，编辑 Toast 连接器已更新；保存后重置表单/头像/类别，关闭弹窗。新增时默认属性：归属为「自定义」、数据来源为企业连接器、筛选主分类取所选类别第一项、创建人为当前用户、工具数/调用数为 0。

6. 市场连接器新增/编辑

由顶栏「添加连接器」下拉的「连接器市场」项进入（新增态），或由市场连接器卡片的「编辑」按钮进入（编辑态）。标题随模式与入口显示「新增市场连接器 / 编辑市场连接器」，标题下副文案：「配置凭据后，所有成员都可以在管理端和客户端使用此连接器。」

字段：头像（同 2MB 校验，旁附百炼平台提示及外链）、类别多选、连接器名称、是否内置、描述、服务地址、API Key（必填，密码框输入，眼睛图标切换明文/密文，附「如何获取」外链）。

手动校验顺序（任一失败即 Toast 并中断）

#条件Toast
1名称为空请输入连接器名称
2描述为空请输入描述
3服务地址为空请输入服务地址
4API Key 为空请输入 API Key
5类别未选请至少选择一个类别
  • 保存：编辑态 Toast 授权已保存；新增态 Toast 连接器已保存。新增时默认属性：归属为「官方」、数据来源为连接器市场、筛选主分类取所选类别第一项、工具数/调用数为 0。保存后卡片授权标签更新为「已授权」。
  • 移除 按钮：仅编辑态显示；无 API Key 时禁用。点击后清空 API Key、关闭弹窗、刷新列表（卡片授权标签变为「未授权」），Toast 授权已移除。

7. 回收站

整页视图（非弹窗），由列表页顶栏「回收站」按钮进入（按钮带红色角标显示数量，为 0 时隐藏角标）。进入时清空勾选状态；点右上角 ‹ 退出回收站 返回列表页。

  • 标题：连接器。
  • Tab：全部 / 企业连接器 / 连接器市场（按数据来源过滤）。
  • 搜索：占位「搜索回收站」，按名称模糊匹配，输入即触发。
  • 卡片：图标、名称、归属、描述（2 行截断）、删除信息（在 YYYY/MM/DD 被 {操作人} 删除，移入回收站时记录删除时间与操作人）；右上角为勾选框；底部操作：↺ 恢复 与红色 彻底删除。
  • 批量操作（与搜索同行，靠右）：全选（勾选当前筛选的全部结果，支持半选态）、批量恢复、批量删除；无勾选时两个批量按钮禁用。
  • 列表：全量展示筛选结果，不分页；左下角显示「共 N 条」；空态文案「回收站是空的」。
操作行为Toast
↺ 恢复（单个）回到列表顶部已恢复「{名称}」
彻底删除（单个）先弹确认弹窗（标题「确认彻底删除？」，正文「彻底删除后不可恢复，确认删除『{名称}』？」，按钮 取消 / 彻底删除），确认后永久移除已彻底删除「{名称}」
批量恢复勾选项全部回到列表已恢复 N 个连接器
批量删除先弹确认弹窗（正文「彻底删除后不可恢复，确认删除选中的 N 个连接器？」），确认后永久移除已彻底删除「{名称列表}」

8. 类别管理

由顶栏「设置分类」下拉进入（企业连接器 / 连接器市场两个入口），弹窗标题随入口显示「企业连接器类别管理 / 连接器市场类别管理」。由「类别管理」弹窗 + 「类别新增/编辑」弹窗组成。表格列：类别名称、排序、状态（启用 标签）、技能数、操作（编辑/删除）。

类别表单

字段校验
类别名称 *必填，最长 20 字；为空 Toast 请输入类别名称
排序数字，默认 0
状态启用 / 停用
操作行为Toast
新增保存追加到类别表末尾类别已新增
编辑保存更新原类别类别已更新
删除弹确认弹窗（标题「确认删除类别」，正文「类别『{类别名}』下还有 N 个关联连接器，删除后这些连接器将同步删除分类。确认删除？」，N 按实际关联数计算，为 0 时显示「下暂无关联连接器」；按钮 取消 / 删除）。确认后级联移除所有连接器已选类别中的该类别（筛选主分类指向被删类别时改取剩余类别第一项），若当前分类筛选正是被删类别则重置为「全部分类」已删除类别「{名称}」
