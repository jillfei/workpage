# Markdown 完整常用语法

## 1. 标题

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 2. 文本样式

```
**粗体**
*斜体*
***粗斜体***
~~删除线~~
==高亮==
行内`代码`
```

效果：
**粗体**
*斜体*
***粗斜体***
~~删除线~~
==高亮==
行内`代码`

## 3. 列表

### 无序列表


- 项目1
- 项目2
  - 子项目
* 也可以用星号


### 有序列表


1. 第一条
2. 第二条
   1. 子项


### 任务列表

```
- [x] 已完成
- [ ] 未完成
```

## 4. 引用

```
> 一级引用
>> 嵌套引用
```

> 
> 一级引用
> 
> 
> > 
> > 嵌套引用

## 5. 代码块


python
print("hello world")


```
print("hello world")
```

## 6. 分割线

```
---
***
___
```

---

## 7. 链接 & 图片

```
[链接文字](https://www.example.com "可选标题")

![图片alt文字](图片地址.jpg "可选标题")
```

## 8. 表格

```
| 姓名 | 年龄 | 城市 |
| ---- | ---- | ---- |
| 张三 | 22   | 杭州 |
| 李四 | 25   | 北京 |

# 对齐控制
|左对齐|居中|右对齐|
|:---|:---:|---:|
|a|b|c|
```

| 姓名 | 年龄 | 城市 |
| --- | --- | --- |
| 张三 | 22 | 杭州 |
| 李四 | 25 | 北京 |

| 左对齐 | 居中 | 右对齐 |
| --- | --- | --- |
| a | b | c |

## 9. 转义字符

`\` 用来转义特殊符号：`\* \# \[ \]`

```
\*不是斜体，就是星号*
```

## 10. 脚注（部分编辑器支持）

```
文本[^note1]

[^note1]: 这里是脚注内容
```

## 11. HTML 混写

Markdown 支持内嵌 HTML

```
<span style="color:red">红色文字</span>
```

> 
> 提示：不同平台（GitHub、Obsidian、语雀、掘金）对部分扩展语法支持略有差异。
