NeoOmni 是一款面向中大型企业 / 政企客户的企业级智能体编排平台，以四端协同架构（BOSS 端 / GPT 端 / Chat 端 / 桌面端）覆盖"租户管理—智能体开发—对话使用—桌面工作流"全链路，并以私有化部署 + 数据不出域 + 行业模板切入制造、化工、能源、金融等高合规场景。

一句话定位：把 Dify 的开发力、Coze 的易用性、WorkBuddy 的桌面入口、Agentar 的合规力，封装进一个私有化、懂制造 / 化工业务的四端平台，填补"既安全合规、又懂产业"的空白带。

立项本质：不是再造一个聊天机器人，而是填补企业从"试验智能体"到"规模化用好智能体"之间的产品化鸿沟——以可治理、可审计、可私有化、可嵌入工作流的能力构建差异化护城河。

① 私有化安全合规
原生多租户隔离、RBAC 细粒度权限、私有化部署、数据不出域；RAG 强制 + 置信度阈值 + 人工在环三重控幻觉。呼应三部门"决策权限边界 + 注册平台"监管要求 [P2]。
② 四端统一入口
BOSS 端治理、GPT 端开发、Chat 端使用、桌面端工作流——一个平台覆盖"管 / 建 / 用 / 干"，降低企业多工具拼装成本。
③ 行业资产沉淀
以制造 / 化工 / 纺织行业方案包 + 数据集资产形成可复制交付，把项目制交付升级为"平台 + 模板"的产品化模式。

治理即卖点：将 BOSS 端"配额 / 模型管控 / 审计"作为差异化能力，直接回应 Gartner 预警中 40%+ 代理型项目被取消的"风险管控不足"根因 [D2]。

1 项目预览

1.1 项目背景与 Why

企业智能体正从"尝鲜"走向"生产级部署"。McKinsey 2025 调研显示 88% 企业已在至少 1 个职能使用 AI、62% 至少处于智能体试验阶段 [D1]，但仅 6% 企业从 AI 拿到显著 EBIT、仅 23% 实现规模化 [D1]。Gartner 更预警到 2027 年底超过 40% 的代理型 AI 项目将被取消，主因是成本失控、价值不清、风险管控不足 [D2]。

矛盾点在于：需求侧已验证，但供给侧呈"哑铃型"——一端轻量但强绑公有云（Coze / 元器），一端重但昂贵（蚂蚁 Agentar / 华为）。中间存在一个空白带：既私有化安全合规、又深耕制造业 / 化工业务 Know-How、且提供从开发到桌面端统一入口的产品。NeoOmni 四端架构正是为填补这一空白而生。

1.2 项目目标

北极星指标
私有化部署的月活跃智能体调用次数——衡量平台是否真正进入企业生产流程，而非"搭了不用"。该指标直接对应 IDC"仅 18% 纳入核心流程"的差距 [M3]。
业务目标（3 年）
  • 成为制造 / 化工行业私有化智能体平台的差异化标杆；
  • 打通"开发—治理—使用—桌面"全链路四端体验；
  • 形成可复制的行业方案包与数据集资产（详见 §4 产出）。
驱动指标：四端开通率、上线智能体数、行业模板复用率、私有化部署数、单客户 ARR、续约率。

1.4 非目标（Non-goals · 范围控制）

明确不做
  • 不直接做通用 C 端流量产品，避开与巨头的正面竞争；
  • 不自研底层大模型，采用多模型热插拔接入；
  • 首期不铺公有云大规模 SaaS，聚焦私有化政企。
边界说明
以"平台 + 行业模板"模式交付，行业深度由样板客户共建沉淀，而非一次性全行业铺开。技术可行性优先，不承诺当前工程无法实现的泛化能力。

2.4 竞争格局与空白带

2025 私有化市场前五：火山引擎 HiAgent（17.8%） > 腾讯云 ADP（8.8%）> 阿里云百炼专属版（8.6%）> 蚂蚁数科 Agentar（非云厂商第一）> 电信 AI [C4] IDC 2025。公有云前三：火山引擎扣子、百度智能云千帆、腾讯云 ADP。

阵营代表与 NeoOmni 关系
开源灵活型Dify（148K+ Stars、280+ 企业客户 [C1]）、LangChain、n8n对应 NeoOmni 的 GPT 端（类 Dify 编排），但缺企业级多租户 / 安全治理

桌面入口型腾讯 WorkBuddy（PC 月访问 2097 万、国内第一 [C3]）对应 NeoOmni 桌面端，但偏 C 端通用
全栈高合规型蚂蚁 Agentar、华为盘古直接对标 NeoOmni 主航道，但价格高昂、行业 Know-How 弱
关键洞察：现有阵营缺少"既私有化安全合规、又深耕制造业 / 化工业务、且提供开发到桌面统一入口"的产品。NeoOmni 以"数据不出域 + 行业样板 + 四端协同"切入，错位竞争，避开 C 端流量战。

2.5 市场论证结论

市场成立，且窗口期明确。① 规模高速增长（CAGR 107% [M3]）；② 私有化是当下收入主战场（占 87.5% [M2]）；③ 政策强力托底（2027 >70% 普及率 [P1]）；④ 需求已实证但"用好"存在巨大产品化空间（仅 18% 纳入核心 [M3]）；⑤ 竞争存在"私有化 + 行业 Know-How"空白带。NeoOmni 的产品定义与这一空白带高度契合，立项具备充分的市场依据。

MVP-A · 补齐标配
