代理型 AI 进入企业级爆发期，平台层是确定性最高的价值捕获环节。

  • 全球 AI Agent 市场预计从 2025 年 $78.4 亿增至 2030 年 $526.2 亿（CAGR 46.3%）[M1]；另一机构 Grand View Research 给出 2030 年 $503.1 亿、CAGR 45.8% 的相近预测[M1b]，两大机构高度一致。
  • Gartner 预测到 2028 年 33% 的企业软件将内嵌代理型 AI（2024 年不足 1%）[M4]；IDC 判断 AI 超级周期已从"基础设施建设"转向"企业级应用爆发"，"Tokens 是成本核心，Agent 是价值核心"[M5]。
  • 中国市场增速领先全球：赛迪顾问测算 2025 年中国智能体市场 78.4 亿元、2026 年 135.3 亿元（同比 +70%）[M2]；IDC 中国智能体开发平台 2025 年软件收入约 20 亿元，其中私有化 17.5 亿元构成主体[M3]。
  • 政策强驱动：国务院《人工智能+行动意见》明确 2027 年智能体普及率 >70%、2030 年 >90%[P1]；三部门《智能体规范应用与创新发展实施意见》列出 5 方向 19 个典型场景，并首次从国家层面明确"用户保留最终决策权与叫停权"[P2]。
💡 核心判断
  • 市场处于"政策 + 资本 + 技术"三重共振的导入期，智能体开发 / 治理平台（即 NeoOmni GPT端 + BOSS端）是私有化政企市场最稳妥的切入点——IDC 数据显示私有化占中国开发平台收入的 87.5%[M3]。
  • 四端一体化（开发 + 治理 + 使用 + 桌面）是当前国内竞品中覆盖最完整的架构，可形成差异化护城河。

需求真实存在，但"规模化落地"是核心鸿沟——这正是 NeoOmni 的机会。

  • McKinsey 2025 调研：88% 企业已在至少一个职能使用 AI，但仅 23% 开始规模化智能体，仅约 6% 为高绩效者（AI 贡献 >5% EBIT）[D1]。
  • 62% 企业"至少在试验"智能体，但"真正规模化部署的不到 10%"[P2]——技术碎片化、安全性存疑、难以融入工作流是横亘在企业面前的"三座大山"。
  • Gartner 预警：到 2027 年底超过 40% 的代理型 AI 项目将被取消，主因成本失控、业务价值不清或风险管控不足[D2]。
需求缺口 = NeoOmni 价值锚点：企业不需要"再一个聊天机器人"，而是需要"能治理、可审计、可私有化、能嵌入工作流"的智能体平台。NeoOmni 的 BOSS端（租户 / 配额 / 模型管控）与 GPT端（可视化编排 + 知识基础设施 + Token 运营）正是为填平"试验 → 规模化"鸿沟而生。

竞争已成"巨头主场"，但四端全覆盖的整合者仍稀缺。

  • GPT端对标 Dify：GitHub 148K+ Stars、280+ 企业客户、140 万+ 部署、2026-03 完成 $30M Pre-A（红杉中国领投，估值约 $180M）[C1]——开源生态与全球化是其主要壁垒。
  • Chat端对标 Coze扣子：已有 100,512,211 个 Agent 在工作、Web 端月活 1500 万、开发者 300 万+、企业客户 8 万+[C2]——零代码与渠道分发是壁垒。
  • 桌面端对标 WorkBuddy：2026-03 上线，6 月 PC 端月访问 2097 万次居国内第一（易观 Q2），日活突破 1300 万[C3]——生态导流（微信 / 企微 / 腾讯文档）是壁垒。
  • 私有化对标 HiAgent（火山引擎）：IDC 2025 中国智能体开发平台私有化市场份额第一[C4]。
🎯 竞争空位
  • Dify 强在"开发"、Coze 强在"使用"、WorkBuddy 强在"桌面"、HiAgent 强在"私有化"——但没有一个产品把"开发 + 治理（BOSS）+ 使用（Chat）+ 桌面"四端打通。
  • NeoOmni 的差异化不是单点超越，而是以 BOSS端租户治理为中枢，串联 GPT/Chat/桌面三端，为企业提供"一个平台管全部智能体"的统一体验。

NeoOmni 四端架构：以"治理"统领"构建—使用—桌面"全链路。

  • BOSS端（租户管理）：租户开通 / 配额 / 部署模式（私有化 / 公有云）/ 模型供应商配置——对应企业"买得起、管得住"的采购与治理诉求。
  • GPT端（智能体开发）：可视化编排、知识基础设施（RAG / 知识图谱 / 数据库 / 提示词 / 工具）、运营配置（Token 统计）、组织管理（4 级角色 / SSO）——对标 Dify 并补强企业治理。
  • Chat端（智能体使用）：基础模型体验、智能问答、智能体广场——对标 Coze 扣子，承接业务人员与终端用户。
  • 桌面端（全场景办公工作台）：对标 WorkBuddy，将智能体能力嵌入文档 / 表格 / 会议等办公现场。
产品定位一句话：NeoOmni 是面向中大型企业的"智能体操作系统"——BOSS端管租户、GPT端造智能体、Chat端用智能体、桌面端把智能体带进工作现场，四端共享一套治理与知识底座。

GTM 主线：以"私有化 + 行业模板 + 治理合规"切入政企市场，避开与巨头的 C 端流量战。

  • 主攻私有化政企：私有化占中国开发平台收入 87.5%[M3]，且符合三部门"分级治理、备案检测、注册平台"的监管导向[P2]。
  • 行业模板先行：赛迪指出制造 / 能源 / 金融 / 政务四大领域占中国智能体市场超 70%[M2]，可作为 NeoOmni 行业模板的优先切入方向。
  • 治理即卖点：将 BOSS端"配额 / 模型管控 / 审计"作为差异化能力，回应 Gartner 40% 取消预警中的"风险管控不足"根因[D2]。

风险可控，但边界必须写清。

  • 市场风险：Gartner 预警 40%+ 代理型项目 2027 前取消[D2]；McKinsey 显示仅 6% 企业从 AI 拿到显著 EBIT 提升[D1]——需以"可量化 ROI"而非"技术炫技"驱动签约。
  • 合规风险：三部门要求厘清"用户本人决策 / 授权决策 / 智能体自主决策"边界，并探索智能体注册平台[P2]——NeoOmni 须在 GPT端 / BOSS端内置决策权限与审计能力。
  • 竞争风险：巨头（字节 / 腾讯 / 阿里 / 火山）在资本、生态、流量上全面占优[C3]，NeoOmni 不应在 C 端通用赛道正面交锋。
  • Non-goals（明确不做什么）：不自研基础大模型；不替代 ERP/MES 等现有系统（而是让其"活"起来）；不做 C 端泛娱乐 / 情感陪伴类智能体。

  • 文档 / 表格 / 会议等办公现场嵌入
  • 本地文件与私有数据协同
  • 跨应用任务执行
  • 与 BOSS端配额 / 权限联动

7.1 差异化优势

🏆 NeoOmni 的四项核心优势
  • 治理优先：BOSS端将"配额 / 模型 / 审计"作为平台级能力，呼应三部门决策权限与注册平台要求 [P2]，是政企采购的硬门槛。
  • 四端一体：开发（GPT）→ 治理（BOSS）→ 使用（Chat）→ 桌面（桌面端）共享一套知识 / 权限底座，避免"工具孤岛"。
  • 私有化友好：契合中国开发平台 87.5% 私有化收入结构 [M3]，数据不出域。
  • 行业模板：直接映射三部门 19 个典型场景 [P2] 与制造 / 能源 / 金融 / 政务四大高占比领域 [M2]。

09风险与边界（Non-goals）

明确风险敞口与"不做什么"，防止范围蔓延与战略误判。

9.1 风险登记

风险描述缓解来源
项目取消率高40%+ 代理型项目 2027 前取消签约前置"可量化 ROI + 治理闭环"[D2]
价值难证仅 6% 企业从 AI 获显著 EBIT行业模板绑定明确业务指标[D1]
合规压力决策权限 / 注册平台 / 分级治理BOSS端内置权限与审计[P2]
巨头碾压字节 / 腾讯 / 阿里资本与生态占优错位竞争：私有化政企 + 行业[C3]

9.2 Non-goals（明确不做什么）

  • ❌ 不自研基础大模型——聚焦编排与治理，模型通过 BOSS端多供应商接入。
  • ❌ 不替代 ERP / MES 等现有系统——定位"让现有系统活起来"的智能体层，而非重构。
  • ❌ 不做 C 端泛娱乐 / 情感陪伴智能体——遵循三部门低风险领域自律导向，专注企业价值场景。
  • ❌ 不在通用 C 端流量赛道与巨头正面交锋——资源应集中于私有化政企与行业模板。
