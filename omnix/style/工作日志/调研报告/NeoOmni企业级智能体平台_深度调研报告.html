L1 降本
可视化编排将开发周期从"月级"压缩至"天级"；行业实践显示可显著缩短交付[D2] Gartner
L2 增效

行业方案包对外输出，平台从成本中心转为利润中心

1.4 行业分布与政策驱动

  • 行业集中度：政务、制造、能源、金融四大行业智能体市场份额合计 超过 70%（赛迪顾问），即落地核心战场是业务流程复杂、系统异构、合规刚性强的实体经济领域[M1] 赛迪。
  • 渗透率拐点：Gartner 预测 2026 年底 40% 企业软件嵌入智能体（2025 不足 5%）[M4] Gartner；IDC 预计 2026-2027 是活跃智能体数量增速最快两年（单年同比 >200%），2031 年达 3.5 亿个活跃智能体[M3] IDC。
  • 政策红利：2026 年初《智能体规范应用与创新发展实施意见》首次从国家层面对技术底座、安全治理、场景应用、生态建设提出系统要求，利好合规型私有化平台[P2] 三部门；国务院《人工智能+行动意见》明确 2027 年智能体普及率 >70%、2030 年 >90%[P1] 国务院。
  • 供给侧膨胀：2026 年 2 月国内 AI 智能体服务商已突破 300 家，但 IDC 调研显示 仅 18% 企业将智能体纳入核心业务流程，60% 仍在评估/试点——"会用"到"用好"之间存在巨大产品化空间[M3] IDC。

2 需求验证 — 痛点、需求矩阵与角色

2.1 企业落地智能体的三大核心痛点

痛点一 · 能力碎片化
缺乏统一的 RAG、知识图谱与工具链管理；工具链分散，AI 可行性验证周期长；无法快速将 AI 能力投入生产。
痛点二 · 开发门槛高
业务人员无法直接参与开发，高度依赖研发；AI 人才稀缺；需求交付周期长。Gartner 指出集成遗留系统技术复杂、成本高，是落地主要障碍之一[D2] Gartner。
痛点三 · 安全合规风险
公有云调用存在数据泄露隐患；缺乏细粒度权限管控；无 Token 成本核算机制，资源浪费。三部门要求厘清决策权限、探索智能体注册平台[P2] 三部门。

3 行业痛点与全价值视角

3.1 企业级智能体落地的真实障碍（"最后一公里"问题）

IDC 指出，采购企业关注点已从"能否搭建"扩展到测试、发布、观测、优化、治理[M2] IDC。行业普遍归纳出四大深层障碍：

① 数据不出域的刚性
制造/化工/金融客户核心工艺、配方、报价为商业机密，公有云模式不可接受。平台须支持私有化 + 逻辑/物理隔离双模式。
② 异构系统连接
企业内 ERP/OA/MES/PLM 系统林立、老设备无 API。智能体须能对接业务系统读写，而非停留在对话层。Gartner 将"集成遗留系统技术复杂、成本高"列为落地主要障碍[D2]。
③ 幻觉与可信
高风险场景（合同/风控）须 RAG 强制 + 置信度阈值拦截 + 人工在环，否则业务不敢用。三部门要求厘清"用户本人决策 / 授权决策 / 智能体自主决策"边界[P2]。
④ 成本黑箱
缺乏 Token 级计量与分摊，AI 投入产出无法量化，CIO 难向管理层交代。Gartner 将"成本失控 / 价值不清"列为项目被取消的首要诱因[D2]。

3.2 全价值视角：四层递进模型

L1 · 工具替代（门票钱）
可视化编排将开发周期从"月级"压缩至"天级"；业务人员可低门槛参与。解决"有没有"的问题。
L2 · 流程重构（增长引擎）
智能路由 + 缓存降低 Token 成本；需求响应月级→天级；业务流程自动化闭环。
L3 · 知识资产化（护城河）
企业隐性经验 → 结构化知识资产（知识图谱 / RAG / 行业语料），降低关键人依赖。
L4 · 商业变现（利润中心）
行业方案包对外输出；平台从成本中心转为利润中心。
价值锚点：NeoOmni 不应只卖"L1 替代软件预算"（盘子有限），真正的价值在 L2-L4——把企业分散的数据、流程、经验转化为可复用、可变现的数字资产。行业 Know-How 与数据资产沉淀，是云厂商与开源产品无法短期复制的护城河。

3.3 ROI 视角（价值可证性框架）

企业 AI 投入"黑箱"是项目被取消的首要诱因之一（Gartner：成本失控 / 价值不清）[D2]。NeoOmni 的价值兑现必须以可量化为前提，建议从以下维度建立 ROI 归因模型（具体数值属企业内部测算，本报告不列）：

说明："待补"指当前产品化短板，对应第 6 章优先级规划（P0/P1 须立即补齐的行业标配能力）。功能对比基于公开产品能力与行业通用认知，精确能力边界以各厂商官方文档为准。

4.3 重点竞品画像

Dify（开源灵活型）
优势：开源可自托管、RAG 强、社区生态丰富（GitHub 148K+ Stars、280+ 企业客户、$30M Pre-A 红杉中国领投）[C1]，是 GPT 端最直接的参照系。
劣势：企业级多租户/权限/私有化运维靠自研；无独立用户端；缺统计看板。NeoOmni 对策：以"企业级管理增强 + Chat/桌面端入口"差异化。
Coze 扣子（生态协同型）
优势：零代码、插件生态、一键分发（100,512,211 个 Agent 在工作中、Web 月活 1500 万、开发者 300 万+）[C2]，是 Chat 端参照系。
劣势：私有化有限、深度系统集成弱、多智能体协同不足。NeoOmni 对策：Chat 端取其易用，但底座走私有化 + 业务系统连接。
火山 HiAgent / 腾讯 ADP / 阿里百炼（云厂商）
优势：全栈、生态、模型能力；HiAgent 居私有化份额第一（17.8%）[C4]。
劣势：深度绑定公有云、数据合规存疑、定制化弱、行业 Know-How 浅。NeoOmni 对策：以"数据不出域 + 行业样板"抢私有化高合规客户。
蚂蚁 Agentar（全栈高合规型）
优势：金融级可信、全链路审计、金融 MCP 广场。
劣势：价格高昂、偏金融、通用产业 Know-How 弱。NeoOmni 对策：在制造/化工复制其"高合规 + 行业 MCP"打法，但更下沉、更垂直。
WorkBuddy / 桌面端原生（腾讯龙虾等）
2026 年 6 月 17 款桌面端 AI 办公智能体合计访问量破 6000 万次，WorkBuddy 以 2097 万月访问量领跑[C3]。NeoOmni 桌面端对标此形态，作为四端中"员工侧生产力入口"。
联通元景（同赛道直接竞品）
对比显示 NeoOmni 在组织多级管理、群组管理、三方对接（企微）、Skill 广场、React+DAG 多智能体占优；弱在统计看板、API Key 管理、安全护栏、模板广场。指明补齐方向。

4.4 NeoOmni 差异化定位一句话

"把 Dify 的开发力、Coze 的易用性、WorkBuddy 的桌面入口、Agentar 的合规力，封装进一个私有化、懂制造化工业务的四端平台。"——填补"既安全合规又懂产业"的空白带。

5 NeoOmni 产品优势 — 四端架构与护城河

5.1 四端协同架构（核心差异化）

类似云厂商管理控制台

GPT 端

统一入口 · 智能体广场 · 场景模板

四端覆盖"模型接入 → 智能体开发 → 终端应用 → 员工桌面"全链路闭环，竞品多只覆盖其中一环。Boss 端提供独有的租户运营管控，GPT 端提供类 Dify 编排，Chat 端提供类 Coze 入口，桌面端补齐"最后一公里"员工生产力场景。

5.2 五大核心优势

① 全链路闭环
Boss-GPT-Chat-桌面端四端协同，覆盖从模型管理、智能体开发到终端应用完整链路，竞品多为单点。
② 企业级安全合规
原生多租户隔离、RBAC 细粒度权限、私有化部署、数据不出域；RAG 强制 + 置信度阈值 + 人工在环三重控幻觉。呼应三部门"决策权限边界 + 注册平台"监管要求[P2]。
③ 低代码敏捷开发
可视化拖拽编排，业务人员可零代码搭建；开发周期从"月级"压缩至"天级"，显著降低交付门槛。
④ 成本透明可控
Token 级消耗统计与成本分摊模型，ROI 可视化，解决企业 AI 投入"黑箱"。直接回应 Gartner"成本失控 / 价值不清"的项目取消主因[D2]。
⑤ 生态开放 + 行业资产
标准 API 对接三方系统、主流模型灵活切换；面向制造/化工/纺织的行业 Know-How 与数据资产沉淀，形成可复制的行业样板。
⑥ 已验证的行业样板路径
以"灯塔客户 + 行业数据集资产"做信任背书，提供"行业解决方案包"降低交付成本，形成对外可复制的一站式交付能力。

6 产品策略 — 功能优先级与路线图

6.1 功能缺口与优先级（基于竞品对比）

竞品功能对比显示：智能体创建类为当前最大短板，其次为模型服务/模型开发/数据集管理类。单 Agent 创建、对话流、工作流、模板市场、MCP、发布渠道均为行业官网标配能力，须优先补齐以消除选型硬伤。

优先级功能战略意义
P0模板市场、单 Agent 创建入场券，行业标配，必须立即补齐
P1对话流创建、工作流创建覆盖主流编排形态
P2内置系统工具、AI 提示词生成器、HTTP 工具、定时/Webhook完善工具生态
P3多 Agent、AI 快速创建、图知识库、MCP 服务/工具/广场、模型管理高级能力，扩大场景
P4发布渠道、远程数据库、效果测评、模型微调/蒸馏、数据集管理远期优化体验

6.2 分阶段功能规划

第一阶段（1-2 月）
P0+P1：模板市场、单/对话流/工作流创建。
目标：核心创建能力，满足基础使用。
第二阶段（2-4 月）
P2：内置/HTTP/工作流工具、AI 提示词生成器、定时任务。
目标：完善工具生态。
第三阶段（4-6 月）
P3：多 Agent、图知识库、MCP 服务/工具/广场。
目标：增强高级功能。

6.3 商业化路径（GTM）

  • 商业模式："平台授权 + 定制实施 + 运维服务"。私有化部署为当前政企市场最稳妥的切入点——私有化占中国开发平台收入 87.5%[M2] IDC，且符合三部门"分级治理、备案检测、注册平台"的监管导向[P2]。
  • 行业模板先行：赛迪指出制造 / 能源 / 金融 / 政务四大领域占中国智能体市场超 70%[M1] 赛迪，可作为 NeoOmni 行业模板的优先切入方向。
  • 治理即卖点：将 BOSS 端"配额 / 模型管控 / 审计"作为差异化能力，回应 Gartner 40% 取消预警中的"风险管控不足"根因[D2]。
  • ROI 驱动签约：以"可量化降本 / 增效"而非"技术炫技"驱动签约，回应 McKinsey 仅 6% 企业从 AI 获显著 EBIT 提升的落差[D1]。

7 行动计划 — 三期实施与 MVP

7.1 三期实施计划

第一期（2026 Q3 – 2027 Q1）基础能力建设
Boss 端核心、GPT 端基础开发环境、Chat 端基础对话、模型接入 3+、基础 RAG、私有化 V1。聚焦私有化 + 治理底座。
第二期（2027 Q2 – 2028 Q2）能力增强与规模化
知识图谱引擎、多 Agent 协作、高级 RAG、成本管控、组织权限完善、ERP/MES 集成；目标 50+ 智能体上线。
第三期（2028 Q3 – 2030）生态构建与商业化
多租户 SaaS、智能体市场、行业解决方案包、外部商业化输出、生态合作伙伴体系。

7.2 MVP 三阶段建议（产品化聚焦）

MVP-A · 补齐标配
优先 P0/P1：单 Agent、对话流、工作流、模板市场、MCP。让"能搭"达到行业基准，消除选型硬伤。
MVP-B · 强化治理
补齐统计看板、API Key 管理、安全护栏、Token 成本分摊。呼应 IDC"治理侧"竞争焦点[M2]，凸显企业级差异。
MVP-C · 行业样板
打包"化工/化纤/纺织行业解决方案 + 数据集资产 + 桌面端"，形成对外可复制的一站式交付。

7.3 风险与边界（Non-goals）

维度要点依据
市场风险Gartner 预警 40%+ 代理型项目 2027 前取消[D2]；McKinsey 显示仅 6% 企业从 AI 拿到显著 EBIT[D1]须以"可量化 ROI"而非"技术炫技"驱动签约
合规风险三部门要求厘清"用户本人决策 / 授权决策 / 智能体自主决策"边界，并探索智能体注册平台[P2]须内置决策权限与审计能力
竞争风险巨头（字节 / 腾讯 / 阿里 / 火山）在资本、生态、流量上全面占优错位竞争：私有化政企 + 行业模板，避开 C 端通用赛道
技术风险模型迭代快，自建能力易被追平抽象层热插拔、多模型接入、行业资产沉淀形成护城河
明确不做什么（Non-goals）：① 不自研基础大模型；② 不替代 ERP/MES 等现有系统（而是让其"活"起来）；③ 不做 C 端泛娱乐 / 情感陪伴类智能体；④ 不在通用 C 端流量赛道与巨头正面交锋。
