服务介绍

什么是 Amap Maps MCP 服务？

为实现 LBS 服务与 LLM 更好的交互，高德地图 MCP Server 现已覆盖 15 大核心服务接口，提供全场景覆盖的地图服务，包括生成专属地图、导航到目的地、订车、地理编码、逆地理编码、IP 定位、天气查询、骑行路径规划、步行路径规划、驾车路径规划、公交路径规划、距离测量、关键词搜索、周边搜索、详情搜索等。

通过高德 MCP Server 与高德地图APP无缝打通，用户可将大模型产出的攻略与高德地图APP无缝衔接。实现一键生成专属地图，将攻略中的单位、描述、行程规划等个性化信息自动导入到高德地图APP，生成一张独属于用户的私有地图，实际出行中可实现由攻略到一键导航、打车、订票的丝滑体验。

工具列表 6
maps_direction_bicycling
骑行路径规划用于规划骑行通勤方案，规划时会考虑天桥、单行线、封路等情况，最大支持 500km 的骑行路径规划
maps_direction_driving
驾车路径规划 API 可以根据用户起点终点经度坐标规划以小汽车、轿车通勤出行的方案，并且返回通勤方案的数据
maps_direction_transit_integrated
根据用户起点终点经度坐标规划综合公交（火车、公交、地铁）交通方式的通勤方案，并且返回通勤方案的数据，跨…
maps_direction_walking
根据输入起点终点经度坐标规划 100km 以内的步行通勤方案，并且返回通勤方案的数据
maps_distance
测量两个经纬度坐标之间的距离,支持驾车、步行以及球面距离测量
maps_text_search
根据用户输入的关键字搜索 POI 兴趣点信息，可设置城市及类别筛选，返回匹配的地点列表及地址、坐标等详情
