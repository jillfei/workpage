一、概述

背景与目标

在 AI Agent 平台中，MCP（Model Context Protocol）服务是扩展大模型工具能力的核心载体。用户需要将各类外部服务（如地图、邮件、即时通讯、数据库等）以 MCP Server 的形式接入 AI Agent，使 Agent 在对话过程中能够调用这些服务的 API 完成实际任务。

当前 MCP 服务的接入与管理存在以下痛点：

  • 用户需手动编写配置文件接入 MCP，门槛高、易出错
  • 缺乏统一的 MCP 管理入口，已接入的服务无法集中查看和管控
  • 无法快速了解某个 MCP 提供了哪些工具（Tools）及工具的具体能力
  • 服务的启用/禁用、编辑、卸载操作散落在不同位置，操作链路长

MCP 服务管理模块旨在建立统一的 MCP 服务管理平台，支持 MCP 服务的添加（自定义/市场安装）、编辑配置、启用/禁用、卸载、详情查看（工具列表与服务介绍），实现 MCP 服务的标准化管理和便捷使用。

用户画像

🔧 平台开发者

需要接入自定义 MCP Server 的技术用户，熟悉 SSE/Stdio/HTTP/WebSocket 协议，能自行部署 MCP 服务并通过 URL 接入。关注配置灵活性和服务地址准确性。

🏢 业务用户

需要扩展 Agent 能力但缺乏技术背景的用户，倾向于从 MCP 市场一键安装预置服务（钉钉、飞书、QQ邮箱等），关注安装便捷性和服务可用性。

👁️ 服务管理员

负责管控平台已接入 MCP 服务的管理员，需要查看所有服务状态、启用/禁用服务、编辑配置、卸载无用服务，关注管理效率和操作安全。

核心目标

目标说明
统一管理入口提供 MCP 服务的集中管理页面，支持自定义和市场两类服务的统一浏览与操作
低门槛接入自定义 MCP 通过弹窗表单填写配置；市场 MCP 一键安装，降低接入门槛
状态可视化每个 MCP 服务的启用/禁用状态、安装状态清晰可见，支持快速切换
工具能力透明详情页展示 MCP 提供的全部工具（Tools）清单及每个工具的功能描述
安全卸载卸载操作二次确认，防止误操作；卸载后服务从列表移除，状态可恢复

Non-goals（不做什么）

本模块不包含以下功能：
  • 不支持 MCP 服务的在线调试/测试调用（仅管理配置，不提供运行时调试）
  • 不支持 MCP 市场的搜索/分类筛选（市场列表为预置固定列表）
  • 不支持 MCP 服务配置的版本管理和回滚
  • 不支持 MCP 服务的权限分配（不区分用户可见范围）
  • 不支持 MCP 服务运行日志查看和调用统计
  • 不涉及 MCP Server 端的开发和部署（仅管理客户端接入配置）

用户故事

作为 平台开发者，我希望能够通过填写服务名称、传输协议、服务地址等配置信息来自定义添加 MCP 服务，以便将我自行部署的 MCP Server 接入 Agent 平台，扩展 Agent 的工具能力。
作为 业务用户，我希望能够从 MCP 市场一键安装预置服务（如钉钉、飞书、QQ邮箱），以便无需了解技术细节即可快速扩展 Agent 的外部服务能力。
作为 服务管理员，我希望能够在列表页查看所有已接入的 MCP 服务及其启用状态，并支持快速启停，以便灵活管控哪些服务对 Agent 生效，避免不必要的 API 调用。
作为 平台开发者，我希望能够查看某个 MCP 服务的详情页，了解其提供的全部工具及每个工具的功能描述，以便评估该服务的实际能力，决定是否启用或如何使用。
作为 服务管理员，我希望卸载 MCP 服务时能弹出二次确认弹窗，防止误操作，以便安全地移除不再需要的服务，避免误删导致 Agent 能力缺失。
作为 平台开发者，我希望能够编辑已接入自定义 MCP 服务的配置信息（名称、协议、地址等），以便在服务端地址变更或配置调整后快速更新接入配置。

二、功能架构与流程图

MCP 服务管理模块包含两大子功能：MCP 列表管理（服务列表、添加、编辑、启停、卸载）和MCP 详情页（服务介绍、工具列表、添加/启停/卸载操作）。两个子功能通过列表页卡片点击跳转关联。

核心交互流程

流程一：市场 MCP 安装 → 启用 → 卸载

1

点击「+」添加按钮

用户在 MCP 市场卡片右侧点击「+」按钮，按钮被加载动画（Spinner）替换，进入加载状态。

2

加载完成 + Toast 提示

约 1.2 秒后，Spinner 消失，顶部弹出 Toast「添加X成功」。卡片右侧出现启禁用开关（默认开启，绿色）和右上角三点菜单（hover 显示）。

3

启用/禁用切换

用户点击开关切换启用/禁用状态。开启为绿色，关闭为灰色。切换时仅记录状态，不弹窗确认。

4

点击三点菜单 → 卸载

用户 hover 卡片显示三点菜单按钮，点击后弹出下拉菜单（仅含「卸载」选项），点击「卸载」弹出卸载确认弹窗。

5

确认卸载 → 恢复未添加状态

确认弹窗显示「确定要卸载 X 吗？此操作不可撤销」。点击「确认卸载」后移除开关和菜单，重建「+」添加按钮，Toast 提示「已卸载 X」。

流程二：自定义 MCP 添加 → 编辑 → 卸载

1

点击「添加服务器」

用户点击右上角「添加服务器」按钮，弹出添加 MCP 弹窗。

2

填写配置并提交

填写服务器名称（必填）、上传图标（可选）、选择传输协议（必填：SSE/Stdio/HTTP/WebSocket）、描述（可选）、服务地址（必填）、HTTP Headers（可选）。提交后 Toast 提示「MCP 添加成功」。

3

点击编辑按钮

自定义 MCP 卡片右侧显示编辑（齿轮）按钮，点击弹出编辑弹窗，表单回填当前配置数据。

4

编辑保存 / 卸载

编辑弹窗左下角有「卸载」按钮（需二次点击确认：首次点击变为「确认卸载？」红色状态，3 秒内再次点击才执行卸载并移除卡片）。修改后点击「保存」更新配置。

流程三：查看 MCP 详情

1

点击 MCP 卡片

用户点击列表中任意 MCP 卡片（非按钮区域），携带 name、icon、source、added 参数跳转到 detail.html。

2

详情页展示

页面顶部展示 MCP Logo、名称、来源标签（自定义MCP/MCP市场）。内容区展示服务介绍（Lead 描述 + 服务详情说明）和工具列表（Tool name + 描述）。

3

头部操作区（按来源区分）

自定义 MCP：无操作区（隐藏）。市场 MCP 未添加：显示「添加MCP」按钮（点击 → 0.8s 加载 → Toast + 进入已添加状态）。市场 MCP 已添加：显示启禁用开关 + 三点菜单（卸载）。

三、子模块详细设计

MCP 服务管理模块包含两个子功能：MCP 列表管理（列表展示、添加、编辑、启停、卸载）和MCP 详情页（服务介绍、工具列表、头部操作）。以下分别说明每个子功能的描述、字段设计、功能清单和特殊规则说明。

🔹 3.1 MCP 列表管理

功能描述

MCP 列表管理是模块的核心入口页面，负责展示所有已接入的 MCP 服务，并支持添加、编辑、启停和卸载操作。列表按来源分为两大区块：自定义 MCP（用户通过表单配置的服务）和MCP 市场（预置可一键安装的服务）。自定义 MCP 卡片显示编辑按钮；市场 MCP 卡片在未安装时显示添加按钮，安装后切换为启禁用开关 + 三点菜单。

字段设计

字段类型必填说明
服务器名称 文本 ✅ MCP 服务名称，显示在卡片标题位置。自定义 MCP 可编辑修改；市场 MCP 为预置固定值
图标 图标 — 服务的视觉标识。市场 MCP 使用品牌色字母方块（如钉=蓝色、飞=青色）；自定义 MCP 使用内置 SVG 图标（globe/map/mail）或用户上传图片
来源 枚举 ✅ 自定义MCP / MCP市场。决定卡片的操作区形态：自定义显示编辑按钮；市场显示添加/开关+菜单
描述 文本 — MCP 服务功能描述，显示在卡片名称下方，最多两行截断
传输协议 枚举 ✅ SSE / Stdio / HTTP / WebSocket。自定义 MCP 必填
服务地址 文本(URL) ✅ MCP Server 的服务地址，如 http://localhost:8080/mcp。自定义 MCP 必填
HTTP Headers JSON — 自定义请求头，JSON 格式，如 {"headers": {"Authorization":"Bearer xxx"}}
启用状态 布尔 自动 市场 MCP 安装后默认为启用（开关绿色）。支持切换为禁用（开关灰色）
安装状态 布尔 自动 市场 MCP 的安装状态：未安装（显示+按钮）/ 已安装（显示开关+菜单）。自定义 MCP 恒为已安装
💡 市场品牌色对照：钉钉(#3370ff 蓝)、飞书(#00d6b9 青)、SQL(#0055ff 蓝)、ima(#1f1f1f 黑)、QQ邮箱(#ffb800 黄)。自定义 MCP 图标统一灰色底(#f4f4f5) + 深灰图标(#52525b)。

序号功能名称优先级功能描述

4 市场 MCP 安装 P0 点击市场卡片「+」按钮 → Spinner 加载动画（约 1.2 秒）→ Toast「添加X成功」→ 按钮区域替换为启禁用开关（默认开启）+ 右上角三点菜单
5 启用/禁用切换 P0 已安装市场 MCP 卡片右侧显示启禁用开关。开启时绿色，关闭时灰色。点击切换状态，无确认弹窗，即时生效
6 三点菜单（卸载入口） P0 已安装市场 MCP 卡片右上角显示三点菜单按钮（hover 时显示，非 hover 隐藏）。点击弹出下拉菜单，仅含「卸载」选项
7 卸载 MCP（列表） P0 从三点菜单点击「卸载」→ 弹出卸载确认弹窗（标题+副标题「此操作不可撤销」+确认文字）。确认后移除开关和菜单，重建「+」按钮恢复未安装状态。Toast「已卸载 X」
8 卸载 MCP（编辑弹窗） P0 编辑弹窗左下角「卸载」按钮，需二次点击确认：首次点击变为「确认卸载？」红色状态，3 秒超时自动恢复；3 秒内再次点击执行卸载，移除整个卡片。Toast「已卸载 X」
9 跳转详情页 P0 点击卡片（非按钮区域）跳转到 detail.html，携带 URL 参数：name、icon、source、added（是否已安装）
10 Toast 消息提示 P0 操作成功时顶部弹出黑色 Toast 提示（如「MCP 添加成功」「保存成功」「已卸载 X」），2.5 秒后自动消失
11 ESC 关闭弹窗 P1 按 ESC 键关闭当前打开的任意弹窗（添加/编辑/卸载确认）

特殊规则说明

序号规则说明
1 来源决定操作区形态 自定义 MCP 卡片右侧恒显示编辑（齿轮）按钮；市场 MCP 未安装时显示「+」按钮，安装后显示开关+三点菜单。两类卡片操作区完全不同，不混用
2 市场 MCP 安装加载时长 点击「+」后显示 Spinner 约 1.2 秒，模拟安装过程。期间按钮不可重复点击（已被 Spinner 替换）
3 三点菜单显隐规则 三点菜单按钮在卡片 hover 时显示（opacity 0→1），非 hover 隐藏。点击弹出下拉菜单，点击空白处或菜单外区域自动关闭。同时只能打开一个菜单
4 开关点击不触发卡片跳转 点击开关时 stopPropagation，防止冒泡触发卡片点击跳转详情页。编辑按钮同理
5 编辑弹窗卸载二次确认 编辑弹窗左下角「卸载」按钮采用二次点击确认机制：首次点击变红+文字变为「确认卸载？」+3 秒倒计时自动恢复；3 秒内再次点击才真正执行卸载
6 卸载后恢复状态 列表三点菜单卸载后：移除开关+菜单，重建「+」按钮，卡片恢复为未安装状态（可再次安装）。编辑弹窗卸载后：整个卡片从列表移除
7 添加/编辑表单校验 提交时校验：服务器名称非空、传输协议已选、服务地址非空。校验失败弹出 Toast 提示具体原因，不关闭弹窗
8 图标上传 添加/编辑弹窗支持点击图标区域上传图片（accept image/*），上传后预览区域显示图片，未上传时显示默认用户图标
9 弹窗关闭重置 添加弹窗关闭时重置所有表单字段和图标预览；编辑弹窗关闭时重置图标和卸载按钮状态。点击遮罩层（弹窗外部）可关闭弹窗
10 跳转参数传递 点击卡片跳转详情页时，URL 参数传递 name、icon、source、added。自定义 MCP 的 added 恒为 true；市场 MCP 根据当前是否已安装判断

🔹 3.2 MCP 详情页

功能描述

MCP 详情页展示单个 MCP 服务的完整信息，包括服务介绍（Lead 概述 + 详细说明）和工具列表（Tool name + 功能描述）。页面顶部根据来源类型展示不同的操作区：自定义 MCP 无操作区，市场 MCP 根据安装状态展示「添加MCP」按钮或启禁用开关+三点菜单。详情页通过 URL 参数接收 name、icon、source、added 四个参数动态渲染。

字段设计

字段类型来源说明
服务名称 文本 URL参数 从 list.html 跳转时通过 ?name= 传递，渲染为页面标题和 document.title
图标标识 枚举 URL参数 从 list.html 跳转时通过 ?icon= 传递。市场 MCP 映射为品牌色字母方块（钉/飞/S/i/Q）；自定义 MCP 映射为灰色底 SVG 图标（globe/map/mail）
来源类型 枚举 URL参数 从 list.html 跳转时通过 ?source= 传递，值为「自定义MCP」或「MCP市场」。决定来源标签样式和操作区形态
安装状态 布尔 URL参数 从 list.html 跳转时通过 ?added= 传递。自定义 MCP 恒为 true；市场 MCP 根据当前是否已安装判断
来源标签 Badge 派生 根据 source 派生：自定义MCP（紫色底 #eef2ff）、MCP市场（青色底 #ecfeff）。source 为空时隐藏标签
Lead 概述 文本 页面内容 服务的一句话概述，显示在内容区顶部，深灰色文字
服务详情 文本 页面内容 服务的详细说明，包含功能介绍和使用场景。分多段展示
工具数量 数字 派生 显示在「工具列表」标签旁，如「工具列表 6」
工具名称 文本 页面内容 Tool 的标识名称（如 maps_direction_bicycling），蓝色链接样式。第一个工具高亮显示（灰色底）
工具描述 文本 页面内容 Tool 的功能说明，灰色文字

功能清单

序号功能名称优先级功能描述
1 详情页头部渲染 P0 根据 URL 参数渲染 Logo（品牌色字母/灰色 SVG）、标题（name）、来源标签（自定义MCP/MCP市场）。返回导航栏显示「← MCP」可点击返回列表页
2 服务介绍展示 P0 内容区展示 Lead 概述段落 + 服务详情说明（含功能介绍和使用场景）。支持多段文本展示
3 工具列表展示 P0 展示 MCP 提供的全部工具（Tools），每项含图标+名称（蓝色链接样式）+描述。第一个工具高亮显示（浅灰底+圆角边框）。工具数量显示在标签旁
4 操作区-自定义MCP P0 自定义 MCP 详情页头部右侧操作区隐藏（不显示添加/开关/菜单）
5 操作区-市场MCP未安装 P0 显示「添加MCP」按钮。点击 → Spinner 加载（约 0.8 秒）→ Toast「添加X成功」→ 进入已添加状态（显示开关+三点菜单）
6 操作区-市场MCP已安装 P0 直接显示启禁用开关（默认开启）+ 三点菜单按钮。点击三点弹出卸载菜单，点击卸载弹出确认弹窗
7 详情页卸载 P0 从三点菜单卸载 → 确认弹窗 → 确认后移除开关和菜单，恢复「添加MCP」按钮。Toast「已卸载 X」
8 Toast 消息提示 P0 操作成功时顶部弹出黑色 Toast 提示，2.5 秒后自动消失
9 关闭菜单 P1 点击页面空白处关闭已打开的三点下拉菜单。同时只能打开一个菜单

特殊规则说明

序号规则说明
1 操作区按来源区分 自定义 MCP：操作区整体隐藏（display:none）。市场 MCP 未安装：显示添加按钮。市场 MCP 已安装：直接进入已添加状态（开关+菜单）。三种状态互斥
2 添加加载时长 详情页点击「添加MCP」后 Spinner 加载约 0.8 秒（比列表页的 1.2 秒更短），完成后 Toast 提示并进入已添加状态
3 Logo 渲染规则 市场 MCP：根据 icon 参数匹配品牌色映射（dingtalk→钉蓝、feishu→飞青、sql→S蓝、ima→i黑、qqmail→Q黄），渲染为彩色字母方块。自定义 MCP：灰色底+SVG 图标。无匹配时保留默认蓝色 Logo
4 来源标签样式 自定义MCP：紫色文字(#4f46e5)+浅紫底(#eef2ff)+浅紫边框(#e0e7ff)。MCP市场：青色文字(#0e7490)+浅青底(#ecfeff)+浅青边框(#cffafe)。source 为空时隐藏标签
5 工具列表首项高亮 工具列表第一个项目使用浅灰底(#f5f6f7)+圆角边框+加粗深色名称样式。其余工具为标准白底+蓝色名称样式，以顶部边框分隔
6 卸载后状态恢复 详情页卸载后：移除已添加状态元素（开关+菜单），恢复显示「添加MCP」按钮，并重新绑定添加事件。用户可再次点击添加
7 菜单互斥关闭 打开三点菜单时，先关闭页面上其他已打开的菜单（querySelectorAll 逐一移除 open 类）。点击空白处也关闭所有菜单
8 开关默认状态 市场 MCP 安装后开关默认为开启状态（checked=true，绿色）。切换时仅 console.log 记录状态
9 页面标题动态更新 根据 name 参数更新 document.title 为「{name} - MCP」，同时更新 header-title 文本内容

四、边界与异常情况

序号场景处理策略备注
1 添加 MCP 时未填写服务器名称 Toast 提示「请输入服务器名称」，不关闭弹窗，不提交 前端校验
2 添加 MCP 时未选择传输协议 Toast 提示「请选择传输协议」，不关闭弹窗 前端校验
3 添加 MCP 时未填写服务地址 Toast 提示「请输入服务地址」，不关闭弹窗 前端校验
4 编辑 MCP 时未填写必填字段 同添加校验：名称/协议/地址非空校验，Toast 提示对应信息 前端校验
5 市场 MCP 安装过程中重复点击 点击「+」后按钮被 Spinner 替换，无法重复点击。加载完成后按钮区域整体替换为开关+菜单 防重复提交
6 详情页添加过程中重复点击 点击「添加MCP」后按钮隐藏，显示 Spinner。加载完成后进入已添加状态，按钮不再显示 防重复提交
7 卸载确认弹窗点击遮罩层 点击弹窗遮罩层（modal-overlay 区域）关闭弹窗，不执行卸载 防误操作
8 编辑弹窗卸载按钮超时未确认 首次点击「卸载」后 3 秒内未再次点击，自动恢复为普通状态（文字恢复、去除红色样式），需重新点击 二次确认超时
9 同时打开多个三点菜单 打开新菜单前先关闭所有已打开的菜单（querySelectorAll 移除 open 类）。同时只显示一个菜单 菜单互斥
10 点击空白处关闭三点菜单 document 添加 click 事件监听，点击任意位置关闭所有打开的卡片菜单 全局关闭
11 点击开关/编辑按钮触发卡片跳转 开关和编辑按钮的 click 事件调用 stopPropagation()，阻止冒泡到卡片的跳转事件 事件隔离
12 点击三点菜单按钮触发卡片跳转 三点菜单按钮的 click 事件调用 stopPropagation()，阻止冒泡 事件隔离
13 详情页 URL 参数缺失 name 为空时保留默认标题；icon 无匹配时保留默认蓝色 Logo；source 为空时隐藏来源标签；added 为空时视为未安装状态 容错处理
14 ESC 键关闭弹窗 监听 keydown 事件，ESC 键依次检查添加/编辑/卸载确认弹窗，关闭当前显示的弹窗 键盘交互
15 图标上传非图片文件 file input 设置 accept="image/*"，文件选择器过滤非图片文件。若仍传入非图片，FileReader 读取后以 DataURL 展示 前端过滤
16 HTTP Headers 格式错误 前端不校验 JSON 格式有效性，以纯文本形式传递。后端需校验并返回错误提示 后端校验
17 列表页卸载 vs 编辑弹窗卸载的差异 列表三点菜单卸载：移除开关+菜单，重建「+」按钮，卡片保留在列表（恢复未安装）。编辑弹窗卸载：整个卡片从列表移除 两种卸载路径
18 添加弹窗关闭后表单未重置 关闭添加弹窗时重置所有 input/textarea/select 值，重置图标预览为默认 SVG，清空 avatarData 状态重置
19 编辑弹窗关闭后状态未重置 关闭编辑弹窗时重置图标预览、清空 avatarData、重置卸载按钮状态（取消 armed 状态和定时器） 状态重置
20 详情页卸载后恢复添加按钮事件 卸载后移除已添加状态元素，恢复「添加MCP」按钮显示，并重新绑定 handleAddClick 事件（先 removeEventListener 再 addEventListener） 事件重绑定
