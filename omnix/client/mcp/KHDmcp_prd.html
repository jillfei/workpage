连接器管理 · 功能需求文档

产品 OmniX 连接器（模型上下文协议） 页面 连接器列表页 版本 第 1.0 版 更新 2026-09-09

1功能概述

连接器管理页支持四类连接器的浏览、搜索、安装/卸载、启停、增删改。所有反馈通过顶部轻提示（约 2 秒自动消失），弹窗支持点遮罩、点关闭按钮、按退出键三种方式关闭。

连接器来源（4 类）

  • 连接器市场：官方市场收录，可安装 / 卸载
  • 企业连接器：企业内部提供，可安装 / 卸载
  • 插件：客户端插件（如浏览器控制），可安装 / 卸载
  • 自定义连接器：用户手动添加，可编辑 / 卸载

2分类页签与视图

顶部一级页签切换面板，右侧提供搜索框与列表/卡片视图切换。

元素行为交互细节
一级页签 连接器市场 / 企业连接器 / 插件 / 已安装 点击切换对应面板；支持键盘 ← → 切换并聚焦；同步选中状态（无障碍标记）
视图切换 列表 / 卡片 切换视图模式，卡片视图为多列网格
搜索框 按「名称 + 描述」实时过滤 输入即触发，与二级筛选叠加生效；无结果显示空状态提示

3二级来源 / 分类筛选

各面板内提供筛选标签，与搜索关键词叠加过滤，选中项高亮（同步「已选中」无障碍状态）。

所在面板筛选项匹配字段
已安装 全部来源 / 连接器市场 / 企业连接器 / 插件 / 自定义连接器 按卡片「来源」匹配，"全部来源"显示全部
连接器市场 全部 / 办公 / 知识 / 商务 / 开发 等 按卡片「市场分类」匹配（可含多分类）
企业连接器 全部 / 办公协同 / 客户与销售 / 数据报表 / 研发运维 按卡片「企业分类」匹配

4添加连接器

点击右上角「添加连接器」打开弹窗，填写表单并提交，创建自定义连接器。

表单字段与校验（按顺序校验，命中即拦截并提示）

字段必填校验失败提示
服务器名称必填请输入服务器名称
传输协议必填请选择传输协议
描述必填请输入描述
服务地址必填请输入服务地址
请求头选填—
头像选填见「头像上传」章节

结果反馈

  • 全部校验通过 → 提示 连接器添加成功 → 关闭弹窗并重置表单
  • 关闭 / 取消 / 遮罩 / 退出键 → 清空头像预览与输入

5编辑连接器

通过卡片「···」菜单 → 编辑，回填原数据后修改。校验规则与「添加」完全一致。

  • 打开时回填名称 / 协议 / 描述 / 地址 / 请求头 / 头像
  • 校验失败提示与添加一致：请输入服务器名称 等
  • 校验通过 → 同步更新卡片显示的名称与描述 → 提示 保存成功 → 关闭弹窗

6头像上传校验

添加 / 编辑弹窗内点击头像框上传图片，实时校验后在本地预览（图片转为文本编码后直接嵌入页面）。

规则限制失败提示
格式仅 JPG / PNG 图片仅支持 JPG、PNG 格式的图片
大小不超过 2MB图片大小不能超过 2MB
  • 校验失败时清空已选文件，不更新预览
  • 通过则读取图片并渲染缩略图；未上传时显示默认占位图标

7安装（市场 / 企业 / 插件）

未安装卡片显示「安装连接器 / 安装插件」按钮，点击后执行安装流程。

  • 点击安装按钮 → 按钮替换为加载动画（约 1.2 秒）
  • 完成后 → 提示 安装 [名称] 成功
  • 按钮变为「试一试」，并在名称旁追加来源标签

8卸载

通过卡片「···」菜单 → 卸载，或已安装卡片「试一试」旁入口，先弹出确认框。

确认弹窗

  • 文案：确定要卸载 [名称] 吗？（危险操作，确认按钮红色）
  • 取消 / 关闭 / 遮罩 / 退出键 → 关闭且不执行

确认后行为（按来源区分）

场景行为提示文案
自定义连接器 / 已安装面板内 直接从列表移除卡片 已卸载 [名称]
市场 / 企业 / 插件面板内 移除「试一试」→ 恢复安装按钮 → 移除来源标签 已卸载 [名称]

9启用 / 禁用开关

已安装、插件面板的卡片带开关，切换连接器启停状态（不触发卡片跳转）。

操作提示文案
打开开关已启用 [名称]
关闭开关已禁用 [名称]

10卡片跳转详情

点击卡片空白区域跳转详情页（连接器详情页），携带查询参数。

  • 参数：名称 / 图标 / 来源 / 是否已添加，插件类额外携带插件标识
  • 点击开关、菜单、编辑、安装、试一试等操作区域不触发跳转
  • 「是否已添加」判定：自定义连接器、已安装面板、已含「试一试」按钮 → 视为已添加

11公共交互规则

  • 所有弹窗支持：关闭按钮 / 取消 / 点遮罩 / 退出键关闭
  • 轻提示统一样式，顶部居中，自动消失
  • 卡片「···」下拉菜单：点击外部空白自动关闭
  • 关闭弹窗时重置对应表单与头像状态
