个人助手工作台

统一承接任务 · 异步派发执行 · 远程 IM 连接 · 任务与工作产物预览

文档版本修改日期修改人修改说明
v1.02026-11-03孙礼飞个人助手工作台产品需求文档，包含指令路由、任务执行、工作台、任务/产物预览及 IM 连接能力。

一、概述

1.1 背景说明

用户在处理代码修改、问题排查、资料查询、文档审读和产物交付等工作时，通常需要在沟通工具、执行环境和结果文件之间频繁切换。任务过程不可见、执行结果分散、远程发起与跟进不连续，会降低任务协同效率。

个人助手工作台提供统一任务入口与执行承载：用户以自然语言提出需求，系统根据任务性质完成直接答复、直接处理、异步派发、上下文续办或补充确认；任务执行后，用户可在同一工作台查看任务会话和生成产物，并通过 IM 频道远程提交任务和跟进结果。

1.2 需求描述

  • 统一任务承接：支持将用户自然语言需求识别为问答、秘书事务、新任务、已有结果迭代、待确认事项或受限事项，并执行匹配处理。
  • 可跟进的异步执行：新任务可在不阻塞用户操作的前提下派发执行，状态从已受理进入执行并回传完成、失败或取消结果。
  • 集中工作台：在同一侧边工作区查看 IM 连接状态、最近任务和工作产物；任务与文件均可打开为独立标签页预览。
  • 远程连接：支持微信、企业微信、钉钉、飞书四类 IM 频道的绑定、状态展示和安全解绑。

1.3 核心概念定义

概念定义与说明
个人助手面向个人工作流的任务协调入口，负责理解需求、决策处理方式、派发执行并汇报结果。
任务会话承载一个可执行任务的上下文单元，包含目标、已知路径、约束、已有结论以及执行过程和结果。
助手工作台个人助手右侧的管理与预览区域，汇集 IM 频道、最近任务、工作产物和打开的标签页。
工作产物任务执行后生成或引用的文件型结果，例如 HTML 文档；可从对话消息或工作台列表打开。
IM 频道用于远程向个人助手发送任务并接收结果的外部即时通讯入口，具有未绑定、绑定中、已绑定状态。
绑定用户通过指定 IM 平台的扫码授权流程建立频道连接；连接成功后可远程发起任务。

1.4 目标用户与典型场景

研发与技术负责人

将修复缺陷、阅读代码、审查改动等任务交由助手异步执行，并在任务完成后直接打开对应会话或交付文件。

产品与运营人员

通过自然语言委派调研、文档生成和内容审读任务，在工作台集中查看任务进展和结果。

移动办公用户

在微信、企业微信、钉钉或飞书中远程发送任务，保持电脑端执行环境与移动端沟通渠道连接。

三、功能架构与流程图

3.1 系统架构图

个人助手页面由会话区和助手工作台组成。会话区承载任务沟通与产物消息；工作台承载 IM 频道管理、最近任务和工作产物，并以标签页预览任务会话或文件型结果。工作台支持可调宽、全屏与收起。

3.2 业务流程图

用户可从对话中的任务卡片、最近任务、对话中的文件卡片或工作产物列表进入预览。系统按标题识别是否已打开相同对象：已存在则切换至对应标签，不重复创建；不存在则创建新标签并加载相应预览内容。关闭当前任务标签后，优先切换至剩余任务标签；无剩余任务标签时返回助手工作台。

四、详细设计

4.1 个人助手页面

个人助手页面为左右分屏布局：左侧展示会话历史、用户任务消息、助手状态和工作产物卡片；右侧默认展示助手工作台。会话区与工作台之间的分割线支持拖动调宽和双击恢复默认宽度。工作台可进入全屏、收起和恢复状态。

4.1.1 会话展示模块

字段类型必填说明
页面标题文本是固定展示“个人助手”，标识当前会话空间。
助手消息富文本消息是左对齐展示助手的说明、任务安排和结论；支持保留换行。
用户消息文本气泡是右对齐展示用户需求；当消息来自 IM 时，在消息前展示来源图标，悬停可查看来源平台。
任务状态状态文本否展示任务完成状态及耗时；仅任务存在可展示状态时显示。
消息时间时间文本否展示消息产生时间；与复制操作同一信息区域展示。
复制消息图标按钮否用于复制对应助手消息内容；鼠标悬停时提供视觉反馈。
工作产物卡片文件卡片否展示文件名和文件类型；点击或按 Enter、空格可打开工作产物预览标签。
任务入口卡片任务标签否展示任务标题和执行中状态；点击或按 Enter、空格打开对应任务会话预览。

4.1.2 分屏与工作台状态模块

字段类型必填说明
工作台宽度可拖动尺寸是默认按窗口比例初始化，最小宽度为 300px；最大宽度为窗口宽度减 420px，保证会话区保留最小可用空间。
分割线拖拽控件是按住后左右拖动实时调整工作台宽度；双击恢复默认宽度；收起或全屏状态下不允许拖动。
全屏放大 / 还原图标按钮是全屏时工作台覆盖整个视口；再次点击或按 Esc 退出全屏。进入全屏会自动取消收起状态。
收起 / 展开图标按钮是收起后隐藏工作台和分割线，仅保留页面右上角“展开面板”入口；展开后恢复此前宽度。
窗口尺寸适配系统行为是窗口尺寸变化时，非全屏状态下重新按最小值和最大值约束校正工作台宽度。

4.2 助手工作台模块

助手工作台为默认首页，提供 IM 频道、最近任务和工作产物三个信息区。顶部保留工作台标签，并支持查看全部已打开标签、切换活动标签、关闭任务或产物标签。

4.2.1 工作台标签与总览模块

字段类型必填说明
助手工作台标签固定标签是默认激活；点击后关闭当前预览状态并返回工作台总览。
全部标签页图标按钮 + 下拉菜单是点击生成标签清单，包含助手工作台及全部任务/产物标签；当前活动项高亮。点击菜单外区域自动关闭菜单。
任务 / 产物标签可切换标签否首次打开对象时创建，标题为任务或文件名称；重复打开同标题对象时切换已有标签，不重复创建。
关闭标签图标按钮否仅任务/产物标签显示。关闭活动标签时，优先切换到剩余任务标签；不存在剩余标签时清空预览并返回助手工作台。
IM 频道区信息列表是展示频道配置入口、引导说明和已绑定频道；未绑定任何频道时展示空状态提示。
最近任务任务列表是展示最近任务标题；点击或键盘触发后打开任务会话预览。
工作产物文件列表是展示工作产物文件名；点击后打开文件型结果预览。

4.3 任务与工作产物预览模块

任务与工作产物使用工作台内容区承载。打开任务时加载任务会话预览；打开工作产物时加载文件型结果预览。预览区与工作台总览互斥，活动标签决定当前展示内容。

4.3.1 预览加载与切换模块

字段类型必填说明
预览类型页面内容是任务对象加载任务会话预览；工作产物对象加载文件型结果预览。
预览标题标签标题是来源于被打开任务或文件的名称；用于标签显示、去重识别和全部标签页菜单展示。
活动状态标签状态是当前标签高亮，工作台总览与其他标签取消高亮；对应预览内容显示。
工作台返回页面切换是点击固定工作台标签后隐藏预览内容并恢复 IM 频道、最近任务和工作产物总览。

4.4 IM 频道配置弹窗

IM 频道配置弹窗提供微信、企业微信、钉钉、飞书四类连接渠道。用户可在渠道列表发起绑定，系统显示对应平台的二维码和连接中状态；绑定成功后更新渠道列表和工作台已绑定频道。已绑定渠道再次操作时进入解绑确认流程。

4.4.1 IM 频道列表模块

字段类型必填说明
配置主按钮是打开“IM 连接”弹窗，并将焦点置于关闭按钮，便于键盘操作。
连接说明说明文本是说明连接后可通过 IM 向助手发送任务并跟进结果。
平台图标与名称渠道信息是固定支持微信、企业微信、钉钉、飞书；每个平台独立维护绑定状态。
绑定状态状态文本是未绑定时显示“未绑定”和“去绑定”；已绑定时显示“已绑定”和“解绑”。
去绑定渠道操作是点击未绑定渠道进入绑定视图；按钮与整行均可触发。
关闭弹窗图标按钮 / 遮罩行为是点击关闭按钮、绑定视图关闭按钮、弹窗外遮罩或按 Esc 均关闭连接弹窗，并清理未完成的绑定计时状态。

4.4.2 绑定与解绑表单模块

字段类型必填说明
绑定平台只读信息是由用户在频道列表中选择的平台决定，展示平台图标和“绑定 + 平台名称”标题。
扫码提示说明文本是按所选平台动态展示“平台名称 + 扫一扫”，提示用户使用对应 IM 完成授权。
绑定二维码二维码画布是依据平台标识生成差异化二维码图案；绑定中展示，成功后隐藏。
绑定结果成功反馈是绑定成功后展示成功状态和“平台名称绑定成功”，同时将该平台写入已绑定频道列表；成功反馈后自动回到频道列表。
返回按钮否在绑定中返回频道列表，取消当前绑定等待状态，不改变已绑定频道。
解绑提示确认文本是动态带入被解绑平台名称，明确说明解除后无法通过该 IM 频道向助手发送任务。
取消按钮是关闭解绑确认弹窗，不改变当前绑定关系。
确认解绑危险按钮是删除当前平台绑定状态，渠道列表恢复“未绑定”，工作台已绑定频道列表同步更新；最后一个频道解绑后恢复空状态提示。
移动端适配：当屏幕宽度不超过 540px 时，IM 连接弹窗全屏展示，避免二维码与渠道列表在窄屏中被裁切。
