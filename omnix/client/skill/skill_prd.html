一、概述

1.1 背景与问题

在 AI 智能体平台中，技能是扩展智能体工具能力的模块化组件（类似于插件或工具包）。一个技能对外声明它能做什么（如创建文档、分析股票、绘制架构图），智能体在对话中按需调用这些能力来完成实际任务。随着平台上可使用的技能越来越多——既有平台预置的公开技能，也有企业下发的内部技能、系统出厂自带技能，以及用户自己导入的自定义技能——迫切需要提供一个统一的"技能中心"来集中承载浏览、安装、试用与管理。

在没有统一管理中心之前，用户面临以下问题：

  • 入口分散：技能按来源散落在不同地方（公开货架、企业下发、系统内置、个人自定义），没有一个页面能集中查看"我现在有哪些技能可用"；
  • 接入门槛高：想把外部技能接入平台，缺少便捷方式（本地导入文件、通过链接安装），只能依赖技术操作；
  • 能力不透明：安装或看到一个技能后，用户不清楚它具体能做什么、来自哪里、配置文件长什么样，只能靠试；
  • 管理链路长：已安装的技能缺少统一的启用、禁用、卸载入口，无法快速暂停或下线某个技能；
  • 试用割裂：装好技能后，没有顺手的入口直接跳到对话里去试，体验断层。

因此，本模块要建设一个统一的技能中心：在一个列表页集中呈现全部技能并支持分组浏览、搜索、筛选、安装与导入；在详情页透明展示单个技能的介绍与配置；并提供安装、禁用、启用、卸载、试用的完整管理闭环。

1.2 目标用户与典型场景

普通业务用户

希望扩展智能体能力但没有技术背景的用户。他们更关心"好不好用、点一下能不能装上"，倾向从技能市场一键安装，并直接试用。关注便捷性。

企业管理员

负责维护团队技能的用户。需要管理企业技能与系统内置技能，按状态启用或禁用，下线不再使用的技能。关注管理效率与操作安全（防误卸载）。

高级用户 / 开发者

熟悉技能接入方式的技术用户。他们需要将本地编写或从网络获取的技能接入平台，关注导入与链接安装的便捷性、安装前的配置预览与安全扫描。

典型场景

1.3 核心概念

概念定义
技能扩展智能体能力的最小可安装模块。一个技能声明它能做什么（如创建文档、分析股票），智能体在对话中按需调用。技能由名称、描述、来源、能力标识、启用状态等元信息构成。
技能市场平台预置的公开技能货架。其中的技能由平台维护，用户只需安装或卸载，不能修改其配置。
企业技能由企业内部分享或下发给团队成员的技能。通常来源于企业内部，用户可安装使用，一般不支持自行卸载（视分组而定）。
系统内置平台出厂自带的技能。默认已安装且已启用，用户不可卸载，仅可做启用/禁用管理。
自定义技能用户通过本地导入或链接安装自行添加的技能。其来源标记为"自定义"，用户拥有完整管理权（安装、禁用、卸载）。
来源标记某个技能的生产方，取值为：技能市场、企业技能、系统内置、自定义。来源决定该技能在列表中的分组归属、可展示的状态选项以及可用的管理操作。
安装状态标记技能当前是否可被智能体使用。存在"未安装 / 已安装"两种状态；系统内置技能恒为已安装。
启用状态在安装的基础上进一步标记技能是否处于可用（启用）或被暂停（禁用）。被禁用的技能在列表中置灰且不可试用。
技能配置文件技能的描述文件，声明技能的名称、描述、能力等信息。本地导入的压缩包或描述文件必须包含此文件，且文件内需包含结构化的名称与描述。
技能安装目录自定义技能在本地存放的路径（形如"用户目录下的技能文件夹 / 技能名"），在链接安装预览时向用户展示，便于了解文件落点。

1.4 用户故事

作为 普通业务用户，我希望在技能市场中一键安装公开技能，以便不了解任何技术细节也能扩展智能体的能力。
作为 用户，我希望安装后能通过"去试试"直接跳到对话中试用，以便快速验证这个技能是否真的好用。
作为 高级用户，我希望通过本地导入文件或粘贴链接来安装自定义技能，并在安装前看到安全扫描与文件清单，以便放心地把外部技能接入平台。
作为 用户，我希望进入任意技能的详情页，看到它的介绍与配置（可视化 / 代码两种视图），以便在使用前评估该技能能帮我做什么、它的配置长什么样。
作为 企业管理员，我希望通过三点菜单禁用或卸载已安装的技能，以便安全下线技能，避免误调用或能力冗余。

1.5 非目标

本期不做以下内容：
  • 不提供技能运行时的调试、工具试运行与调用日志（仅管理安装与配置展示，不提供运行期验证）；
  • 不提供技能配置内容的在线编辑（详情页的配置仅做只读展示，可视化与代码视图都不支持修改）；
  • 不提供技能的版本管理与回滚；
  • 不提供技能级别的权限管控（不区分不同用户对该技能的可见与可用范围）；
  • 不提供按"开发工具 / 效率提升"等分类的精确筛选（分类标签在本期作为筛选维度呈现，但其精确过滤能力不在本期强制实现）；
  • 不涉及技能配置文件本身的编写、托管与发布，只负责接入与展示。

二、功能架构与流程图

2.1 系统架构图

模块由两个页面与若干弹窗构成：技能列表页（统一入口，承载浏览、搜索、筛选、分组、安装、导入、管理）与技能详情页（承载单个技能的介绍、配置展示与安装/卸载）。列表页提供"添加技能"入口，展开后包含本地导入弹窗与从链接安装弹窗，后者进一步进入安装预览弹窗。点击列表中的技能卡片进入对应详情页；已安装技能可通过"去试试"跳转到智能对话页进行试用。

2.2 业务流程图

五条核心业务流程：列表的浏览与筛选、技能的安装（市场安装 / 本地导入 / 链接安装）、试用、管理（禁用与卸载）、以及详情查看与配置预览。

三、详细设计

本模块共两个页面：3.1 技能列表页（浏览与全部管理操作的入口）和3.2 技能详情页（单个技能的能力展示与安装/卸载）。每个页面按"功能描述 → 显示数据说明 → 操作字段说明 → 操作说明"四部分展开。

3.1 技能列表页

功能描述

技能列表页是模块首页，集中呈现当前平台可安装及已安装的技能。页面按来源分为四个分组：技能市场（平台公开技能）、企业技能（企业下发技能）、系统内置（出厂自带技能）、已安装（我安装的全部技能）。每个技能以卡片形式展示图标、名称与描述；卡片右侧的操作按钮随来源与安装状态变化：未安装的技能显示"安装技能"（精选技能显示"试一试"），已安装的技能显示"去试试"。已安装且当前分组支持管理的技能，卡片右上角提供三点菜单，含"禁用/启用"与"卸载"。页面顶部的"添加技能"入口用于接入自定义技能（本地导入、链接安装）。点击卡片本身（非按钮区域）进入该技能的详情页。

3.2 技能详情页

功能描述

技能详情页用于展示单个技能的完整信息，帮助用户在使用前评估其能力。页面自上而下包含：返回导航、技能头部（图标、名称、来源相关的收藏/下载信息、操作区）、技能描述，以及配置预览区（含"可视化 / 代码"两种视图，展示名称、描述、来源、能力标识、是否禁用）。头部操作区根据安装状态呈现两种形态：未安装时显示"安装技能"按钮；已安装时显示"在对话中去试试"按钮 + 三点菜单（禁用技能/启用技能、卸载）。页面进入时所需的技能基础信息（名称、来源等）由列表页跳转时传入。

显示数据说明

字段显示规则来源及说明
返回导航 页面顶部左侧展示"← 技能"，点击返回技能列表页 系统固定导航元素
技能图标 头部左侧渐变圆角图标，与列表页视觉一致 由列表页传入的图标标识与来源共同决定
技能名称 头部主标题，大号加粗；被禁用时右侧带"已禁用"灰色角标 由列表页传入；
收藏数 / 下载量 名称下方一行小字，仅来源为技能市场时显示 由来源派生；其余来源默认隐藏该信息
安装 / 操作区 两种形态：① 未安装——展示"安装技能"按钮；② 已安装——展示"在对话中试一试"按钮 + 三点菜单（禁用技能/启用技能、卸载） 由安装状态与来源共同派生
技能描述 头部下方段落，介绍技能的能力范围与典型使用场景 技能基础信息
配置预览区 含视图切换（可视化 / 代码）与配置体。可视化视图以"标签—值"网格展示：名称、描述、来源、能力标识、是否禁用；代码视图以键值形式展示同样五项。默认可视化视图 数据来源skill.md文件；
如果未安装，则显示名称、版本、描述；
如果已安装，则显示skill.md文件所有内容；（详情页安装成功后自动显示）
操作结果提示 安装成功后顶部居中弹出深色轻提示，约 2.5 秒后自动消失 系统根据操作结果生成


操作说明

操作前提效果边界与例外
返回列表 无 点击"← 技能"返回技能列表页；
返回进入详情之前的列表结果页（包括标签、搜索、分页等）		 返回后列表状态（安装/启用）应与本页操作结果保持一致
安装技能 当前未安装 点击"安装技能"，按钮进入"安装中…"加载态，约 1.5 秒后隐藏安装按钮、显示操作区（试一试 + 三点菜单）并提示"安装成功" 加载期间按钮禁用防重复点击；点击安装不触发返回
在对话中试一试 当前已安装且未禁用 点击"在对话中试一试"跳转智能对话页，并带入技能 已禁用时该入口随操作区变化；禁用态下不可试用
禁用 / 启用 当前已安装 三点菜单点击"禁用技能/启用技能"切换：禁用时名称右侧显示"已禁用"角标、菜单文字变"启用技能"；启用则反之 切换即时生效并收起菜单；禁用后不可试用
卸载 当前已安装 三点菜单点击"卸载"，隐藏操作区、恢复"安装技能"按钮并清除禁用态/角标 卸载后回到未安装态，可再次安装
可视化 / 代码视图切换 无 点击配置预览区右上角"可视化视图"或"代码视图"按钮切换配置展示形态 两种形态展示同一份配置五项数据；默认可视化视图
