一、概述

1.1 背景与问题

在智能体逐步承担复杂工作的当下，用户并不缺少一个对话框，真正缺的是一个能把正确的知识、合适的专家角色、相关的项目上下文与恰当的权限一次性组织好、再交给智能体执行的统一入口。当前多数工具把「选模型、挂知识、挑角色、定权限」拆散在多个界面，用户往往要在任务进行中反复补充背景，导致首轮产出质量低、返工多；而权限一旦默认全开，又埋下安全隐患。

此外，作为一款持续迭代的产品，应用还需要一个清晰、稳定的外壳来承载导航、历史组织、账户管理与版本更新，否则功能越多越容易让用户迷失。本产品正是为解决「任务发起前配置割裂」与「应用外壳缺失」两个问题而设计。

1.2 目标用户与典型场景

用户角色典型场景核心诉求
个人创作者 / 自由职业者 用「海报设计」「演示文稿生成」等项目发起创作任务，挂载本地知识库辅助产出 开箱即用、配置简单、产出快
产品经理 / 策划人员 发起任务前挂载「需求文档存档库」与「产品设计」专家角色，让智能体基于正确背景产出方案 背景充分、角色专业、可复用知识
开发者 / 技术团队 挂载开发类技能与「全栈开发团队」专家团，在「产品官网」项目下做工程任务 专家协作、项目上下文一致
企业版管理员（规划中） 通过用户中心切换企业版、进入管理后台、查看可用额度 账户可控、额度可见、合规

1.3 核心概念

概念定义
智能体协作输入区新建会话时承载「任务描述 + 上下文挂载 + 配置」的核心交互界面，是用户发起一次协作任务的统一入口。
上下文挂载在发起任务前，将本地知识库、技能、MCP、专家 / 专家团、项目等背景以「标签」形式挂到本次任务上，随任务一同提交给智能体。
专家 / 专家团预设的单一专业角色（如产品经理）或多角色协作团队（如全栈开发团队），作为本次任务的主要执行主体。
权限模式本次任务对文件与系统的访问级别：只读、默认权限（路径内读写）、完全访问（系统级广泛权限，需风险确认）。
模型与质量档位执行任务的底层模型（企业模型 / 个人模型）与产出质量档位（轻度 / 中 / 高 / 极高），决定能力边界与资源消耗。
应用主控框架产品的整体外壳：侧边导航、会话与项目组织、用户中心、版本更新与外观主题，承载所有内容页面的加载与切换。

1.4 用户故事

作为新用户，我希望打开产品就能看到清晰的引导与输入框，以便立刻明白下一步该做什么、如何发起第一次协作。
作为产品经理，我希望在发起任务前把「需求文档存档库」和「产品设计」专家角色挂上，以便智能体首轮就能基于正确背景产出方案，减少来回解释。
作为注重安全的用户，我希望权限默认受限、开启「完全访问」前必须确认风险，以便我清楚知道这次任务会拿到多大权限，避免误开。
作为深色模式偏好者，我希望在用户中心一键切换浅色 / 深色外观，以便在不同光线环境下都获得舒适的可读性。
作为长期用户，我希望在侧边栏通过会话与项目分组快速回到历史任务，以便延续上下文、复用语料，不必每次从头描述。

1.5 非目标

本版产品需求文档明确不包含以下内容：

  • 技能 / 知识库 / 专家的「后台管理编辑」能力（如新建、编辑、发布、回收）——本版仅消费已存在的预设项，管理面由独立模块负责。
  • 多模型并行对比、任务执行过程的可视化与结果页交互——本版聚焦「发起前」的输入与配置体验。
  • 企业版的完整管理能力（成员、计费、合规审计）——本版仅在用户中心预留切换入口与额度展示。
  • 自动化任务编排与定时触发的完整引擎——侧边栏预留入口，本版不展开。
  • 多语言国际化——本版以中文界面为默认。

二、功能架构与流程图

产品整体由应用主控框架与智能体协作输入区两层构成：主控框架负责「在哪里、看什么、我是谁」，输入区负责「这次任务带什么背景、用什么能力、给多大权限」。两者通过统一的内容加载区衔接，用户在任何导航下进入新会话都会落到输入区。

2.1 系统架构图

💡 架构原则：主控框架只管「壳」，输入区只管「一次任务的完整前置」。任何导航路径进入的新会话都复用同一输入区，保证配置体验一致、可演进。

2.2 业务流程图

💡 流程要点：文本与任意一类上下文 / 附件至少具备其一方可发送；权限默认为「默认权限」，仅当用户主动选择「完全访问」且完成风险确认后，才提升至系统级广泛权限。

三、详细设计

3.1 页面一：应用主控框架与用户中心

本页面是产品的整体外壳，承载侧边导航、会话与项目的组织、用户身份与账户入口、版本更新与外观主题。所有内容页面通过统一的内容加载区呈现，导航保持唯一选中态。尚未就绪的能力在导航中置灰且不可交互，避免误导用户。

功能描述

用户登录后默认进入主控框架：左侧为固定导航栏，含版本日志、新建会话、专家广场、本地知识库，以及预留的MCP接入、技能、自动化入口；其下以可折叠分组呈现历史会话与项目，点击即可切换内容区。底部常驻用户资料入口，点击展开用户中心，聚合管理后台、可用额度、设置、外观、检查更新、切换企业版与退出登录等高频操作。发现新版本时弹出版本更新提示与日志，支持立即更新或跳过；更新过程展示实时进度，完成后需用户主动重启。

显示字段说明（列表格式）

字段 / 按钮规则来源 / 例外 / 边界
侧边主导航项 固定展示一级入口：版本日志、新建会话、专家广场、本地知识库、MCP接入、技能、自动化；当前所在页高亮唯一选中态 数据来源：产品固定配置。例外：MCP接入与技能暂未开放，置灰且不可点击、不可悬停。边界：点击置灰项无任何响应，避免进入空白页。
会话分组 可折叠 / 展开，标题显示会话数量；列出历史会话条目 数据来源：服务端会话列表。例外：暂不可进入的历史会话置灰不可点。边界：列表为空时显示数量（0）并引导新建会话。
项目分组 可折叠 / 展开，标题显示项目数量；项目行可展开子任务列表，点击切换内容区 数据来源：服务端项目列表。例外：无项目时显示（0）。边界：子任务展开箭头随状态旋转，反映展开 / 收起。
用户资料入口 侧边底部常驻，显示头像与用户名；点击展开用户中心；更新进行时在用户名旁显示「更新中」 数据来源：当前登录账户。边界：「更新中」标签仅在更新流程进行时出现，结束后自动隐藏。
用户中心 - 管理后台 点击在新页面打开管理后台并同步登录态 数据来源：账户权限。例外：无权限时不展示该入口；操作：新页面打开，不脱离当前应用。
用户中心 - 可用额度 展示当前可用额度数值 数据来源：账户配额。例外：个人版不展示额度（由企业版分配）。边界：额度为 0 时引导充值 / 购买，避免静默失败。
用户中心 - 设置 点击进入设置页 数据来源：固定页。边界：跳转后保留主控框架上下文。
用户中心 - 外观 浅色 / 深色一键切换，选中态即时反馈 数据来源：本地主题状态。边界：刷新后是否保持由实现约定，建议持久化到本地。
用户中心 - 检查更新 点击打开更新提示；有新版本时显示「有可用更新」徽标 数据来源：版本服务。例外：无更新时不显示徽标。
用户中心 - 切换企业版 点击切换至企业版，展示所属企业 数据来源：企业授权。例外：无企业权限时不可切换。边界：切换后呈现企业版相关入口（成员 / 计费后续承接）。
用户中心 - 退出登录 点击跳转登录页并清理本地会话 边界：退出后后续请求需重新鉴权；本地会话清理。
版本更新弹窗 发现新版本时首次登录自动弹出（当天关闭后不再弹，次日继续）；展示版本号与更新日志；支持立即更新 / 跳过 数据来源：版本服务。边界：当天仅弹一次，避免反复打扰。
立即更新 点击后关闭弹窗，用户名旁显示更新中，进度 10% → 100%，完成后提示「更新完成，点击重启」 数据来源：更新服务。边界：需用户主动点击重启方可生效至新版本。
跳过本次更新 点击后不再弹出，直至下个版本发布 边界：仅影响当前版本，新版本发布后重新提示。
外观主题切换 用户中心内切换浅色 / 深色，选中态即时反馈 边界：深浅主题下弹窗、下拉文字对比度均需满足可读性规范。

本页面无表单输入类模块（用户中心与更新均为按钮驱动操作），故不单列表单字段说明。

3.2 页面二：智能体协作输入区

本页面是新建会话时的核心交互界面。用户首先看到品牌引导（吉祥物 + 标题 + 一句价值主张），随后在输入框中描述任务或提问。输入框上方通过下拉选择器挂载四类上下文——本地知识库、技能、MCP、专家与专家团、项目；并通过MCP栏完成权限模式、底层模型、质量档位的选择与附件上传。所有已挂载的上下文以「标签」形式直观呈现在输入框上方，可单独移除。发送前，用户已完成「背景 + 能力 + 权限」的一次性配置。

功能描述

输入区由「引导区 + 输入框 + 工具栏 + 文件行」四部分构成。工具栏左侧依次提供：选择 / 上传入口（上传照片和文件、挂载插件）、技能选择、MCP接入、专家与专家团选择、本地知识库、权限模式；工具栏右侧提供模型选择、质量档位与发送按钮；文件行提供「添加项目」入口与已选项目标签。各类上下文以下拉形式选择，已选项以彩色标签呈现，悬停显示移除按钮。涉及系统级广泛权限时弹出风险确认，涉及新建 / 引用项目时弹出对应表单弹窗。

显示字段说明（列表格式）

字段 / 按钮规则来源 / 例外 / 边界
欢迎引导区 新建会话首屏展示吉祥物、标题「开始使用 OmniX」与价值主张副标题 数据来源：固定引导文案。边界：仅在新建会话空态展示，输入内容或挂载上下文后引导区淡出。
任务输入框 多行文本，高度自适应（约 8 行后滚动）；占位提示引导输入；支持轻量指令语法 数据来源：用户输入。例外：与任意上下文 / 附件至少其一方可发送。边界：空输入时发送按钮禁用。
选择 / 上传按钮 展开菜单：上传照片和文件、插件（浏览器扩展 / 文档解析 / 演示文稿生成，可多选） 数据来源：本地文件 / 内置插件。边界：文件类型与大小前端校验，超限拦截不进入提交。
技能选择 下拉展示技能列表并支持搜索，多选挂载为标签；提供管理技能入口 数据来源：技能库（如在线文档协作、个人知识库读写、产品设计、开发助手等）。例外：多选独立增删。边界：点击页面其它区域自动收起下拉。
MCP接入 下拉含「MCP市场 / 自定义MCP」两标签，分组展示，支持整组或部分子项选择，显示已选计数 数据来源：MCP市场配置。例外：搜索无结果提示「未找到匹配」。边界：同组全选 / 局部选中状态以勾选样式区分。
专家与专家团 下拉分「专家 / 专家团」两组，单选其一作为协作主体；提供召唤更多入口 数据来源：我的专家（如开发工程师、产品经理、设计师、各专项团队）。例外：单选，重选替换原选择。边界：已选后原按钮隐藏，以标签呈现。
本地知识库 下拉列出知识库（如需求文档存档库、办公技巧私库、会议纪要、周报、行业调研等），多选挂载为标签；提供管理入口 数据来源：本地知识库。例外：多选独立管理。边界：取消某项仅移除对应标签，不影响其它。
权限模式 三档：只读 / 默认权限 / 完全访问；默认选中「默认权限」；选完全访问弹风险确认 数据来源：固定枚举。例外：完全访问须勾选风险确认方可生效，否则按钮禁用。边界：默认不开放完全访问，避免误开。
模型选择 右侧胶囊，分企业 / 个人两组，标注能力说明；选中回显名称 数据来源：模型配置（企业旗舰推理模型、企业通用模型、多模态理解模型、个人代码模型、个人高性价比开源模型等）。边界：默认选中企业旗舰推理模型。
质量档位 四档：轻度 / 中 / 高 / 极高；默认极高 数据来源：模型质量档位。边界：若模型未配置质量档位则不显示该控件。
添加项目 文件行内下拉，单选一个项目；支持搜索、新建空白文件夹、使用现有文件夹 数据来源：项目列表 / 本地目录。例外：单选，重选替换。边界：重名时取同名项目，不重复创建。
附件上传 上传图片与文档，按类型展示图标，标签区显示文件名可移除 数据来源：本地文件。边界：支持图片、文档、表格、代码、音视频等常见格式，单文件上限 200M，超限前端拦截。
发送按钮 聚合文本、上下文标签与全部配置后提交；空输入禁用 数据来源：本页全部配置。例外：无任何文本 / 上下文 / 附件时禁用，阻止无效提交。
上下文标签 已挂载的知识库 / 技能 / MCP / 专家 / 项目 / 附件以标签呈现，可单独移除 数据来源：本页选择。例外：移除即解除，不影响其它配置。边界：标签与下拉选中态双向同步。
新建空白文件夹弹窗 输入文件夹名称，确定后创建项目并自动选中 数据来源：用户输入。边界：名称为空时提示错误且不创建；确定后在项目列表新增项并自动选中。
使用现有文件夹弹窗 选择本地文件夹作为项目，确定后添加 数据来源：本地目录。边界：未选择时提示错误；确定后同名项目复用、非同名则新增。
完全访问确认弹窗 勾选风险确认后「允许完全访问」按钮才可点；取消则保持原权限 数据来源：用户确认。边界：未勾选时按钮禁用，强制显式知情。

表单字段说明

本页面包含三个表单类弹窗，字段、类型、必填与说明如下。

（一）新建空白文件夹

字段类型必填说明
文件夹名称 文本输入 是 输入项目名称，作为本次任务的工作目录；确定后在项目列表创建对应项目并自动选中；为空时显示错误提示且不创建
取消（按钮） 按钮 — 关闭弹窗，不创建项目，不改动当前选择
确定（按钮） 按钮 — 校验名称非空后创建项目并自动选中，关闭弹窗；名称为空时禁用创建并提示

（二）使用现有文件夹

字段类型必填说明
选择文件夹 只读文本 + 浏览按钮 是 点击浏览选择本地目录，所选路径回显至输入框；确定后将当前文件夹添加为项目；未选择时提示错误
取消（按钮） 按钮 — 关闭弹窗，不添加项目
确定（按钮） 按钮 — 校验已选择目录后添加为项目；同名则复用、非同名则新增

（三）完全访问确认

字段类型必填说明
我已了解风险，并愿意继续 复选框 是（须勾选） 显式风险知情确认；勾选后「允许完全访问」按钮方可启用，否则保持禁用
取消（按钮） 按钮 — 关闭弹窗，权限保持原值（不升级为完全访问）
允许完全访问（按钮） 按钮（默认禁用） — 确认后权限升级为完全访问并回显；未勾选风险确认时禁用，强制显式知情
