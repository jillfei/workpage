企业知识库 · 功能说明

一、知识库列表

入口：顶部「知识库」→「企业知识库」标签

1.1 搜索与筛选

元素规则说明
搜索框输入即时过滤，无需回车按知识库名称模糊匹配，忽略大小写；对当前筛选结果再过滤
筛选项全部 / 我创建的 / 我加入的数字为各分组实时计数；切换筛选后搜索关键词保留
空结果无匹配项展示空状态：「没有找到匹配的知识库」，不显示卡片网格
右上角计数—「共 N 个知识库」随筛选结果变化

1.2 卡片信息

字段规则
图标首字色块；点击可更换图标（增强功能，可后续迭代）；颜色从预设色板随机分配
名称 + 状态点状态三态：已完成处理 部分文件处理中 存在解析失败文件，悬浮显示具体提示文案
所有者显示「所有者：姓名」，无所有者时显示横杠「—」
模型标签依次为 大语言模型 / 视觉语言模型（可选）/ 嵌入模型 / 重排序模型（可选），悬浮显示完整模型名
描述最多 2 行，超出省略；无描述时显示灰色「无描述」
底部统计「N 个文件」「创建：2026-07-25 14:43」「更新：2026-10-23 13:43」（日期精确到分钟）
点击卡片主体进入知识库详情页（带上 name / desc / owner / 模型 / mode 参数）

二、卡片更多操作

入口：卡片右上角「⋯」按钮

2.1 菜单项

序菜单项动作说明
1编辑知识库跳转到详情页后自动打开编辑弹窗核心功能
2对话试一试进入对话页并携带当前知识库上下文重要功能
3删除弹出二次确认框，确认后删除知识库核心功能，红色文字，与上方用分隔线隔开

2.2 删除知识库

确认框文案

标题：「删除知识库」

正文：「删除知识库「{名称}」？删除后该知识库下的文档与问答将一并移除，且不可恢复。」

操作结果提示文案
点「取消」/ 遮罩 / ×关闭确认框，数据不变无
点「删除」成功卡片从列表移除，计数同步减 1，容量占用同步释放「已删除」
删除失败（后端异常）卡片保留，界面不变化删除失败，请稍后重试
注意：删除为不可逆操作，前端需在请求返回前禁用「删除」按钮防止重复提交。

三、容量进度条

位置：列表页工具栏右侧、「共 N 个知识库」左侧

3.1 展示规则

元素内容
总容量由管理端分配固定配额（如 1 TB）
第一行左「存储容量」；右「已用 / 1 TB」，保留 1 位小数
进度条宽度 = 已用 / 总量 × 100%；实际占比 > 0 但极小时至少保留约 1.5% 的可见宽度
第二行左「已用 xx GB」；右「剩余 xx GB」
悬浮提示三行：总量、已占用（含百分比，1 位小数）、剩余

3.2 阈值配色与提示文案

占用率颜色说明提示文案
< 75% 绿色渐变 正常 不提示，仅通过进度条颜色暗示
75% ~ 90% 橙色渐变 提醒存储将满 进度条上方常驻一行橙色提示：「存储空间已使用 {已用百分比}%，请留意容量」
≥ 90% 红色渐变 高风险；上传文档前需二次提示
① 常驻提示（红色）：「存储空间即将用尽，剩余 {剩余容量}」
② 上传 / 新建文档前二次确认：标题「存储空间即将用尽」；正文「当前剩余 {剩余容量}，继续上传可能失败，是否仍要继续？」；按钮「取消」/「继续上传」
③ 用户确认后允许继续；上传过程中超出配额时提示 存储空间已满，请清理后重试
文案占位：「{已用百分比}」保留 1 位小数（如 92.4%）；「{剩余容量}」按 KB / MB / GB / TB 自动取合适单位，保留 1 位小数（如 78.6 GB）。

3.3 数据来源

  • 已用容量 = 所有知识库的已占用容量之和。
  • 知识库删除、文档增删后需重新拉取并刷新进度条与三个文案。

四、新建知识库向导

入口：右上角「新建知识库」→ 下拉选择「企业知识库」

4.1 弹窗结构与两种创建模式

弹窗骨架
  • 标题：「新建企业知识库」；右上角提供「×」关闭。
  • 左侧步骤导航：按「基础 / 索引与解析 / 召回与检索 / 权限管理」分组，每项显示序号与步骤名，当前步骤高亮；可点击任意步骤直接跳转。
  • 底部：左侧显示进度「第 N / M 步」，右侧「取消」「创建知识库」。
  • 点「×」或「取消」直接关闭弹窗，不弹二次确认。
创建模式步骤数步骤构成适用场景
快速创建
默认		 2 步 基本信息 → 成员管理 零配置，即刻使用。系统已为您预设基础参数，只需填写基本信息即可一键生成知识库，适合快速上手与轻量级应用。
进阶创建 7 步 基本信息 → 模型配置 → 分块设置 → 图像处理 → 高级设置 → 检索策略 → 成员管理 深度定制，精准控制。您可以一步步配置模型、分块规则、检索策略等底层参数，打造完全贴合您专属业务场景的高质量知识库。
模式切换规则：两张卡片为单选，选中卡片显示绿色描边＋右上角勾选标记。切换时只更新左侧导航数量与底部「第 N / M 步」，当前页面内容与已填输入全部保留；若当前停留的步骤在新模式下不存在，自动回到最后一步。默认进入为快速创建（第 1 / 2 步），选择进阶创建后为第 1 / 7 步。

4.2 基本信息（第 1 步）

页面标题「基本信息」，副标题「选择知识库类型并填写相关信息」

字段必填说明
支持的文件格式 — 页面顶部浅黄提示条，只读。内容：Markdown · 文本文件 · PDF · Word · Excel · PPT · 图片，用于提前说明该知识库可上传的文件范围。
创建模式 是 两张并排单选卡片：快速创建 / 进阶创建，卡片内含标题、图标、勾选态与一段说明文案（见 4.1）。切换规则见 4.1 提示。
名称 是 单行输入框，占位符「例如：产品需求文档库」；下方灰色说明「名称将用于识别与检索范围选择。」
图标 否 默认显示玫红色圆角方块＋白色加号，点击打开本地文件选择，选中后立即在预览位显示图片。右侧说明：「支持 JPG、PNG、GIF 格式，图片大小不超过 1MB，建议尺寸 128×128px」。
描述 否 多行文本框，占位符「简要说明该知识库的内容范围与使用场景」。
图标上传校验：文件超过 1MB 时拒绝并提示 图片大小不能超过 1MB；文件选择框默认只过滤 JPG / PNG / GIF。

4.3 模型配置与分块设置（进阶创建）

模型配置

字段默认值说明
Embedding 嵌入模型 *qwen3.7-text-embedding用于文本向量化的嵌入模型。
Wiki 合成模型 *qwen3.8-max用于提取 Wiki 摘要和索引关系的模型。

分块设置

字段默认值 / 范围说明
分块策略自动可选 自动 / 按标题切分 / 结构感知 / 按长度切分；选「自动」时下方展示该模式的说明。旁附「测试分块效果」入口。
分块大小512 字符（100 ~ 4000）每个分块的最大字符数，默认 512 ≈ 中文 300 tokens。
分块重叠80 字符（0 ~ 500）相邻分块共享的字符数，默认 80 ≈ 分块大小的 15%。
分隔符默认 7 个切分时优先使用的字符。默认选中双换行、单换行、中文句号、感叹号、问号、中文分号、英文分号；支持增删与自定义，按选中顺序决定优先级（段落 → 句子 → 标点）。
父子分块开启两级分块：小的子块用于向量匹配，大的父块返回给 LLM 补足上下文。建议用于长文档（> 10 页）。
父块大小4096 字符（512 ~ 8192）开启父子分块后显示，返回给 LLM 的上下文块大小。
子块大小384 字符（64 ~ 2048）开启父子分块后显示，用于向量匹配的嵌入块大小。

4.4 图像处理（进阶创建）

字段默认值说明
多模态功能关闭开启后支持图片等非文本内容的解析与检索。
VLLM 视觉模型 *未选择开启多模态后显示且必选，下拉仅展示带视觉能力的模型。
图片解析要求空开启多模态后显示。补充需重点识别的视觉信息，≤ 4000 字符，右下角实时显示字数（如 120/4000）。

4.5 高级设置（进阶创建）

AI 问题生成

  • 开关默认开启；开启后展开「生成问题数量」与「问题生成要求」。
  • 生成问题数量：整数 1~10，默认 3。
  • 问题生成要求：≤ 4000 字符，右下角实时显示已输入字数（如 120/4000）。

Wiki 设置

字段默认值说明
Wiki 提取粒度标准三选一分段按钮：聚焦 / 标准 / 详尽。下方随选择切换说明：聚焦＝只抽取文档主角，最干净但可能漏掉次要实体；标准＝抽取主角＋被详细描述的次要实体，适合大多数场景；详尽＝抽取所有命名实体与概念，适合把知识库当术语表使用。
Wiki 内容生成要求空≤ 4000 字符，控制摘要、页面与首页的表达重点；引用、合并与防幻觉规则由系统固定维护，修改后需重新解析才对已有内容生效。
Wiki 提取重点空≤ 4000 字符，说明应重点识别的领域实体与概念，不会替换系统的 JSON 与引用协议。

4.6 检索策略（进阶创建）

字段默认值 / 范围说明
向量召回数量10（0 ~ 100）向量检索返回的最大结果数量。
关键词阈值0.30（0 ~ 1，步长 0.01）关键词检索的最低相关性分数，滑块调节并实时回显数值。
向量阈值0.50（0 ~ 1，步长 0.01）向量检索的最低相似度分数。
重排序关闭对召回结果二次排序，提高回答准确性；开启后展开以下三项。
ReRank 模型 *未选择开启重排序后必选。
重排数量5（0 ~ 100）重排序后保留的最大结果数量。
重排阈值0.2（-10 ~ 10，步长 0.1）重排序的最低相关性分数。

4.7 成员管理

区域说明
添加成员点击输入框或「添加」按钮打开成员选择弹窗：支持按姓名 / 手机号 / 工号搜索，或按部门勾选，可多选，确认后加入列表。
成员列表首行为当前创建人，标注「（我）」与「所有者」标签，并提供「转让」入口；其余成员显示姓名、部门、手机号，行内下拉选择角色（管理员 / 编辑者 / 只读），右侧「×」移除。
说明文案列表下方提示：「所有者可将知识库转让给管理员或编辑者，转让后原所有者变为管理员。」
权限说明右侧开关展开权限对照表（能力 × 所有者 / 管理员 / 编辑者 / 只读）：查看检索、上传删除文档、修改配置、管理成员与角色、删除知识库与转让所有者。

4.8 校验与提示

字段规则失败提示
知识库名称必填，1~50 字符，同名不允许请填写知识库名称 / 知识库名称已存在
知识库描述可选，≤ 500 字符超长时禁止输入（不弹提示）
图标JPG / PNG / GIF，≤ 1MB图片大小不能超过 1MB
分块大小整数，100~4000输入中超过上限自动回到 4000；失焦时低于下限自动置为 100
分块重叠整数，0~500同上，按边界自动纠正
父块大小整数，512~8192同上，按边界自动纠正
子块大小整数，64~2048同上，按边界自动纠正
生成问题数量整数，1~10输入框自动纠正到边界值
向量召回数量 / 重排数量整数，0~100输入框自动纠正到边界值
重排阈值范围 -10 ~ 10，步长 0.1，默认 0.2滑块限制，无需提示
关键词 / 向量阈值范围 0 ~ 1，步长 0.01滑块限制，无需提示
VLLM 视觉模型开启「多模态功能」时必填请选择 VLLM 模型
ReRank 模型开启「重排序」时必填请选择 ReRank 模型
成员至少保留 1 名所有者知识库至少需要一名所有者
校验时机：仅「名称」在点击「创建知识库」时校验；其余字段通过输入框上下限与滑块区间在输入阶段约束，不做逐步拦截，允许自由跳转任意步骤。

场景结果提示文案

五、文件管理

详情页「知识库文件」标签

5.1 区域结构

区域内容
顶部标签「知识库文件」「Wiki」两个标签页；Wiki 处理中时标签旁显示转圈标识
右上容量「知识库使用容量：xx」，点击文字或右侧柱状图标打开容量统计弹窗（见 5.11）
左侧文件夹栏标题「文件夹」+ 实时计数「N 个」；下方为目录树
右侧文件区过滤栏 →（勾选后出现）批量操作栏 → 文件表格 → 分页
添加文档右上角「添加文档」按钮，点击展开下拉菜单：「上传文件」「上传文件夹」（见 5.6）

5.2 文件夹树与文件列表联动

点击对象列表结果说明
根节点（知识库名）显示全部文件默认选中；不提供删除入口
父文件夹包含其下所有子文件夹中的文件计数为递归总数
子文件夹仅该文件夹内的文件有子节点时点击同时展开 / 收起
展开箭头只展开 / 收起，不切换选中项无子节点时箭头隐藏
  • 文件夹过滤可与「文档状态」「文件类型」「搜索」叠加生效，四项条件为与关系。
  • 切换文件夹、改筛选、改每页条数时分页重置到第 1 页。
  • 文件夹计数与左上角「N 个」均按当前实际文件数实时统计：目录计数 = 自身及全部子目录下的文件数。

5.3 文件夹「更多」菜单

菜单项交互校验 / 提示
重命名节点就地变为输入框，预填原名并全选；Enter 确认、Esc 取消、失焦即保存清空则回退原名；同级重名拒绝并提示 已存在同名文件夹「{名}」
新建子文件夹节点下方就地插入输入框，Enter 确认 / Esc 取消清空则回退为「未命名文件夹」；同级重名同上
删除二次确认，正文提示「其中的 N 个文件将一并删除，且无法恢复」；N 为含全部子目录的递归文件数确认后该目录、其全部子目录及目录内所有文件一并删除，不可恢复；计数与容量占用同步刷新；若正在浏览该目录（或其子目录）内文件则自动返回根目录；文件夹为空时正文提示「该文件夹下暂无文件」
根节点保护：知识库根节点代表整个知识库，菜单中不显示「删除」；若绕过菜单触发删除，提示 根目录不可删除。

5.4 过滤与分页

控件规则
文档状态下拉：全部 / 解析完成 / 索引中 / 解析中 / 待解析 / 处理失败，单选，选中即过滤
文件类型下拉：全部 / Markdown / 文本文件 / PDF / Word / Excel / PPT / 图片
搜索「搜索文档名称」，输入即时过滤，无需回车；按文件名模糊匹配
分页每页 10 / 20 / 50 条可选；底部显示「共 N 个文件」与上一页 / 当前页 / 下一页，首页与末页按钮置灰
空结果表格区显示「没有匹配的文件」，分页显示「共 0 个文件」

5.5 文件表格

列呈现
勾选框表头为全选（可半选态）；单行勾选进入批量操作
文件名文件图标 + 名称，超长省略并悬浮显示全名；仅「解析完成」的文件可点击，点击打开文件详情弹窗，悬浮变绿并显示下划线
文档大小按量级自动取 KB / MB / GB，保留 2 位小数
文档状态彩色圆点 + 文字：解析完成（绿）/ 索引中（浅绿）/ 解析中（蓝）/ 待解析（紫）/ 处理失败（红）
更新时间格式 YYYY-MM-DD HH:mm
操作行尾「⋯」打开行内菜单（见 5.8）
处理失败行：状态右侧额外显示一个「重新处理」圆形按钮，悬浮提示「处理失败：{失败原因}，点击重新处理」；点击后状态置为「待解析」并提示「已加入重新处理队列」。

5.6 上传文件 / 文件夹

入口：右上角「添加文档」→ 上传文件 / 上传文件夹；或「添加文档」弹窗内的拖拽区

区域说明
拖拽区支持点击选择或拖入文件；说明文案「支持 Markdown · 文本文件 · PDF · Word · Excel · PPT · 图片，单个文件不超过 100MB」
支持的文件类型白名单校验，仅以下扩展名可上传：md markdown txt pdf doc docx xls xlsx csv ppt pptx jpg jpeg png gif webp bmp。不在白名单内的文件仍保留在待添加列表，但整行置灰并标记「暂不支持该类型文件，无法上传」，提交时自动跳过
待添加列表显示「待添加 N 个文件」与「清空」；每行列出文件图标、名称、（上传文件夹时）相对路径、大小与移除「×」；不支持的文件行内额外显示红色标签
添加到文件夹下拉列出目录树中的全部路径，默认定位到当前选中的文件夹
保留文件夹结构仅上传文件夹时出现，默认勾选；说明文案「将在所选文件夹下新建「{源文件夹名}」，并按原层级放入文件」
底部按钮「取消」/「添加到知识库」；存在不支持的文件时按钮文案变为「添加到知识库（跳过 N 个不支持的文件）」
场景结果 / 提示
重复选择同一文件按「文件名 + 大小」去重，不重复加入待添加列表
选择了不支持的文件类型保留在待添加列表并置灰，行内标记「暂不支持该类型文件，无法上传」，同时提示 不支持的格式：{文件名}，仅支持 Markdown、文本文件、PDF、Word、Excel、PPT、图片；多个不支持时取前 2 个文件名，其余合并为「等 N 个文件」。用户可手动移除，提交时不支持的文件自动跳过
上传文件夹时含不支持的文件逐个按扩展名判断，系统文件 / 临时文件等不支持项同样置灰保留在列表，其余文件与目录结构照常导入；给出一次与上方一致的提示
选中的文件全部不支持按钮文案变为「添加到知识库（无可上传文件）」；点击后不提交，提示 所选文件均不支持上传，仅支持 Markdown、文本文件、PDF、Word、Excel、PPT、图片
部分文件不支持时提交仅上传合法文件；若本次未同时导入文件夹，提示「已跳过 N 个不支持的文件」
未选文件就提交提示 请先选择要添加的文件
提交成功文件以「待解析」状态插入列表顶部，分页回到第 1 页，表格与左侧计数同步刷新，并打开上传进度面板（见 5.7）
上传文件夹且保留结构按原层级自动创建目录，完成后额外提示「已导入文件夹，已创建文件夹「{名}」」
文件归属规则勾选保留结构时文件放入对应子目录；未勾选时全部直接放入所选目标文件夹；目标为根目录时不记录层级

5.7 上传进度面板

元素说明

标题「正在解析 {已完成}/{总数}」，副标题「上传至「{目标文件夹}」」
进度条按完成比例推进，最小保留 6% 可见宽度；底部圆点 + 「处理中 {未完成数}」
文件列表逐条展示文件名、类型标签与状态：排队解析 → 解析中… → 解析完成；完成项右侧为「查看」箭头，未完成项为「重新上传」按钮
说明文案「文件已全部上传，解析在后台继续，可以放心离开此页面」

失败态标题「0 个完成，{N} 个未成功」，进度条转红；顶部出现「全部 {N} / 未成功 {N}」页签，每条显示「解析失败 · {失败原因}」，右侧为重新解析按钮；面板不自动收起，需手动关闭

七、文件详情

入口：文件列表点击文件名 / Wiki 词条页「来源文档」链接

7.1 区块结构

区块内容
弹窗标题栏左侧文件名（过长省略，悬浮显示全名）；右侧「下载」按钮与关闭「×」
基本信息上传时间、类型、上传人
自定义元数据键值对列表，可编辑（文本 / 数字 / 布尔值 / 空值四种类型）
摘要可编辑、可重新生成、可删除
文件预览原文件渲染
文件分块片段列表，每个片段可启用/停用、编辑、查看父块、管理辅助召回问题

7.2 文件下载

位置与样式
  • 位置：详情弹窗标题栏右侧、关闭「×」左侧，与列表行菜单「下载文件」为同一功能入口。
  • 样式：浅色描边按钮，下载图标 + 文字「下载」；悬浮时描边与文字变绿（品牌色 #07C160），背景转为浅绿。
  • 点击：直接下载该文件的原始文档，不关闭详情弹窗，不影响当前分块浏览与编辑状态。
  • 下载的是用户上传的源文件本体，不是预览渲染结果或分块内容。
交互触发条件结果
点击「下载」按钮可用立即开始下载，提示「正在下载「{文件名}」」；完成后提示「已下载「{文件名}」到本地下载目录」；弹窗保持打开
下载失败源文件缺失 / 网络异常提示 下载失败，请稍后重试；按钮恢复可点
下载中重复点击请求未结束按钮置灰不可点，避免重复发起
源文件已被清理仅有索引与分块、无原始文件按钮置灰并悬浮提示「源文件已失效」

7.3 辅助召回问题

操作交互提示
新增点「+」展开输入框，Enter 确认「已添加 1 个辅助召回问题」
编辑行内变输入框，预填并全选；Enter 保存、Esc 取消；编辑态常驻显示 ✓/×空内容 问题内容不能为空；成功「问题已保存」
删除无需二次确认，点击即删；弹窗内列表与标题计数立即刷新「已删除 1 个辅助召回问题」
重新生成覆盖该片段全部问题「已重新生成辅助召回问题」

7.4 来源文档链接

  • Wiki 词条页「来源文档」中的链接，点击后打开对应文件的详情弹窗，而非跳转新页面。
  • 若文档名在文件库中不存在，提示 原型演示：打开文档 {名}（正式环境应提示「源文件已删除」并置灰）。

八、编辑知识库

入口：详情页「编辑知识库」按钮 / 卡片菜单「编辑知识库」

8.1 结构

与新建向导的步骤一致（7 步，左侧导航），区别仅在于：所有字段预填当前值，底部按钮为「取消 / 保存」。

8.2 字段可编辑范围

总原则

除 Embedding 嵌入模型 外，其余参数全部可编辑。

步骤可编辑字段说明
1 基本信息名称、图标、描述均可改；名称变更后，左侧目录树的根节点名称与已有文件的归属路径同步更新
2 模型配置 Wiki 合成模型
Embedding 嵌入模型（不可编辑）		 嵌入模型置灰不可点，下拉箭头保留但为禁用态，悬浮/下方说明文案「嵌入模型在创建后不可修改」。原因：更换嵌入模型需要全量重新向量化存量数据，创建后不允许变更
3 分块设置分块策略、分块大小、分块重叠、分隔符、父子分块开关、父块大小、子块大小改动后需重新解析才对已有文档生效
4 图像处理多模态功能开关、VLLM 视觉模型、图片解析要求关闭多模态后，模型选择与解析要求两项隐藏
5 高级设置AI 问题生成开关、生成问题数量、问题生成要求、Wiki 提取粒度、Wiki 内容生成要求、Wiki 提取重点同新建向导的字段与范围限制
6 检索策略向量召回数量、关键词阈值、向量阈值、重排序开关、ReRank 模型、重排数量、重排阈值阈值类为滑块；改动即时生效，无需重新解析
7 成员管理添加成员、成员角色、移除成员、转让所有者至少保留 1 名所有者
嵌入模型锁定说明：该字段在编辑弹窗中始终展示当前值，用户可读但不可改；保存时也不会提交该字段。若业务上确需更换嵌入模型，应通过「重建知识库」或管理端迁移流程处理，不在此弹窗内提供入口。
