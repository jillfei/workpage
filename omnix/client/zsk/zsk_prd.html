一、概述

1.1 背景与问题

用户在日常工作中积累了大量本地文件——产品规范、研究报告、技术文档、合同模板、设计素材等，分散在不同的本地文件夹中。要让 AI Agent 能够基于这些资料进行检索、问答与生成，必须先把这些本地资料"接入"系统并建立可检索的索引。当前存在以下突出问题：

  • 本地资料无法被 AI 利用：文件躺在本地磁盘，Agent 无法读取与检索，用户只能手动复制粘贴内容，效率低且易出错。
  • 索引过程不可见：扫描了多少文件、哪些解析成功、哪些失败、容量占用了多少，缺乏统一的可视化呈现，用户无从判断资料是否被正确纳入。
  • 多知识库缺乏统一运维入口：当知识库数量增多，缺少集中查看、搜索、筛选与删除的管理视图，运维成本高。

为此，平台需要一套本地知识库管理能力：用户绑定一个本地文件夹，系统自动扫描、解析内容、提取元数据并向量化，形成可被检索的知识库；同时提供列表总览与详情浏览（目录树 + 文件表格）、逐文件状态与操作、容量统计，构成知识库的完整生命周期管理。

1.2 目标用户与典型场景

知识工作者 / 研究者

收集行业研究报告、财务数据、文献资料，绑定文件夹建库后直接向 AI 提问"某行业最新数据是什么"。典型场景：研究员绑定"金融投资研究"文件夹，基于库内资料快速检索与问答。

产品 / 设计 / 技术团队

沉淀产品规范、UI 组件库、技术架构与接口文档，建库便于团队检索复用。典型场景：产品同学把"产品设计资料库"文件夹绑定，让 AI 基于设计规范评审新方案。

法务 / 合规人员

归档合同模板、法律文书范本、合规清单，需快速检索特定条款。典型场景：法务绑定"法律合同归档"文件夹，检索某类合同条款与范本。

1.3 核心概念

概念定义与说明
本地知识库 用户绑定一个本地文件夹后，经系统扫描、解析、向量化形成的可检索知识集合。一条知识库记录包含：名称、图标、描述、状态、类型（本地文件夹）、绑定路径、文件数量、创建时间与更新时间。一个知识库对应一个本地文件夹。
知识库状态 知识库的整体生命周期状态，分三态：待处理（已创建但尚未开始解析）、处理中（系统正在后台解析与向量化）、已完成（索引就绪，可供检索）。新建知识库提交后进入"处理中"，由系统后台自动推进为"已完成"。
文档状态 知识库内每个具体文件的解析状态，分五态：待解析、解析中、已完成（已索引，可检索）、暂不支持（文件格式不在支持范围）、解析失败（解析引擎报错，如文件加密或损坏）。
扫描 / 解析 / 向量化 绑定文件夹后系统依次执行的三步：扫描文件结构、解析正文内容与元数据、向量化生成索引。这是知识库从"处理中"走向"已完成"的核心处理链路。
容量 知识库占用的存储空间，按文件类型（Markdown、文本、PDF、Word、Excel、PPT、图片）分别统计数量、大小与占比，帮助用户了解存储分布。
目录树 按文件夹层级组织的结构视图，展示各级文件夹及其文件数量，支持展开/收起，以及文件夹级操作（打开、重命名、新建子文件夹、删除）。

1.4 用户故事

作为 知识工作者，我希望 绑定一个本地文件夹来创建知识库，以便 无需手动搬运文件，就能让 AI 基于其中的资料进行检索与问答。
作为 产品同学，我希望 在知识库详情中按文件夹浏览、搜索并查看每个文件的解析状态，以便 确认资料是否被正确索引，发现未索引的文件及时处理。
作为 研究员，我希望 对解析失败的文件一键重新解析，并查看失败原因，以便 修正问题（如解除加密）后让资料重新可被检索。
作为 管理员，我希望 查看知识库容量统计（按文件类型分布），以便 了解存储占用情况，避免容量无序增长。

1.5 非目标

  • 不做云端 / 远程知识库，本期仅支持绑定本地文件夹，不支持远程存储或第三方网盘。
  • 不做知识库之间的文档移动与共享，每个知识库独立绑定各自文件夹。
  • 不做在线编辑文档内容，本模块只管理本地文件的索引，不修改原文件（删除知识库仅移除索引，原文件夹文件保留）。
  • 不做权限与协作，知识库为个人级别，不跨用户共享。
  • 不做知识图谱实际展示，"知识图谱"页签本期仅占位（界面默认隐藏，展示预览占位区），不实现图谱渲染。

二、功能架构与流程图

2.1 系统架构图

本地知识库模块由两个页面构成：知识库列表页是总览与运维入口，知识库详情页是文档浏览与管理的核心。详情页由头部信息、目录树、文件区（统计·容量·筛选·表格·批量·分页）与一组弹窗（新建、编辑、设置、移动到、容量详情、确认）共同组成。

2.2 业务流程图

下图描述一条知识库从创建到运维的完整业务流转。用户从列表页"新建知识库"进入配置，选定本地文件夹后系统开始扫描、解析与向量化，状态从"处理中"自动转为"已完成"后可供检索。进入详情页后，用户可浏览目录树、按文件名/状态/类型筛选文件、对文件执行移动/删除/重新解析等操作，并可查看容量统计。用户也可随时"立即更新"重新扫描，或对整库执行删除（仅移除索引，原文件保留）。

💡 业务闭环说明：知识库自"新建"起进入扫描→索引链路，状态自动从处理中转为已完成；用户在详情页完成文档级浏览与运维，也可在列表/详情触发"立即更新"重新扫描；删除知识库仅移除系统索引，本地原文件不受影响。

三、详细设计

本地知识库模块包含两个页面：知识库列表页（总览与运维入口）与知识库详情页（文档浏览与管理中枢）。以下按页面分别说明功能描述、显示字段与表单字段。

🔹 3.1 知识库列表页

功能描述

知识库列表页是模块的主入口，以两列卡片网格展示用户全部本地知识库。每张卡片展示图标、名称、状态标签、来源（OmniX @ 本地文件夹）、描述、绑定路径标签、文件数量以及创建/更新时间；鼠标悬停时显示删除按钮与"去使用"按钮。页面顶部常驻"新建知识库"入口；筛选行提供搜索框（按名称与描述过滤）与状态筛选（全部状态 / 待处理 / 处理中 / 已完成）。点击卡片本身进入对应知识库详情页。新建时弹出配置弹窗，提交后展示扫描进度遮罩与扫描结果，新库以"处理中"状态加入列表。删除需二次确认，并明确提示"原文件夹中的文件不会被删除"。当没有任何知识库时展示空状态引导。

去使用按钮 悬停卡片时显示于底部右侧，点击跳转至该知识库详情页 例外：仅悬停时显示（默认隐藏）；底色为黑色（#1F2937），悬停时更深（#111827）；用于快速进入知识库应用
搜索框 输入关键字实时过滤，匹配知识库名称与描述 边界：不区分大小写；无匹配时展示空状态
状态筛选 切换筛选：全部状态 / 待处理 / 处理中 / 已完成 例外："处理中"筛选同时包含"待处理"与"处理中"两类（视其为进行中的连续态）；"待处理"仅筛选待处理
空状态 无知识库时居中引导，提供"创建第一个知识库"入口 边界：仅当过滤后列表为空时展示
💡 "处理中"与"待处理"在筛选中归为同一连续态（选"处理中"即含二者）；"删除知识库"仅移除系统索引，本地原文件保留，二次确认弹窗对此有明确提示。

🔹 3.2 知识库详情页

功能描述

知识库详情页进入某知识库后展示其全貌。顶部为返回导航；头部展示大图标、名称（可编辑）、状态、绑定路径、更新时间与"立即更新"按钮、描述。页签提供"文档"（默认展示）与"知识图谱"（本期隐藏占位）。主区左侧为目录树，按文件夹层级展示结构与文件计数，每个文件夹支持更多操作（打开文件夹、重命名、新建子文件夹、删除）；主区右侧为文件区：顶部状态统计卡（待解析/解析中/已完成/暂不支持/解析失败）、容量链接、"重新解析"按钮（仅存在解析失败文件时显示）、设置入口（本期隐藏）；下方为筛选区（文件名搜索、文档状态下拉、文件类型下拉、批量操作条）与文件表格（复选框、文件名称含文件夹子行、文档大小、文档状态、更新时间、修改人、操作更多菜单），底部为分页。点击文件名称可打开本地文件；解析失败文件在操作菜单提供"重新解析"并展示失败原因。

文档状态（表格列） 以彩色标签展示该文件解析状态 边界：解析失败额外显示警告图标，悬停展示失败原因 tooltip（如"文档包含加密内容""文件损坏"）
更新时间（表格列） 展示文件最近更新时间 来源：文件记录
修改人（表格列） 展示最后修改人名称 来源：文件记录（示例数据含具体人名）
操作 - 更多菜单 每行"更多"展开：重新解析（仅解析失败时）、复制路径、文件管理器中打开、移动、删除 例外：重新解析仅对解析失败文件出现；复制路径 / 打开（演示环境）给出提示；移动打开目标文件夹选择；删除需确认
分页 展示"共 X 项，每页显示 15 项"，含上一页/页码/下一页与跳页输入 边界：本期分页控件仅作展示，文件列表一次性渲染（未真正实现分段加载）
💡 "重新解析"与"解析失败"的警告提示构成失败处理的闭环：失败时展示原因，用户可单文件或批量重置为待解析重新走索引流程。"解析失败"文件在操作菜单才出现"重新解析"项，避免对正常文件造成误操作。

表单字段说明（编辑知识库弹窗）

字段类型必填说明（含表单字段和表单按钮）
名称 单行文本 是 知识库名称；来源：回填当前知识库名称，用户可改。边界：最多 50 个字符；为空时阻止保存。
图标 图片上传 否 知识库图标；限制同新建（JPG/PNG/GIF ≤1MB，建议 128×128）。
知识库路径 文本（禁用） 显示 绑定路径展示但不可编辑；提示"仅支持本地文件夹，绑定后不可修改"。边界：输入框禁用，保存时不接受变更。
描述 多行文本 否 知识库用途说明；来源：回填当前描述，用户可改。
支持的文件格式（提示） 说明区 — 弹窗内提示区列出支持格式，仅作说明。
取消（按钮） 按钮 — 关闭弹窗，放弃修改。
确定（按钮） 按钮 — 保存名称与描述变更，同步更新头部展示，关闭弹窗。
💡 设置弹窗（本期界面隐藏）的表单字段：① 文档解析默认模型——单选"企业默认模型 / 自定义模型"，自定义模式下可添加或移除已配置模型（标签"文档解析"）；② 知识库向量化模型——单选"企业默认向量模型"。两者均默认选中企业默认项，自定义解析模型优先级高于企业默认。
