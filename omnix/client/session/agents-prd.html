2. 各模块功能与交互说明

2.1 顶部导航

元素交互说明
会话标题 点击标题区进入编辑态（contenteditable），自动全选文字；按 Enter 保存，按 Esc 取消；失焦自动保存。
对话内搜索 点击放大镜或按 ⌘/Ctrl + F 唤起搜索框；输入关键词后聊天区文本高亮，显示 x/y 计数；支持"上一个 / 下一个"循环跳转，当前命中项用橙色高亮并自动滚动；关闭后还原原文。
历史提问 点击时钟图标展开下拉，列表动态收集聊天区所有用户问题（兜底展示内置问题）；点击任意历史项，聊天区平滑滚动到对应消息。
侧边栏开关 点击右侧"侧边栏"按钮，右侧抽屉滑出，主内容区同步右移；再次点击或点击遮罩关闭。

2.2 聊天区

元素交互说明
用户消息气泡 点击编辑图标进入编辑态：气泡变为可编辑输入框，底部出现提示条 +"取消 / 发送"按钮；Enter（非 Shift）保存，Esc 取消；空内容时回退原文。
智能体标签 助手回复下方展示参与执行的子智能体标签（如 Mutation boundary cas / Remaining plan sync / Frontend autosave review）。点击任意标签打开"智能体详情抽屉"，并自动定位到该智能体。
富文本内容 助手回复支持文件树、表格、代码块（含复制图标悬停）、行内代码、附件卡片、操作按钮（复制、点赞、点踩、分享等）。(详见会话渲染组件案例库)

2.3 任务队列

  • 拖拽排序：按住左侧拖拽柄拖动任务行，根据鼠标位置插入到目标行上方或下方，拖动过程中该行半透明。
  • 悬停操作：鼠标悬停任务行时右侧显示"立即发送 / 编辑 / 删除"三个图标按钮。
  • 内联编辑：点击编辑后任务文本变为输入框，失焦时保存 / Esc 取消。

2.4 输入区

元素交互说明
多行输入框 支持在输入区上方以标签形式展示已选技能 / 文件。
选择 + 下拉提供"上传照片和文件"、以及浏览器 / 文档解析 / PPT 生成等插件入口。
技能 下拉展示技能列表，顶部搜索框可按名称和描述实时过滤；点击技能项切换选中，并在输入区生成蓝色标签；支持"从本地添加 / 管理技能"。
专家·专家团 下拉分"专家"与"专家团"两组，点击单选；选中后在工具栏生成专家标签并隐藏原按钮；支持"召唤更多专家·专家团"。
默认权限 下拉三档：只读 / 默认权限 / 完全访问。选择"完全访问"时弹出风险确认模态框，需勾选"我已了解风险"并点击确认后方可生效。
模型选择 下拉展示企业与个人模型（gpt-5.5 / gpt-5 / gpt-4o / claude / deepseek 等），单选并更新工具栏显示。当没设置企业模型时，企业模型不显示
质量 下拉四档：轻度 / 中 / 高 / 极高，单选。
上下文用量环 圆环按已用上下文比例变色（蓝 / 橙 / 红）；点击显示详情，展示模型名、已用 / 总量、进度条。
发送按钮 输入为空时灰色禁用，有内容后变为深色可点击。

3. 右侧侧边栏：子智能体 / 概览

点击顶部导航"侧边栏"按钮后，右侧滑出抽屉式侧边栏（默认宽度 640px，可拖拽调整、可最大化全屏）。顶部有两个主 Tab：子智能体 与 概览。

3.1 子智能体 Tab

  • 左侧导航：按"执行中"与"已完成"分组列出子智能体任务，点击任务项高亮并渲染右侧详情。
  • 右侧详情：展示任务标题、状态、处理说明段落、可折叠的"编辑了文件"记录、智能体更新记录等。
  • 拖拽改宽：抽屉左侧有 8px 拖拽柄，可左右调整侧边栏宽度（最小 400px，最大 95vw）。
  • 最大化：点击顶部最大化按钮切换全屏，主内容区同步调整。

3.2 概览 Tab

概览 Tab 内部又包含一个顶部下拉切换：概览 / 项目文件 / 浏览器 / 变更。

子视图功能与交互
概览 左侧"输出"分区展示产物文件列表（md / html），点击文件在右侧渲染文件内容；分区标题可折叠；右侧支持标签页切换与关闭。
项目文件 左侧展示项目文件树，文件夹可展开 / 收起，文件点击后在右侧渲染；与概览共用同一套右侧渲染区域和标签页。
浏览器 左侧展示产物文件列表，顶部模拟浏览器地址栏（后退 / 前进 / 刷新 / 外部打开）；选中文件后在右侧 iframe 区域渲染。
变更 左侧展示变更文件列表及总增删行数；选中文件后在右侧显示 diff 视图，新增 / 删除行分别用绿 / 红底色高亮。

3.3 标签页管理

在概览及其三个子视图中打开的文件会以标签页形式展示在顶部 Tab 栏下方。标签页支持：

  • 点击切换已打开文件；
  • 点击右侧 ✕ 关闭标签；
  • 关闭后自动激活相邻标签。

4. 智能体详情抽屉

点击聊天区任意智能体标签，或点击侧边栏"子智能体"中的任务项，会打开一个更宽（900px）的智能体详情抽屉，采用完整三栏结构：

  • 顶部 Tab："子智能体"与"概览"。
  • 左侧导航：列出子智能体，点击切换右侧内容。
  • 右侧详情：展示该智能体的状态、说明段落、可折叠文件编辑记录、智能体更新记录。

4.1 关键交互

交互说明
打开 从右侧滑入，带遮罩；默认展示"子智能体"Tab 并高亮左侧对应任务项。
关闭 点击遮罩、点击右上角关闭按钮、按 Esc 均可关闭。
最大化 / 还原 点击顶部最大化按钮切换 100vw 全屏与普通宽度。
左侧任务切换 点击左侧任意任务项，右侧即时刷新为该智能体详情。
编辑了文件 文件编辑记录行可点击展开 / 收起。

在"变更"子视图中，选中变更文件后右侧展示 diff 视图：

  • 新增行：绿色背景 + 绿色行号；
  • 删除行：红色背景 + 红色行号；
  • 上下文行：默认白色背景；
  • HTML 文件额外进行标签 / 属性 / 字符串语法高亮。
