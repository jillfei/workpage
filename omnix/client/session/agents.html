核心能力

功能 说明

使用方式

当你说「把 xxx.pptx 转成 HTML」时，技能会自动触发，执行：

bash 
python scripts/ppt2html.py input.pptx [--theme dark] [--transition zoom] [--autoplay 5]

生成的 HTML 播放器支持快捷键：← → 翻页、F 全屏、T 缩略图、Space 自动播放。
