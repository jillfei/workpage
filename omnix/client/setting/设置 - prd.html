功能概述

账户管理模块用于管理用户的个人信息与偏好设置，包含以下核心功能：

功能 说明
基本信息管理 查看和修改用户头像、用户名
手机号管理 更换绑定手机号（两步验证）
密码管理 修改登录密码（格式校验）
系统偏好设置 发送消息快捷键、技能自动更新、存储路径
账户操作 退出登录

修改信息

触发方式

点击用户信息卡片右侧的"修改信息"按钮

弹窗内容

元素 说明
头像展示 圆形头像，点击可选择新图片
更换头像按钮 点击打开文件选择器
用户名输入框 可编辑，1-20个字符
取消/保存按钮 取消关闭弹窗，保存更新信息

交互逻辑

交互流程
点击头像或"更换头像"按钮 → 打开文件选择器
选择图片后 → 弹窗内头像实时预览
点击"保存" → 主页面头像同步更新，关闭弹窗

校验规则

校验项 规则 错误提示
用户名 必填，1-20个字符 请输入用户名

更换手机号

两步验证流程

1
验证当前手机
→
2
绑定新手机

第一步：验证当前手机

元素 说明
当前手机号 部分隐藏显示（如：131****6909）
验证码输入框 6位数字输入
发送验证码按钮 点击发送验证码，60秒倒计时
下一步按钮 输入6位验证码后启用
交互流程
点击"发送验证码" → 60秒倒计时，按钮显示"XXs"
输入6位验证码 → "下一步"按钮启用
点击"下一步" → 验证验证码，通过进入第二步

第二步：绑定新手机

元素 说明
国家代码 固定显示"+ 86"
新手机号输入框 11位手机号输入，格式校验
验证码输入框 手机号校验通过后才可点击发送
上一步按钮 返回第一步，保留验证状态
保存按钮 所有验证通过后启用
交互流程
输入新手机号 → 实时校验格式
手机号格式正确 → 启用验证码输入框和发送按钮
输入6位验证码 → "保存"按钮启用
点击"保存" → 验证验证码，通过保存成功

输入框状态

状态 样式 说明
默认 灰色边框 未输入或未校验
错误 红色边框 格式校验失败
成功 绿色边框 格式校验通过

修改密码

弹窗内容

元素 说明
原密码输入框 密码类型，可切换显示/隐藏
新密码输入框 密码类型，8-20位字符，包含大写字母、小写字母、数字
确认新密码输入框 校验是否与新密码一致
取消/保存按钮 取消关闭弹窗，保存修改密码

交互逻辑

交互流程
输入原密码 → 实时校验是否非空
输入新密码 → 实时校验格式
输入确认密码 → 实时校验是否与新密码一致
点击"保存" → 验证原密码，通过则修改成功

校验规则

校验项 规则 错误提示
原密码 必填 请输入原密码
原密码 必须正确（模拟：password123） 原密码错误
新密码长度 8-20位字符 密码格式不满足要求
新密码大写 必须包含大写字母 密码格式不满足要求
新密码小写 必须包含小写字母 密码格式不满足要求
新密码数字 必须包含数字 密码格式不满足要求
确认密码 必须与新密码一致 两次密码不相同

功能概述

模型管理模块用于配置和管理AI模型供应商及API密钥，包含以下核心功能：

功能 说明
供应商管理 添加、删除AI模型供应商
模型配置 配置模型API密钥、上下文长度等参数
默认模型设置 选择和切换默认使用的AI模型
自定义供应商 支持添加自定义OpenAI兼容的供应商

支持的供应商

供应商 说明
OpenAI 官方API，支持GPT系列模型
百炼 阿里云百炼平台，支持通义千问系列
深度求索 DeepSeek API，支持V4等模型
MiniMax MiniMax API
月之暗面 Moonshot API
智谱 智谱AI API，支持GLM系列模型
自定义供应商 支持任何OpenAI兼容的API

添加模型配置

添加新的AI模型供应商配置：

字段 说明
供应商 选择要添加的供应商类型
API Key 供应商提供的API密钥（自定义供应商为非必填）
模型名称 自定义供应商时填写（仅自定义供应商）
API Base API端点地址（仅自定义供应商）
上下文长度 模型支持的最大上下文长度（仅自定义供应商）
输出上限 模型单次最大输出Token数（仅自定义供应商）

校验规则

必填项说明
自定义供应商：模型名称、API Base 为必填
预设供应商：API Key 为必填
必填项全部填写后，"添加模型"按钮才会启用
连通性校验
点击"添加模型"后，系统会自动校验 API Key 的连通性
校验通过 → Toast 提示"添加模型成功"，模型添加到列表
校验失败 → Toast 提示"添加模型失败"

已添加模型管理

管理已配置的供应商和模型：

操作 说明
展开/折叠 点击供应商卡片头部展开或折叠模型列表
选择模型 点击单选按钮选择要使用的模型
切换默认 选中非默认模型后，点击"切换为默认"按钮设置为默认模型
编辑模型 点击编辑按钮修改模型配置（仅自定义供应商）
删除模型 点击删除按钮删除模型（需确认删除确认弹窗）
删除供应商 点击供应商卡片的删除按钮删除整个供应商（需确认删除确认弹窗）

默认模型设置

设置系统默认使用的AI模型：

交互流程
选择任意供应商下的模型
点击"切换为默认"按钮
该模型将被标记为"默认"

插件模块用于扩展AI智能体的能力，支持安装、卸载和管理各类功能插件：

功能 说明
插件市场 浏览和搜索可用的功能插件
插件分类 按类别查看插件（桌面控制、浏览器自动化等）
安装插件 一键安装所需的功能插件
卸载插件 移除不需要的功能插件

可用插件

浏览器自动化

插件名称 说明
Google Chrome 浏览器插件 浏览器自动化控制，需要注册浏览器扩展插件

搜索插件

在搜索框输入关键词可快速筛选插件：

搜索规则
支持按插件名称搜索

安装与卸载

交互流程
点击"+"按钮 → 直接安装插件（显示加载动画）
安装完成 → 按钮变为删除图标，显示"已安装"标签
点击删除按钮 → 直接卸载插件（显示加载动画）
卸载完成 → 按钮恢复为"+"图标，隐藏"已安装"标签
Toast 提示
安装成功 → 提示"插件名"安装成功（绿色）
卸载成功 → 提示"插件名"已卸载（绿色）

按钮状态说明

状态 样式 说明
未安装 白色背景 + "+"图标 点击安装插件
安装中 显示旋转加载动画 正在处理安装
已安装 浅蓝背景 + 删除图标 点击卸载插件
卸载中 显示旋转加载动画 正在处理卸载

功能概述

Token用量模块用于监控和分析AI模型的Token消耗情况，帮助用户了解使用趋势：

功能 说明
用量统计卡片 显示Token总量、活跃天数、日均Token、单日峰值
Token统计表 折线图展示输入/输出Token趋势
热力图 近一年每日Token使用量可视化
模型消耗分析 按模型维度查看Token消耗情况

统计卡片

页面顶部显示四个核心统计指标：

指标 说明
Token 总量 累计使用的Token总数
活跃天数 有Token消耗的天数
日均 Token 平均每天消耗的Token数
单日峰值 单日最高Token消耗量

Token 统计表

折线图展示Token使用趋势，支持多种时间范围筛选：

时间范围筛选
快捷筛选：7天、15天、30天
自定义日期范围：选择起止日期
图表说明
紫色线条：输入Token数量
绿色线条：输出Token数量
鼠标悬停显示具体数值和日期

近一年热力图

以热力图形式展示近一年的Token使用情况：

热力图说明
颜色越深表示当日Token消耗越多
灰色表示当日无Token消耗
鼠标悬停显示具体日期和Token数量

模型 Token 消耗

按模型维度查看Token消耗情况：

交互流程
通过下拉框选择不同模型
切换模型后图表自动更新
显示该模型的输入/输出Token趋势

刷新功能

点击刷新按钮可获取最新的Token使用数据：

刷新说明
点击刷新按钮，图标显示旋转动画
数据更新后，统计卡片和图表同步刷新
页面显示"统计生成"时间戳
