自动化模块

任务调度尽在掌握 · 创建 · 编辑 · 运行 · 模板 · 执行历史 —— 产品需求文档 v2.0

文档版本修改日期修改人修改说明
v2.0 2026-07-28 产品 统一标准，描述字段来源、例外与边界

一、概述

1.1 背景与问题

在 AI Agent 平台中，用户经常需要重复执行某些任务，例如每日推送新闻、每周整理工作周报、在固定时间发出提醒等。当前用户只能手动逐次触发 Agent，无法预先设定周期性或定时任务，存在以下突出问题：

  • 重复操作成本高：相同内容需要每天或每周手动发起，浪费时间且容易遗漏。
  • 缺乏可观测性：任务是否执行、执行结果成功还是失败难以追溯，出问题无从排查。
  • 创建门槛偏高：从零配置提示词、模型、技能、频率让用户望而却步，复用困难。

为此，平台需要一套任务调度与自动化执行管理能力：让用户配置一次，系统按设定频率自动执行，并提供模板快速复用、执行历史追溯与运行状态管控。

1.2 目标用户与典型场景

日常效率型用户

希望定时提醒（下班提醒、体检预约）、规律推送（新闻、单词），追求"不遗漏"的日常辅助。典型场景：每天 18:00 提醒下班、每天 07:00 提醒体检注意事项。

内容创作者

需要周期性产出内容（壁纸、冷知识、电影推荐），习惯从模板一键创建、自动产出。典型场景：从模板中心选择"每日新闻推送"后自动开启每日信息推送。

项目管理型用户

需要定期汇总信息（周报、仓库动态、会议准备），依赖技能与 MCP 获取业务数据。典型场景：每周五 17:00 自动从代码仓库提取 PR/Issue 并整理成周报。

1.3 核心概念

概念定义与说明
自动化任务 用户配置的一条"定时/周期性由 Agent 自动执行"的任务，包含名称、提示词、模型、技能、MCP、执行频率与生效区间。每条任务仅执行一条提示词（单步执行）。
运行状态 任务的生命周期状态，分为四态：生效中（正常按频率执行）、已暂停（用户主动暂停，不再触发）、已失效（如单次任务已过执行时间，不再运行）、执行中（手动或定时触发后临时展示的运行态）。
执行频率 决定任务何时运行的规则，提供三种模式：按周期（每天/每周/双周/每月/每年）、按间隔（每隔 N 小时，可限定星期）、单次（指定日期时间，仅执行一次）。
模板 平台预置的常见自动化配置（名称、提示词、模型、技能、MCP、频率均已填好），用户点击即可一键创建，降低配置门槛。
执行记录 每次任务运行的留痕，记录关联任务名称、执行结果（成功/失败/等待中）与执行时间，供用户追溯与排查。
模型 / 技能 / MCP 任务执行时可绑定的能力：模型决定使用哪个 AI 模型；技能提供特定领域能力（如腾讯文档、ima 知识库）；MCP 提供外部服务连接（如代码仓库、自定义服务）。三者均为可选绑定。

1.4 用户故事

作为 日常效率型用户，我希望 设定"每天 18:00 提醒我下班"的自动化任务，以便 不用每天手动触发，系统自动在下班时间提醒我，避免忘记休息。
作为 项目管理型用户，我希望 创建"每周五 17:00 工作周报"自动化，绑定代码仓库 MCP 与文档技能，以便 系统自动提取仓库动态并整理成周报，节省每周手动汇总的时间。
作为 内容创作者，我希望 从模板中心选择"每日新闻推送"模板一键创建自动化，以便 不用从零填写提示词和频率配置，快速开启每日信息推送。
作为 所有用户，我希望 在已执行列表中查看历史运行记录及成功/失败状态，以便 追溯任务执行效果，发现失败时能及时排查问题。

1.5 非目标

  • 不做触发式自动化（如"当收到邮件时自动执行"），本期仅支持时间触发（定时/周期/单次）。
  • 不做分支/条件逻辑（如 if-else），每条自动化仅执行一条提示词。
  • 不做多步骤串联（如第一步执行 A → 第二步执行 B），每条自动化为单步执行。
  • 不做任务共享/协作，自动化为个人级别，不跨用户。
  • 不做失败自动重试与告警通知，执行结果仅记录与展示，不主动推送失败通知。

二、功能架构与流程图

2.1 系统架构图

自动化模块由四个功能页面构成：自动化列表是核心入口，已执行记录提供历史追溯，模板中心提供快速创建，创建/编辑自动化是任务配置中枢，其下挂载名称、提示词、模型、技能、MCP、执行频率与生效区间等配置项。

2.2 业务流程图

下图描述一条自动化任务从创建到运行、再到运维管控的完整业务流转。用户可通过手动创建或模板创建两种入口进入配置；配置完成后任务生效并进入调度；运行过程中可手动触发或等待定时触发，每次执行生成一条执行记录；用户可随时暂停、恢复、编辑或删除任务。

💡 业务闭环说明：任务保存生效后进入调度循环；用户既可在"自动化列表"进行运维管控（暂停、恢复、编辑、删除），也可在"已执行记录"查看每次运行结果，二者共同构成任务的完整生命周期管理。

三、详细设计

自动化模块包含四个页面：自动化列表页（任务总览与运维）、已执行记录页（运行历史追溯）、模板中心页（预置模板一键创建）和创建/编辑自动化页（任务配置表单）。以下按页面分别说明功能描述、显示字段与表单字段。

🔹 3.1 自动化列表页

功能描述

自动化列表页是模块的主入口（默认页签），以卡片列表形式展示用户全部自动化任务。每张卡片展示任务名称、运行状态、下次运行信息，并提供运行、编辑、删除操作，以及生效任务的暂停/恢复切换。列表顶部设有引导区与"添加自动化"入口；用户也可点击卡片本身进入编辑。该页面同时承载任务的即时运维：手动触发执行、暂停/恢复调度、删除任务。

显示字段说明

字段 / 按钮规则来源 / 例外 / 边界
添加自动化 顶部常驻入口，点击打开空白创建弹窗 来源：全局操作入口；例外：在任何页签下均可见，点击均进入创建流程
任务图标 统一以时钟图标呈现，作为任务视觉标识 来源：系统统一预设，用户不可更改
任务名称 展示自动化任务名称，如"提醒我下班""每日新闻推送" 来源：创建/编辑时由用户填写；边界：名称过长时以省略号收起，不换行撑破布局
状态标签 区分四态并以不同底色与文字区分：生效中、已暂停、已失效、执行中 来源：系统根据任务配置自动判定；例外：新建任务默认"生效中"；已失效任务（如单次任务已过执行时间）不展示暂停/恢复切换按钮
下次运行信息 展示下一次执行时间与频率描述，如"下次运行 2 小时后 · 工作日 18:00""即将运行 · 每天 07:00" 来源：系统依据执行频率配置与当前时间自动推算；边界：用户不可直接编辑；已失效任务展示"单次 X 时间"而非倒计时
------------
下次运行时间显示规范：
    ① 超出1天，则显示x天后；
    ② 1天内，显示x小时后；
    ③ 1小时内，显示x分钟后；
    ④ 1分钟内，显示即将执行；
------------
执行频率显示规范：
    ① 按周期： 每天/每周/双周/每月/每年，周一、周二/1日、2日/1月、2月，08:30
    ② 按间隔：周一、周二，每隔1小时执行；
    ③ 按单次：单次 2026-07-28 16:00
运行按钮 点击立即触发该任务执行一次，并展示执行进度 例外：仅鼠标悬停时显示；执行中状态仍允许点击，但任务已处于运行态；点击后状态切换为"执行中"
编辑按钮 点击打开编辑弹窗，并回填该任务全部配置 来源：与点击任务卡片本身等效；例外：仅悬停时显示
删除按钮 点击弹出二次确认，确认后移除任务 例外：仅悬停时显示；确认弹窗内展示任务名称，确认后下方任务项平滑上移填补空位
暂停 / 恢复按钮 生效中任务显示"暂停"，已暂停任务显示"恢复"，点击切换状态并提示 例外：仅悬停时显示；已失效任务不显示该按钮；切换后状态标签与按钮形态同步更新
运行进度条 任务执行时在卡片底部展示进度动画，表示执行进行中 边界：进度约 3 秒后任务自动恢复为"生效中"，并提示用户可查看执行结果
💡 "下次运行信息"为系统推算的只读展示字段，用户不可编辑；"已失效"状态（如单次任务已过执行时间）不再触发运行，且隐藏暂停/恢复切换，但仍支持运行、编辑与删除。

🔹 3.2 已执行记录页

功能描述

已执行记录页以列表形式展示该用户全部自动化任务的运行历史。每条记录展示任务名称、执行结果（成功/失败/等待中）与执行时间（相对时间，如"19 小时前"）。点击记录可跳转至运行结果详情页查看 Agent 输出；悬停时显示删除按钮与"点击查看任务运行结果"提示气泡，便于追溯与清理。

显示字段说明

字段 / 按钮规则来源 / 例外 / 边界
结果指示点 以圆点颜色区分执行结果：成功（绿）、失败（红）、等待中（灰） 来源：由每次执行的后台结果回填；边界：等待中表示已触发但尚未产出结果
任务名称 展示产生该记录的原自动化任务名称 来源：关联对应自动化任务，名称变更后历史记录仍保留原名称快照
失败标签 仅失败记录额外展示红色"失败"文字标签 例外：成功与等待中记录不展示该标签
执行时间 以相对时间展示，如"19 小时前""1 天前""3 天前" 来源：执行发生时刻换算；边界：超过整天以"N 天前"展示，不显示精确时分
删除按钮 悬停显示，点击删除该条执行记录并提示 例外：仅悬停时显示；点击删除不会触发跳转详情
结果提示气泡 悬停记录时跟随鼠标显示"点击查看任务运行结果" 例外：仅悬停时显示；点击记录本身跳转任务执行详情，与删除按钮互不干扰
💡 点击记录跳转运行结果详情页，但点击删除按钮仅删除该记录、不触发跳转，二者通过交互隔离避免误操作。

🔹 3.3 模板中心页

功能描述

模板中心页提供平台预置的常见自动化模板，以三列卡片网格展示，帮助用户一键创建高频场景任务。每张卡片展示图标、名称、描述与默认执行时间；鼠标悬停时显示气泡提示"点击即可按此模板创建自动化任务"。点击卡片即打开创建弹窗，并自动预填模板的名称、提示词、模型、技能、MCP 与执行频率，用户仅需确认或微调即可保存。

显示字段说明

字段 / 按钮规则来源 / 例外 / 边界
模板图标 每个模板配置专属图标，作为视觉识别 来源：模板数据内置，与模板主题对应
模板名称 展示模板标题，如"每日新闻推送""每周工作周报" 来源：模板预置名称；边界：与创建后的任务名称一致，用户可在弹窗内修改
模板描述 简述模板功能与产出，如"关注当天 AI 领域的重要动态……" 来源：模板预置；边界：描述最多展示三行，超出部分以省略号收起，不强制展开
默认执行时间 展示模板预设的执行时间，如"每天 08:00" 来源：模板频率配置换算；在创建弹窗内可调整
卡片（整体） 点击卡片即按该模板创建自动化，打开预填好的创建弹窗 例外：点击时先关闭悬停提示气泡，再打开弹窗，避免气泡残留

🔹 3.4 创建/编辑自动化页（弹窗）

功能描述

创建/编辑自动化页以弹窗形式承载任务配置，是模块的配置中枢。创建模式由"添加自动化"或模板卡片打开，标题为"添加自动化"；编辑模式由列表的编辑按钮或点击卡片打开，标题为"编辑自动化"并回填当前任务全部配置。弹窗包含头部（图标、标题、副标题、关闭）、主体表单（名称、项目、提示词、模型、技能、MCP、执行频率、生效区间）与底部操作（取消、保存）。任一表单区域的展开面板互斥打开，面板智能定位以避免超出可视区域。

显示字段说明（弹窗框架）

字段 / 按钮规则来源 / 例外 / 边界
弹窗图标 头部左侧展示文档/卡片类图标，标识当前为自动化配置场景 来源：系统统一预设
弹窗标题 创建时显示"添加自动化"，编辑时显示"编辑自动化" 来源：根据打开模式动态切换
副标题 创建时"预设最佳流程，一键开启自动化。"，编辑时"修改自动化任务配置。" 来源：随模式切换
关闭按钮 点击关闭弹窗，放弃未保存的修改 例外：关闭不触发校验、不保存
取消按钮 底部左侧，点击关闭弹窗 与关闭按钮行为一致
保存按钮 底部右侧，点击校验必填项后保存并关闭 边界：名称或提示词为空时高亮对应输入并提示，阻止保存；创建成功提示"自动化任务已添加成功"，编辑成功提示"自动化任务已更新成功"

表单字段说明

字段类型必填说明（含表单字段与表单按钮）
名称 单行文本 是 自动化任务名称；来源：用户输入。边界：为空时输入框高亮并提示"请输入任务名称"，开始输入后即时清除提示。
项目 下拉单选 否 关联项目（项目 Alpha / Beta / Gamma / Delta / Epsilon）；来源：平台项目列表。边界：未选时显示"选择项目"占位，不影响保存。
提示词 多行文本 是 Agent 实际执行的内容；来源：用户输入。边界：为空时高亮并提示"请输入提示词"，输入后即时清除；提示词区域附带模型与技能快捷选择。
模型 下拉单选（分组） 否 选择执行使用的 AI 模型，分"企业模型""个人模型"两组（如 gpt-5.5、gpt-5、gpt-4o、claude-sonnet-4、deepseek-r1 等）；默认选中设置的默认模型。来源：设置页面 - 模型管理；分组下没有数据则不显示该分组。
技能 多选标签 否 下拉可搜索多选，选中项以标签（图标+名称+移除按钮）展示在触发器内；支持按名称/描述模糊搜索，无匹配时展示空状态提示。
MCP 分组多选 否 通过"MCP 市场 / 自定义 MCP"两个页签切换；服务可展开，支持父级全选/取消与子级单选；选中项按所属服务分组展示标签；部分选中时显示"服务名 (N)"标识已选数量。
执行频率 复合选择 是 三种模式：按周期 / 按间隔 / 单次。来源：用户配置。边界：未选择时提示"请选择执行频率"。具体子配置见下表。
　└ 按周期 子配置 是 每天（设定时间，默认 08:30）/ 每周·双周（多选星期 + 设定时间）/ 每月（多选日期 1–31 日，支持全选/反选 + 时间）/ 每年（多选月份 + 多选日期 + 时间）。切换周期单位时仅展示对应子选项。
　└ 按间隔 子配置 是 可选多选星期限定执行日 + 每隔 N 小时执行（数字输入，默认 1）。
　└ 单次 子配置 是 选择日期 + 时间，仅执行一次，执行后任务关闭。边界：不能选择当前时间之前的时间。
生效区间 日期范围 否 设定开始日期与结束日期；边界：未填写则永久生效，界面以"（未填写则永久生效）"提示。
取消（按钮） 按钮 — 关闭弹窗，放弃本次修改，不做任何保存。
保存（按钮） 按钮 — 校验必填项（名称、提示词、执行频率）通过后保存：若已选关联项目则在对应项目下创建会话，未选则自动归入自动化默认项目；随后关闭弹窗并提示创建/更新成功。
