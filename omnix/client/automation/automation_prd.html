一、概述

背景与目标

在 AI Agent 平台中，用户经常需要重复执行某些任务（如每日新闻推送、每周周报、定时提醒等）。目前用户只能手动逐次触发 Agent 执行，无法设定周期性或定时任务，效率低且容易遗忘。自动化模块旨在提供一套完整的任务调度与自动化执行管理平台，让用户能够设定提示词、配置运行频率、绑定模型/技能/MCP，实现任务的定时或周期性自动执行，同时提供模板中心快速复用、执行历史追溯和运行状态管控。

用户画像

日常效率型用户

希望定时提醒（下班提醒、体检预约）、推送信息（新闻、单词），追求"不遗漏"的日常辅助

内容创作者

需要周期性生成内容（壁纸、冷知识、电影推荐），利用模板一键创建、自动产出

项目管理型用户

需要定期汇总信息（周报、PR/Issue梳理、会议准备），依赖 MCP 和技能获取数据

核心目标

  • 降低重复操作成本：用户设定一次，系统按频率自动执行，无需手动触发
  • 提升任务可观测性：执行历史、成功/失败状态一目了然，运行结果可追溯
  • 加速任务创建：模板中心提供预置模板，一键预填配置，降低创建门槛
  • 灵活的调度配置：支持按周期（每天/每周/双周/每月/每年）、按间隔、单次执行三种模式，附带生效区间控制

非目标（Non-goals）

  • 不做触发式自动化（如"当收到邮件时自动执行"），本期仅支持时间触发
  • 不做自动化任务的分支/条件逻辑（如 if-else 分支），每条自动化仅执行一条提示词
  • 不做多步骤串联（如第一步执行 A → 第二步执行 B），每条自动化为单步执行
  • 不做自动化任务共享/协作，自动化为个人级别，不跨用户

用户故事

作为 日常效率型用户，我希望 设定"每天 18:00 提醒我下班"的自动化任务，以便 不用每天手动触发，系统自动在下班时间提醒我，避免忘记休息。
作为 项目管理型用户，我希望 创建"每周五 17:00 工作周报"的自动化，绑定 GitHub MCP 和腾讯文档技能，以便 系统自动从仓库提取 PR/Issue 信息并整理成周报，节省每周手动汇总的时间。
作为 内容创作者，我希望 从模板中心选择"每日新闻推送"模板一键创建自动化，以便 不用从零填写提示词和频率配置，快速开启每日信息推送。
作为 所有用户，我希望 在已执行列表中查看历史运行记录及成功/失败状态，以便 追溯任务执行效果，发现失败时能及时排查问题。

二、功能架构与流程图

三、子模块详细设计

自动化模块包含四个子功能：自动化列表管理（查看/运行/暂停/编辑/删除）、已执行记录（运行历史追溯）、模板中心（预置模板一键创建）和创建/编辑自动化（表单配置）。以下分别说明每个子功能的描述、字段设计、功能清单和特殊规则说明。

🔹 3.1 自动化列表管理

功能描述

自动化列表是模块的核心入口，以卡片式列表展示用户所有自动化任务。每个任务项展示名称、状态标签、下次运行时间/频率描述。悬停时显示操作按钮（手动运行、编辑、删除）和状态切换按钮（暂停/恢复）。点击任务项可进入编辑模式。列表上方有 Hero 卡片引导区域和"添加自动化"入口按钮。

字段设计

字段类型必填说明
图标 系统图标 — 每个任务项使用时钟图标作为视觉标识，统一风格
名称 文本 ✅ 自动化任务名称，如"提醒我下班"、"每日新闻推送"，用于标识和搜索
状态标签 枚举 ✅ 生效中 / 已暂停 / 已失效 / 执行中。新增默认为"生效中"
下次运行时间 文本描述 自动 展示下次运行倒计时或频率描述，如"下次运行 2小时后 · 工作日 18:00"、"即将运行 · 每天 07:00"
操作按钮 交互 — 悬停显示：手动运行（播放图标）、编辑（笔图标）、删除（垃圾桶图标）
状态切换 交互 — 仅"生效中"任务显示暂停按钮；"已暂停"任务显示恢复按钮
进度条 动画 — "执行中"状态时底部显示进度条动画，完成后恢复为"生效中"
💡 "下次运行时间"为系统根据频率配置和当前时间自动计算的展示字段，用户不可编辑。"已失效"状态的任务（如单次执行已过期的任务）不显示状态切换按钮。

功能清单

序号功能名称优先级功能描述
1 自动化列表展示 P0 以卡片列表展示所有自动化任务，显示名称、状态标签、下次运行描述。顶部 Hero 卡片引导
2 手动运行 P0 点击运行按钮后，任务状态切换为"执行中"，底部显示进度条动画，完成后恢复"生效中"并 Toast 提示"任务执行完成，点击查看"

4 编辑任务 P0 点击编辑按钮或任务项本身，打开编辑弹窗，预填当前任务所有配置数据
5 删除任务 P0 点击删除按钮弹出二次确认弹窗（"确定要删除「{名称}」吗？删除后不可恢复。"），确认后删除任务项并 Toast 提示
6 添加自动化入口 P0 顶部导航栏"添加自动化"按钮，点击打开空白创建弹窗

🔹 3.2 已执行记录

功能描述

已执行记录是自动化任务运行历史的追溯入口，以列表展示所有已执行的自动化任务记录。每条记录显示任务名称、执行状态（成功/失败）和执行时间（相对时间描述如"19 小时前"）。悬停时显示删除按钮和 Tooltip 提示"点击查看任务运行结果"，点击记录跳转执行结果详情页。

字段设计

字段类型必填说明
状态圆点 枚举 ✅ 成功（绿色圆点）、失败（红色圆点）、等待中（灰色圆点），标识执行结果
任务名称 文本 ✅ 关联的自动化任务名称
失败标签 标签 — 仅失败记录显示红色"失败"文字标签
执行时间 相对时间 ✅ 如"19 小时前"、"1 天前"、"3 天前"，精确到相对天数
删除按钮 交互 — 悬停显示删除按钮，点击删除该执行记录并 Toast 提示
Tooltip 交互 — 鼠标跟随显示"点击查看任务运行结果"浮动提示

功能清单

序号功能名称优先级功能描述
1 已执行列表展示 P0 列表展示所有已执行记录，显示状态圆点、名称、失败标签、相对时间
2 查看执行结果 P0 点击已执行记录跳转执行结果详情页（content.html），查看 Agent 输出内容
3 删除执行记录 P1 悬停显示删除按钮，点击删除该记录并 Toast 提示"已删除该执行记录"
4 Tooltip 提示 P2 鼠标悬停已执行记录时，浮动 Tooltip 随鼠标移动显示"点击查看任务运行结果"

特殊规则说明

序号规则说明
1 状态圆点颜色映射 成功（绿色 #10b981）、失败（红色 #ef4444）
2 失败标签仅失败显示 仅失败记录显示红色"失败"文字标签，成功和等待中不显示

🔹 3.3 模板中心

功能描述

模板中心提供预置自动化模板，帮助用户一键创建常见自动化任务。以 3 列卡片网格展示模板，每张卡片显示图标、名称、描述（最多 3 行截断）和默认执行时间。鼠标悬停时显示 Tooltip 提示"点击即可按此模板创建自动化任务"，点击卡片后自动打开创建弹窗并预填模板数据（名称、提示词、模型、技能、MCP、频率）。

字段设计

字段类型必填说明
模板图标 SVG 图标 — 每个模板配专属 SVG 图标
模板名称 文本 ✅ 模板标题，如"每日新闻推送"、"每周工作周报"
模板描述 文本 ✅ 功能简述，最多 3 行截断展示（-webkit-line-clamp:3）
默认执行时间 文本 — 预置执行时间描述，如"每天 08:00"

预置模板

系统内提前预置模板。

🔹 3.4 创建/编辑自动化

功能描述

创建/编辑自动化弹窗是任务配置的核心表单，包含名称、项目、提示词、模型选择、技能多选、MCP 多选、执行频率配置和生效区间设置。创建模式标题为"添加自动化"，编辑模式标题为"编辑自动化"，编辑时预填当前任务所有配置数据。弹窗顶部显示图标+标题+副标题，底部有取消和保存按钮。

字段设计

字段类型必填说明
名称 文本输入 ✅ 自动化任务名称，为空时显示红色边框和"请输入任务名称"错误提示
项目 下拉单选 — 关联项目选择（项目 Alpha / Beta / Gamma / Delta / Epsilon），非必填
提示词 文本域 ✅ Agent 执行的提示词内容，支持多行输入，为空时红色边框 + "请输入提示词"错误提示
模型选择 下拉单选 — 分组下拉：企业模型、个人模型；默认选中默认模型；
技能多选 多选标签 — 下拉搜索多选，支持按名称/描述搜索。选中项以标签形式展示（含图标+名称+删除按钮）
MCP 多选 分组多选 — 双 Tab（MCP市场 / 自定义MCP），下拉搜索，分组折叠选择。选中项按 MCP 服务分组展示标签
执行频率 复合选择 ✅ 三种模式：按周期 / 按间隔 / 单次。为空时"请选择执行频率"错误提示
生效区间 日期范围 — 开始日期和结束日期，未填写则永久生效

执行频率详细配置

模式周期单位必填配置项
按周期 每天 ✅ 选择时间（默认 08:30）
按周期 每周/双周 ✅ 多选星期（周一至周日，Checkbox） + 选择时间
按周期 每月 ✅ 多选日期（1-31日，Checkbox + 全选/反选） + 选择时间
按周期 每年 ✅ 多选月份（1-12月，Checkbox + 全选/反选） + 多选日期 + 选择时间
按间隔 — ✅ 多选星期（可选） + 每隔 N 小时执行（数字输入，默认 1）
单次 — ✅ 选择日期 + 选择时间。提示："仅执行一次，执行后关闭该任务；不能选择当前时间之前的时间"

四、边界与异常情况

序号场景处理策略备注
1 创建自动化时名称为空 输入框红色边框 + 显示"请输入任务名称"错误提示，阻止保存 即时校验 + 保存时兜底
2 创建自动化时提示词为空 文本域红色边框 + 显示"请输入提示词"错误提示，阻止保存 即时校验 + 保存时兜底
3 必填校验后输入内容清除错误 输入内容后即时移除红色边框和错误提示文字 on input 事件清除
4 多个下拉同时打开冲突 打开任一下拉时自动关闭其他已打开的下拉面板 防止界面混乱
5 下拉面板溢出屏幕 使用 position:fixed 定位，根据触发按钮位置动态计算，适配视窗边界 确保面板可见
6 删除自动化任务 弹出确认弹窗"确定要删除「{名称}」吗？删除后不可恢复。"，确认后删除并下方项平滑上移 二次确认 + 动画
7 手动运行动画期间再次操作 运行状态 3 秒动画期间，进度条使用 CSS animation forwards，不阻止其他操作 动画为前端展示效果
8 技能搜索无匹配 显示"未找到匹配的技能"空状态提示 前端即时反馈
9 MCP 搜索无匹配 显示"未找到匹配的MCP"空状态提示 前端即时反馈
10 已失效任务操作 "已失效"状态（如单次执行已过期）不显示暂停/恢复切换按钮，但仍可运行/编辑/删除 保持可用性
11 已执行记录删除跳转冲突 点击删除按钮时 stopPropagation 阻止触发跳转，仅删除记录 事件隔离
12 模板 Tooltip 与弹窗切换 点击模板卡片时先关闭 Tooltip，再打开创建弹窗 避免残留 Tooltip
13 星期/日期弹出面板全选与反选 提供"全选"和"反选"按钮，仅对当前弹出面板内 Checkbox 生效 便捷操作
14 编辑弹窗回填频率配置 编辑时根据原始数据切换频率模式、周期单位、时间、星期/日期，完整还原配置状态 完整回填
15 点击任务项触发编辑而非其他操作 点击任务项卡片（排除操作按钮和状态切换按钮区域）触发编辑弹窗 stopPropagation 区分
16 MCP 分组全选/取消交互 点击 MCP 服务头部（非展开图标区域）：全选所有子级或取消所有子级选中 一键操作
17 MCP 部分选中状态标识 部分选中时父级显示横线 Check（而非全选勾），选中计数显示"N/M 项已选" 状态清晰
18 点击外部关闭所有下拉 document 全局 click 事件关闭所有打开的下拉面板、弹出面板、Tooltip 统一关闭逻辑
